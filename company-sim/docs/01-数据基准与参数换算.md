## 三、⭐ 三个必须写进游戏的真相

### 真相 1：正餐和火锅，五年平均净利率是负的

- **正餐**：5 年均值净利率 min -27.7% / 中位 -9.6% / max 7.0%
- **火锅**：5 年均值净利率 min -9.0% / 中位 -6.2% / max 5.1%

不是算错。因为样本里有连年亏损的西安饮食、呷哺呷哺、特海国际，还有疫情三年巨亏的全聚德。

**游戏设计含义：默认状态就该是亏的，玩家要做的是把负号拧成正号。**

### 真相 2：毛利率是骗人的

| 品类 | 毛利率 | 人工+折旧+管理+销售 | 真实剩余 |
|---|---|---|---|
| 火锅（呷哺） | 65.0% | 34.8+16.3+4.3 = 55.4% | **9.6%，再减税和财务费用 → -7.8%** |
| 正餐（同庆楼） | 19.3% | 27.0+30.8+4.6+5.5 = 67.9% | **直接为负，靠其他收益救回 3.8%** |
| 茶饮（蜜雪） | 31.1% | 3.2+6.1 = 9.3% | **21.8%，税后 17.7%** |

**火锅毛利看着 65%，但人工 35% + 折旧 16% 吃光，最后亏钱。**
**茶饮毛利只有 31%，但人工极低（加盟商出人），最后赚 17%。**

这是全游戏最反直觉、也最真实的一课：**毛利高不等于赚钱，得看谁在干活。**

### 真相 3：加盟模式 = 卖铲子

蜜雪、古茗、茶百道的净利率 15%~24%，高出直营火锅 20 个百分点。

原因：**它们不炒菜、不雇厨师、不租门店。** 它们卖原料给加盟商、收加盟费，风险全在加盟商那边。

代价是毛利率只有 31%（卖原料本来薄利），但成本结构极轻。

**游戏设计含义：这是"换赛道"的核心选项之一——从亲自干活（直营）转成卖铲子（加盟），毛利降、净利率升、但失去品控和口碑控制权。**

## 四、单店模型换算

### 换算原则
上市公司是全公司合并数据，含总部费用。做单店模型要拆掉总部层。

**换算公式**：
```
单店人工率  = 合并人工率 × (1 + 总部裁员比)
单店管理率  = 合并管理率 × 0.3   （总部管理费不摊到单店）
单店折旧率  = 合并折旧率         （门店折旧本就归属单店）
```

### 四种品类的单店基准模型

#### A. 正餐·单店（参考同庆楼/全聚德）

⚠️ **口径必须先说清，否则会算错**：上市公司报表里的"营业成本"已经含了部分人工和折旧。
若直接拿"毛利率 18%"当食材毛利、再叠加人工 30% + 房租 25%，等于重复扣两遍，会算出 -44% 的假亏损。

**正确算法（单店视角，成本不重复）**：

| 项目 | 占营收 | 月金额 |
|---|---|---|
| 月营收 | 100% | 60.0 万 |
| 食材成本 | 42% | 25.2 万 |
| 人工成本 | 30% | 18.0 万 |
| 房租折旧 | 20% | 12.0 万 |
| 水电燃气 | 4% | 2.4 万 |
| 管理杂费 | 3% | 1.8 万 |
| **月净利** | **+1.0%** | **+0.6 万（勉强保本）** | 验算值 |

**验算：60 − 25.2 − 18.0 − 12.0 − 2.4 − 1.8 = +0.6 万 ✅**

**结论：正餐单店天生在保本线上挣扎，翻台率掉一点就亏。**

#### B. 火锅·单店（参考海底捞，非呷哺规格）

| 项目 | 占营收 | 月金额 | 来源 |
|---|---|---|---|
| 月营收 | 100% | 80.0 万 | 海底捞单店年营收约 1000 万 |
| 食材成本 | 40% | 32.0 万 | 海底捞毛利 59.5% |
| 人工成本 | 33% | 26.4 万 | 海底捞 32.6% |
| 房租折旧 | 12% | 9.6 万 | 海底捞 5.1%，小店更高 |
| 水电燃气 | 5% | 4.0 万 | 火锅耗能高 |
| 管理杂费 | 4% | 3.2 万 | |
| **月净利** | **+6.0%** | **+4.8 万（微利）** | 验算值 |

**验算：80 − 32.0 − 26.4 − 9.6 − 4.0 − 3.2 = +4.8 万 ✅**

**火锅反而比正餐健康，因为毛利率够高（60%）能扛住 33% 的人工。**

#### C. 快餐·单店（参考百胜，KFC 规格）

| 项目 | 占营收 | 月金额 | 来源 |
|---|---|---|---|
| 月营收 | 100% | 40.0 万 | KFC 单店年营收约 500 万 |
| 食品成本 | 35% | 14.0 万 | 快餐食材占比低于正餐 |
| 人工成本 | 18% | 7.2 万 | 百胜未披露，按行业均值 |
| 房租折旧 | 12% | 4.8 万 | |
| 水电 | 4% | 1.6 万 | |
| 管理杂费 | 4% | 1.6 万 | |
| **月净利** | **+27.0%** | **+10.8 万** | 验算值 |

⚠️ 这里必须说明：**百胜报表的"毛利率 21.7%"不是快餐店的食材毛利**，而是集团层面扣完门店运营成本后的数。

**单店视角下，快餐店的食材成本约占营收 35%，毛利率约 65%**——比正餐（58%）高，因为标准化、集中采购、半成品。

**百胜净利率只有 8.5%，是因为它把大量利润让给了加盟商和员工激励，不是单店不赚钱。**

**验算：40 − 14.0 − 7.2 − 4.8 − 1.6 − 1.6 = +10.8 万 ✅**

#### D. 茶饮·加盟单店（参考蜜雪）

| 项目 | 占营收 | 月金额 | 来源 |
|---|---|---|---|
| 月营收 | 100% | 8.0 万 | 蜜雪小店日均 2600 元 |
| 原料成本 | 50% | 4.0 万 | 加盟商从总部进货后自己卖 |
| 人工 | 11.25% | 0.9 万 | 2 人 × 4500 |
| 房租 | 18.75% | 1.5 万 | |
| **加盟商月净利** | **+20.0%** | **+1.6 万** | 验算值 |

**验算：8.0 − 4.0 − 0.9 − 1.5 = +1.6 万 ✅**

而总部那头：**卖原料给这家店，毛利率 31%，月赚 2.5 万原料差价。**

**两头都赚，因为加盟商承担了开店的资本支出和经营风险。**

## 五、现金流节奏（比利润更要命）

真实企业倒闭，90% 不是亏死，是**现金流断**。

### 关键参数

| 品类 | 应收账款周转 | 应付账款周转 | 存货周转 | 说明 |
|---|---|---|---|---|
| 正餐/火锅 | 3~15 天 | 30~60 天 | 5~15 天 | C 端现结，主要是团购平台账期 |
| 快餐 | 1~10 天 | 30~45 天 | 3~8 天 | |
| 茶饮加盟 | 15 天 | 30~45 天 | 10~20 天 | 加盟商有账期 |
| 食品制造 | 30~60 天 | 60~90 天 | 30~60 天 | 商超账期长 |

### 游戏机制设计

```
每月结算顺序（不可调整）：
1. 收钱（按账期到账，不是当月全部到账）
2. 付工资（每月 10 号，雷打不动）
3. 付房租（每月 1 号）
4. 付货款（按应付账期）
5. 还贷款（按还款期）
6. 交税（按季度预缴）

如果第 2 步现金不足 → 欠薪 → 员工流失
如果第 3 步现金不足 → 欠租 → 房东解约（直接关门）
如果第 5 步现金不足 → 逾期 → 征信受损，后续借不到钱
```

**关键陷阱：营收好的时候钱还没到账，工资却已经要发了。**

**这就是"生意越做越大、老板越来越穷"的真相。**

## 六、换赛道机制（转换成本公式）

> 老爹要求：转换有成本、有成功率、有失败损失；规模越大越难转换、损失越高。

### 6.1 转换成本公式

```
转换成本 = 不可复用资产 × 折损率 + 遣散费 + 租约违约金 + 品牌重建费

其中：
不可复用资产 = 现有资产 × 不可复用比例(按规模)
```

### 6.2 不可复用比例（核心参数，按规模递增）

| 规模阶段 | 人数 | 不可复用比例 | 理由 |
|---|---|---|---|
| 小店 | 1-5 | 20% | 换个招牌、换套设备就能转 |
| 多店/小厂 | 10-50 | 45% | 要关店、赔租约、遣散员工 |
| 区域公司 | 100-500 | 70% | 供应链、渠道全绑死 |
| 上市 | 500+ | 90% | 转换等于二次创业 |

### 6.3 折损率（按新旧品类相似度）

| 转换类型 | 折损率 | 例子 |
|---|---|---|
| 相似品类 | 25% | 火锅 → 烧烤（都用一个灶、一个服务员模型） |
| 相邻品类 | 50% | 正餐 → 快餐（座位翻倍但客单价腰斩） |
| 跨大类 | 80% | 餐饮 → 食品制造（要建厂） |
| 跨模式 | 60% | 直营 → 加盟（要重建加盟体系） |

### 6.4 成功率公式

```
成功率 = 基础成功率 × 资金充足系数 × 经验系数 × 团队系数 × 时机系数
```

| 因子 | 计算方式 |
|---|---|
| 基础成功率 | 相似 70% / 相邻 55% / 跨大类 35% / 跨模式 45% |
| 资金充足系数 | 转换成本 < 现金 30% → 1.0；30-60% → 0.85；60-90% → 0.6；>90% → 0.3 |
| 经验系数 | 本行业从业年数 × 3%，上限 +30% |
| 团队系数 | 核心骨干留存率 × 1.0（流失一半就直接砍半） |
| 时机系数 | 行业上升期 1.15 / 平期 1.0 / 下行期 0.75 |

### 6.5 失败损失

```
失败损失 = 转换成本 × 1.5 + 原业务中断损失（2~6 个月营收 × 毛利率）
```

**为什么是 1.5 倍？因为失败意味着钱花了、新业务没起来、老业务也停了。**

### 6.6 举例验算

**场景：一家 3 店火锅（员工 30 人，总资产 300 万，现金 120 万），想转正餐**

```
不可复用比例：45%（多店阶段）
转换成本 = 300万 × 45% × 50%（相邻品类） = 67.5万
         + 遣散费（裁 10 人 × 2 月 × 5000） = 10万
         + 租约违约金（3 店 × 3 万）= 9万
         = 86.5 万

资金充足系数：86.5/120 = 72% → 0.6
经验系数：干了 3 年火锅 → +9% = 1.09
团队系数：骨干留 80% → 0.8
时机系数：平期 → 1.0

成功率 = 55% × 0.6 × 1.09 × 0.8 × 1.0 = 28.8%

失败损失 = 86.5 × 1.5 + 原业务中断（80万/月 × 60%毛利 × 3月）= 129.8 + 144 = 273.8万
```

**说白了：砸 86.5 万，只有 28.8% 概率成功。一旦失败，连本带利赔 273.8 万——比公司总资产（300万）还接近。**

**这就是真实世界里"转型等于二次创业"的量化证据：小店转型是决策，多店转型是赌博。**

**这就是"规模越大越难掉头"的量化体现。**
