一、公式原理与文献出处

1.1 Bazett 公式 (1920)

公式：QTc = QT / √RR

文献：Bazett HC. An analysis of the time-relations of electrocardiograms. Heart. 1920;7:353-370.

Bazett 于 1920 年提出 QT 间期与 RR 间期之间存在平方根关系。该公式假设 QT 间期随心率变化的校正因子为 RR 的平方根。这是临床应用最广泛的 QTc 校正公式，已被纳入多数心电图机的默认算法。

1.2 Fridericia 公式 (1920)

公式：QTc = QT / ∛RR

文献：Fridericia LS. Die Systolendauer im Elektrokardiogramm bei normalen Menschen und bei Patienten mit Morbus Addison. Acta Medica Scandinavica. 1920;53:469-486.

Fridericia 同期提出使用 RR 间期的立方根作为校正因子。相比 Bazett 公式，Fridericia 在极端心率下的偏差较小，但仍非完美。

1.3 Framingham 公式 (1992)

公式：QTc = QT + 154 × (1 − RR)，其中 QT 单位为 ms，RR 单位为秒

文献：Sagie A, Larson MG, Goldberg RJ, Bengtson JR, Levy D. An improved method for adjusting the QT interval for heart rate (the Framingham Heart Study). Am J Cardiol. 1992;70(7):797-801.

注：原始文献中回归系数 β = 0.154（QT 与 RR 均以秒为单位）。当 QT 以 ms 为单位输入时，系数需乘以 1000，即 154。本工具采用此换算后的形式。

Framingham 公式基于 Framingham 心脏研究的 5000 余名受试者数据，采用线性回归模型。该公式在较宽心率范围内表现较为稳定。

二、计算步骤详解

  1. 输入验证：检查心率是否在 30–200 次/分范围内，QT 是否在 200–700 ms 范围内。超出范围则拒绝计算并提示用户。
  2. RR 间期计算：RR = 60 / HR（单位：秒）。例如 HR = 72 次/分 → RR = 60/72 ≈ 0.833 秒。
  3. Bazett 校正：计算 √RR，然后 QTc_Bazett = QT / √RR。例如 QT = 400 ms，RR = 0.833 s → √0.833 ≈ 0.913 → QTc = 400/0.913 ≈ 438 ms。
  4. Fridericia 校正：计算 ∛RR，然后 QTc_Fridericia = QT / ∛RR。例如 QT = 400 ms，RR = 0.833 s → ∛0.833 ≈ 0.941 → QTc = 400/0.941 ≈ 425 ms。
  5. Framingham 校正：QTc_Framingham = QT + 154 × (1 − RR)。例如 QT = 400 ms，RR = 0.833 s → QTc = 400 + 154 × 0.167 ≈ 426 ms。
  6. 风险分层：根据性别判断 QTc 是否延长。男性阈值 450 ms，女性阈值 460 ms（部分文献采用 470 ms）。QTc > 500 ms 为高度心律失常风险。

三、适用场景与不适用场景

3.1 适用场景

  • 窦性心律下的常规心电图 QT 间期评估
  • 药物安全性监测（如已知可延长 QT 的药物）
  • 先天性长 QT 综合征的初步筛查
  • 电解质紊乱（低钾、低镁、低钙）对复极的影响评估
  • 临床试验中 QT/QTc 作为安全性终点

3.2 不适用场景

  • 心房颤动/心房扑动：RR 间期不规则，单一 RR 值无法代表整体心率，三种公式均不可靠。应取多个心搏的平均值或使用特殊方法。
  • 束支传导阻滞/心室起搏心律：QRS 增宽导致 QT 测量本身不准确，校正公式的前提不成立。
  • 极端心率（<30 或 >200 次/分）：超出公式验证范围，结果不可信。
  • T 波低平或 U 波融合：QT 测量本身存在困难，校正结果无意义。
  • 儿童（尤其婴幼儿）：上述公式均基于成人数据推导，儿童需使用年龄特异性参考值。

四、临床/工程意义

QTc 间期反映心室复极化的时间长度，是预测恶性室性心律失常（尤其是尖端扭转型室速，TdP）的重要指标。

临床意义：

  • QTc 450–500 ms（男性）或 460–500 ms（女性）：边界延长，需关注潜在可逆因素（药物、电解质）。
  • QTc > 500 ms：高度风险区间，TdP 发生率显著增加。需紧急评估并处理可逆因素，考虑心电监护。
  • QTc 变化量（ΔQTc）：某些场景下，QTc 较基线延长 > 60 ms 比绝对值更有临床意义。

工程/研发意义：

  • 药物研发中，ICH E14 指南要求评估新药对 QTc 的影响。Fridericia 校正（QTcF）通常作为主要分析指标，因其在心率变化较大时偏差较小。
  • 心电图设备制造商需实现多种校正算法，供临床选择。
  • 远程心电监测系统中，QTc 自动计算可辅助预警，但须设置合理的报警阈值并配合人工复核。

五、已知局限与误差来源

  1. Bazett 公式的系统偏差：心率 > 100 次/分时过度校正（QTc 偏高），心率 < 60 次/分时校正不足（QTc 偏低）。偏差可达 20–40 ms 甚至更多。
  2. 个体差异：所有公式均基于群体回归，未考虑年龄、性别、体型等个体因素对 QT-RR 关系的影响。
  3. QT 测量误差：不同导联、不同测量方法（手动 vs 自动）可导致 QT 值差异 20–40 ms。
  4. 心率变异性：即使窦性心律，呼吸性窦性心律不齐也可导致相邻心搏的 QTc 差异显著。
  5. Framingham 公式的人群特异性：基于美国 Framingham 队列（主要为白人中老年人），在其他种族/年龄群体中的适用性需验证。

六、精度与误差说明

① 算准了什么

本工具严格按照给定公式进行数学计算，浮点运算精度在 IEEE 754 双精度范围内（约 15–16 位有效数字）。对于给定输入，计算结果在数学上是确定的、可复现的。输出值四舍五入至小数点后 1 位。

② 哪些因素没算进去

  • 未考虑 QT 测量本身的误差（导联选择、T 波终点判定等）
  • 未考虑心律不齐时的逐搏变异
  • 未考虑药物、电解质、体温等对 QT-RR 关系的动态影响
  • 未实现个体化校正（如基于患者自身 QT-RR 回归的校正）
  • 未考虑不同公式之间的系统性差异（同一数据用不同公式可得到差异 > 30 ms 的结果）

③ 误差大概多大

  • 数学计算误差：< 0.1 ms（可忽略）
  • Bazett 公式在 HR 100 次/分时：可能高估 QTc 约 10–25 ms
  • Bazett 公式在 HR 45 次/分时：可能低估 QTc 约 15–30 ms
  • QT 测量本身的不确定性：通常 20–40 ms，这是最大的误差来源
  • 不同公式间的差异：在极端心率下可达 30–60 ms

结论：本工具的计算精度不等于临床精度。QTc 值的临床解读必须考虑测量误差和公式局限性，不应将计算结果视为"真实"QTc。

适用范围与假设条件

适用条件：

  • 窦性心律（规则的心室激动）
  • 心率在 30–200 次/分范围内
  • QT 间期在 200–700 ms 范围内
  • QRS 波宽度正常（< 120 ms）
  • T 波形态可辨识，T 波终点可明确判定
  • 成人患者（≥18 岁）

不适用条件（结果不可靠）：

  • 心房颤动、心房扑动等不规则心律
  • 束支传导阻滞、预激综合征、心室起搏心律
  • 低体温（< 35°C）导致的显著 QT 延长
  • 急性心肌缺血/梗死急性期
  • 输入参数超出上述范围
