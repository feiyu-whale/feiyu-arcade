第三部分 · 使用说明书



一、工具简介


本工具用于按照 GB/T 7714-2015《信息与文献 参考文献著录规则》 生成规范的参考文献条目。该国标等效采用 ISO 690:2010，是国内学术论文、科技报告、学位论文、期刊投稿中最常用的参考文献著录依据。


工具解决的核心问题：


    
  
  • 手工拼接参考文献时标点、空格、大小写极易出错（例如英文作者姓与名的顺序、页码连接符、文献类型标识方括号等）。
    • 
  
  • 不同文献类型（专著、期刊、学位论文、报纸、电子资源、标准）的著录格式差异较大，需要分别记忆。
    • 
  
  • 顺序编码制与著者-出版年制两种编排方式在标点、序号、年份位置上存在细微差别。
    • 



本工具通过结构化输入（JSON 对象）+ 纯函数输出（字符串），把上述规则固化为可复用的代码，避免人工反复核对国标原文。



二、标准依据


    
  
  • GB/T 7714-2015《信息与文献 参考文献著录规则》（现行有效，替代 GB/T 7714-2005）。
    • 
  
  • 文献类型标识采用该标准附录 A 的规定：M（普通图书）、J（期刊）、D（学位论文）、N（报纸）、EB（电子资源）、S（标准）等。
    • 
  
  • 载体标识采用附录 B：OL（联机网络）、MT（磁带）、DK（磁盘）等，本工具仅实现最常用的 [EB/OL]。
    • 



说明：本工具严格遵循 GB/T 7714-2015 正文与附录的明文规定。对于标准中"可省略""宜""建议"等推荐性条款，本工具按"保留"处理，以保证信息完整。个别细节（如 DOI 的著录位置）在标准中存在多种示例，本工具采用标准正文 8.1 节的示例样式，如需其他样式请查标准原文。



三、参数说明


主入口 formatReference(data, style) 接受两个参数：



  
参数类型取值范围含义

  
dataObject见下表文献元数据对象，不同 type 所需字段不同

  
stylestring'numeric' | 'author-year'编排体制。numeric 为顺序编码制，author-year 为著者-出版年制





data 通用字段：



  
字段类型必填说明

  
typestring是文献类型：'M' | 'J' | 'D' | 'N' | 'EB' | 'S'

  
authorsstring[]是作者列表。中文直接写"张三"；英文建议写"Smith J"（姓在前，名缩写）。超过 3 人时工具自动截断并追加", 等"或", et al"

  
titlestring是文献题名

  
yearnumber|string是出版年，4 位数字。工具会校验范围 1000–当前年份

  
indexnumber条件必填顺序编码制下的序号，从 1 开始。style='numeric' 时必填

  
citePagesstring否引文页码（专著中具体引用的页），与 pages（整体页码范围）区分

  
isChineseboolean否是否为中文文献，默认 false。影响", 等"与", et al"的选择，以及标点全半角





各类型专有字段：



  
type专有字段说明

  
MpublisherPlace, publisher, edition, pages出版地、出版者、版本（如"3 版"或"3rd ed"）、总页码

  
Jjournal, volume, issue, pages刊名、卷、期、页码范围（如"10-15"）

  
Dcity, university保存地、保存单位

  
Nnewspaper, date, edition报纸名、出版日期（YYYY-MM-DD）、版次

  
EBurl, updateDate, citeDateURL、更新日期、引用日期（均为 YYYY-MM-DD）

  
SstandardCode, publisherPlace, publisher标准编号（如"GB/T 7714-2015"）、出版地、出版者





四、实际使用场景




  
场景 1：中文专著（顺序编码制）

  

data = { type:'M', authors:['刘国钧','陈绍业'], title:'图书馆目录',
  publisherPlace:'北京', publisher:'高等教育出版社', year:1957, pages:'15-18',
  index:1, isChinese:true }

style = 'numeric'
  

  






  
场景 2：英文期刊论文（著者-出版年制）

  

data = { type:'J', authors:['O'Brien J A','Boone L E'],
  title:'The Internet challenge', journal:'Journal of Management Inquiry',
  year:1995, volume:4, issue:2, pages:'112-120', isChinese:false }

style = 'author-year'
  

  






  
场景 3：中文学位论文

  

data = { type:'D', authors:['张筑生'], title:'微分半动力系统的不变集',
  city:'北京', university:'北京大学数学系', year:1983,
  index:3, isChinese:true }

style = 'numeric'
  

  






  
场景 4：报纸文章

  

data = { type:'N', authors:['丁文祥'], title:'数字革命与竞争国际化',
  newspaper:'中国青年报', date:'2000-11-20', edition:'15',
  index:5, isChinese:true }

style = 'numeric'
  

  






  
场景 5：电子资源 [EB/OL]

  

data = { type:'EB', authors:['中华人民共和国教育部'],
  title:'高等学校人工智能创新行动计划',
  url:'http://www.moe.gov.cn/srcsite/A16/',
  updateDate:'2018-04-10', citeDate:'2023-09-15',
  year:2018, index:7, isChinese:true }

style = 'numeric'
  

  






  
场景 6：国家标准

  

data = { type:'S', authors:['全国信息与文献标准化技术委员会'],
  standardCode:'GB/T 7714-2015',
  title:'信息与文献 参考文献著录规则',
  publisherPlace:'北京', publisher:'中国标准出版社', year:2015,
  index:2, isChinese:true }

style = 'numeric'
  

  





五、常见错误与排查



  
现象原因处理

  
抛出 "year 超出合理范围"year 不在 1000 至当前年份之间检查是否误传了字符串 "2023年"，应传数字 2023

  
抛出 "authors 不能为空"authors 为 null/undefined/[]至少提供 1 位作者。责任者确实缺失时应按国标用"佚名"或题名起款，本工具暂不支持，需查标准原文 8.1.2 节

  
英文作者姓名顺序反了输入时写成了 "John Smith"应写为 "Smith J"（姓在前，名缩写）。工具不会自动识别姓名顺序

  
顺序编码制缺少序号未传 index 字段style='numeric' 时 index 必填且为正整数

  
电子资源引用日期缺失未传 citeDateGB/T 7714-2015 要求联机资源必须著录引用日期

  
作者超过 3 人但显示不全这是预期行为国标规定第一责任者超过 3 人时只著录前 3 人，后加", 等"或", et al"





六、局限性说明


本工具为轻量级实现，以下能力不具备，使用者需知悉：


    
  
  1. 不支持析出文献：即专著中的析出篇章（如会议论文集中的一篇、文集中的某一章节）的著录格式（GB/T 7714-2015 中 8.2 节）未实现。
    2. 
  
  2. 不支持连续出版物的"年卷期"复杂组合：如无卷号只有期号、无期号只有年月等情况，需调用方自行补齐字段。
    3. 
  
  3. 不支持 DOI 著录：GB/T 7714-2015 允许著录 DOI，但本工具未实现。
    4. 
  
  4. 不支持多语种同一责任者的并列题名：如中英文并列题名。
    5. 
  
  5. 不自动识别作者姓名顺序：英文作者必须由调用方按"姓 名缩写"格式传入。
    6. 
  
  6. 不做文献真实性校验：工具只负责格式化，不验证 ISBN、ISSN、URL 是否真实存在。
    7. 
  
  7. 不支持专利[P]、报告[R]、档案[A]、古籍[M]等其他类型：仅实现 M/J/D/N/EB/S 六种。
    8. 
  
  8. 标点细节可能因期刊要求而异：部分期刊在国标基础上有自己的微调（如页码连接符用 "-" 还是 "~"），本工具统一使用国标示例中的 "-"。
    9. 



如需上述未支持功能，建议直接查阅 GB/T 7714-2015 标准原文，或联系目标期刊的投稿指南。
