📖 公式说明

1. 基本参数

有效厚度：he = 0.7 × hf 有效长度：lw = l − 2 × hf（扣除起弧、灭弧缺陷）

2. 正面角焊缝（力垂直于焊缝长度方向）

σf = N / (he × lw) = N / (0.7 × hf × lw) 验算条件：σf ≤ βf × ffw

其中 βf 为正面角焊缝强度增大系数：
· 承受静力荷载或间接动力荷载：βf = 1.22
· 直接承受动力荷载：βf = 1.0

3. 侧面角焊缝（力平行于焊缝长度方向）

τf = N / (he × lw) = N / (0.7 × hf × lw) 验算条件：τf ≤ ffw

4. 组合受力验算

√((σf / βf)² + τf²) ≤ ffw

其中 σf 为垂直于焊缝长度方向的正应力，τf 为平行于焊缝长度方向的剪应力。

⚠️ 注意：lw 不应小于 8hf 且不应小于 40mm；hf 应满足最小及最大焊脚尺寸要求（详见 GB 50017 第 11.3.5 条）。本工具不自动校验构造要求，请自行核查。
📚 数据来源
  1. GB 50017-2017《钢结构设计标准》—— 第 11 章"连接"，第 11.2 节"焊缝连接"。角焊缝强度计算公式（第 11.2.2 条）、正面角焊缝强度增大系数 βf 取值、角焊缝设计强度 ffw 取值（第 4.4.5 条 表 4.4.5）均依据该标准。
  2. 有效厚度 he = 0.7hf：适用于直角角焊缝（等焊脚），依据 GB 50017-2017 第 11.2.1 条。
  3. 有效长度 lw = l − 2hf：每条焊缝扣除起弧和灭弧各 hf 长度的缺陷段，依据 GB 50017-2017 第 11.2.3 条。
  4. ffw 取值：Q235 配 E43 型焊条 → ffw = 160 N/mm²；Q345 配 E50 型焊条 → ffw = 200 N/mm²；Q390 配 E55 型焊条 → ffw = 200 N/mm²；Q420 配 E55 型焊条 → ffw = 210 N/mm²。具体数值以 GB 50017-2017 表 4.4.5 为准。
  5. βf 取值：正面角焊缝在静力或间接动力荷载下 βf = 1.22，直接动力荷载下 βf = 1.0，依据 GB 50017-2017 第 11.2.2 条。
⚠️ 本工具仅提供强度验算计算，不涵盖构造要求（最小/最大焊脚尺寸、最小/最大焊缝长度等）的自动校核。设计时请同时满足 GB 50017-2017 第 11.3 节的构造规定。具体表值请以标准原文为准。
