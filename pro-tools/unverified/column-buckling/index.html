📚 数据来源

  • 欧拉临界力公式 Pcr = π²EI / (μL)²，长细比 λ = μL / i，临界应力 σcr = π²E / λ²，均出自经典《材料力学》教材（如刘鸿文《材料力学》、孙训芳《材料力学》、Hibbeler《Mechanics of Materials》）中的压杆稳定章节。
  • 四种典型支承的长度系数 μ = 1.0 / 2.0 / 0.5 / 0.7 为材料力学教材中的标准理论值。
  • 惯性半径 i = √(I/A)；临界长细比 λp = π√(E/σp)，欧拉公式仅适用于 λ ≥ λp 的大柔度杆（弹性失稳）。
  • 钢结构设计中 μ 的取值还可参考 GB 50017《钢结构设计标准》中关于计算长度的相关规定；本工具采用理论值，工程设计请以现行规范为准。
  • 中柔度、小柔度杆的临界应力需采用经验公式（如直线公式、抛物线公式）或查稳定系数表，本工具不涵盖。
