⚡ UPS 后备时间计算工具

基于电池容量、负载功率与放电倍率修正的后备时间估算

UPS 输出端所带负载的总有功功率
铅酸电池通常为 12V，锂电单体常见 3.2V / 3.6V / 3.7V
串联提升电压，并联提升容量（本工具按串联计）
通常以 20 小时率标定，例如 12V100Ah
典型值 0.85~0.95，在线式 UPS 常取 0.9
铅酸电池 1.1~1.3，锂电接近 1.0。k=1 表示无倍率修正
电池容量标定的放电时长，铅酸通常为 20h 或 10h
