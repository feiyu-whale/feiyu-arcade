基坑放坡计算工具

依据 GB 50497《建筑基坑工程监测技术标准》、JGJ 120《建筑基坑支护技术规程》

第一部分 · 核心算法源码 
/**
 * ============================================================
 *  基坑放坡计算核心模块
 *  依据：GB 50497《建筑基坑工程监测技术标准》
 *        JGJ 120《建筑基坑支护技术规程》
 *        GB 50300《建筑地基基础工程施工质量验收标准》
 *  说明：本模块为纯函数实现，无外部依赖，可在浏览器直接运行。
 *        所有放坡系数、支护选型建议均为工程经验参考值，
 *        实际工程须以勘察报告与标准原文为准。
 * ============================================================
 */

/**
 * 土质分类枚举（与 GB 50497、JGJ 120 常用分类对齐）
 * @readonly
 * @enum {string}
 */
const SOIL_TYPE = Object.freeze({
  HARD_CLAY:       'hard_clay',        // 坚硬黏土
  HARD_PLASTIC:    'hard_plastic',     // 硬塑粉质黏土 / 黏土
  PLASTIC:         'plastic',          // 可塑粉质黏土
  SOFT_PLASTIC:    'soft_plastic',     // 软塑黏土
  DENSE_SAND:      'dense_sand',       // 密实砂土、碎石类土
  MEDIUM_SAND:     'medium_sand',      // 中密砂土
  LOOSE_SAND:      'loose_sand',       // 松散砂土
  SOFT_SOIL:       'soft_soil',       // 淤泥、软土
  ROCK:            'rock'              // 岩石（微风化 / 中风化）
});

/**
 * 放坡系数参考表（高宽比 1:m 中的 m 值范围）
 * 说明：表中数值为工程经验参考区间，源自 JGJ 120 及行业通用做法，
 *       具体取值须结合现场勘察、地下水、荷载等条件，查标准原文确定。
 * @type {Object.<string, {min:number, max:number, desc:string}>}}
 */
const SLOPE_COEFFICIENT_TABLE = Object.freeze({
  [SOIL_TYPE.HARD_CLAY]:     { min: 0.25, max: 0.33, desc: '坚硬黏土，整体性好' },
  [SOIL_TYPE.HARD_PLASTIC]:  { min: 0.33, max: 0.50, desc: '硬塑粉质黏土 / 黏土' },
  [SOIL_TYPE.PLASTIC]:       { min: 0.50, max: 0.75, desc: '可塑粉质黏土' },
  [SOIL_TYPE.SOFT_PLASTIC]:  { min: 0.75, max: 1.00, desc: '软塑黏土' },
  [SOIL_TYPE.DENSE_SAND]:    { min: 0.50, max: 0.75, desc: '密实砂土、碎石类土' },
  [SOIL_TYPE.MEDIUM_SAND]:   { min: 0.75, max: 1.00, desc: '中密砂土' },
  [SOIL_TYPE.LOOSE_SAND]:    { min: 1.00, max: 1.50, desc: '松散砂土' },
  [SOIL_TYPE.SOFT_SOIL]:     { min: 1.25, max: 1.75, desc: '淤泥、软土（需特殊处理）' },
  [SOIL_TYPE.ROCK]:          { min: 0.10, max: 0.25, desc: '微风化 / 中风化岩石' }
});

/**
 * 根据土质类型获取放坡系数参考区间
 *
 * @param {string} soilType - 土质类型，取值见 SOIL_TYPE 枚举
 * @returns {{min:number, max:number, desc:string}} 放坡系数区间（1:m 中的 m）
 * @throws {Error} 当 soilType 非法时抛出
 *
 * @example
 *   getSlopeCoefficient('hard_clay');
 *   // => { min: 0.25, max: 0.33, desc: '坚硬黏土，整体性好' }
 */
function getSlopeCoefficient(soilType) {
  if (typeof soilType !== 'string' || soilType.trim() === '') {
    throw new Error('参数 soilType 必须为非空字符串');
  }
  const entry = SLOPE_COEFFICIENT_TABLE[soilType];
  if (!entry) {
    throw new Error('未识别的土质类型：' + soilType + '，请参考 SOIL_TYPE 枚举');
  }
  return { min: entry.min, max: entry.max, desc: entry.desc };
}

/**
 * 根据深度与放坡系数计算单侧水平放坡宽度
 * 公式：b = m × H
 *
 * @param {number} depth       - 基坑开挖深度 H（m），必须 > 0
 * @param {number} coefficient - 放坡系数 m（1:m 中的 m），必须 > 0
 * @returns {number} 单侧水平放坡宽度（m）
 * @throws {Error} 参数非法时抛出
 */
function calculateSlopeWidth(depth, coefficient) {
  if (typeof depth !== 'number' || !isFinite(depth) || depth <= 0) {
    throw new Error('depth 必须为有限正数');
  }
  if (typeof coefficient !== 'number' || !isFinite(coefficient) || coefficient <= 0) {
    throw new Error('coefficient 必须为有限正数');
  }
  return depth * coefficient;
}

/**
 * 计算放坡后基坑顶部平面尺寸（矩形基坑）
 * 公式：L_top = L_bottom + 2·m·H
 *       W_top = W_bottom + 2·m·H
 *
 * @param {number} bottomLength - 基坑底部长边（m），必须 > 0
 * @param {number} bottomWidth  - 基坑底部短边（m），必须 > 0
 * @param {number} depth        - 开挖深度（m），必须 > 0
 * @param {number} coefficient  - 放坡系数 m，必须 > 0
 * @returns {{topLength:number, topWidth:number, slopeWidth:number}}
 */
function calculateTopDimensions(bottomLength, bottomWidth, depth, coefficient) {
  [bottomLength, bottomWidth, depth, coefficient].forEach(function (v, i) {
    if (typeof v !== 'number' || !isFinite(v) || v <= 0) {
      throw new Error('第 ' + (i + 1) + ' 个参数必须为有限正数');
    }
  });
  var slopeWidth = depth * coefficient;
  return {
    topLength:  bottomLength + 2 * slopeWidth,
    topWidth:   bottomWidth  + 2 * slopeWidth,
    slopeWidth: slopeWidth
  };
}

/**
 * 计算矩形基坑放坡开挖的土方量（棱台公式）
 * 公式：V = H/6 × [S_bottom + S_top + 4·S_mid]
 * 其中：
 *   S_bottom = A × B
 *   S_top    = (A + 2mH) × (B + 2mH)
 *   S_mid    = (A + mH)  × (B + mH)
 *
 * @param {number} A - 基坑底部长边（m），必须 > 0
 * @param {number} B - 基坑底部短边（m），必须 > 0
 * @param {number} H - 开挖深度（m），必须 > 0
 * @param {number} m - 放坡系数，必须 > 0
 * @returns {{volume:number, bottomArea:number, topArea:number, midArea:number}}
 *          体积单位 m³，面积单位 m²
 */
function calculateExcavationVolume(A, B, H, m) {
  [A, B, H, m].forEach(function (v, i) {
    if (typeof v !== 'number' || !isFinite(v) || v <= 0) {
      throw new Error('第 ' + (i + 1) + ' 个参数必须为有限正数');
    }
  });
  var slopeWidth = m * H;
  var topA = A + 2 * slopeWidth;
  var topB = B + 2 * slopeWidth;
  var midA = A + slopeWidth;
  var midB = B + slopeWidth;

  var S_bottom = A * B;
  var S_top    = topA * topB;
  var S_mid    = midA * midB;

  var volume = (H / 6) * (S_bottom + S_top + 4 * S_mid);
  return {
    volume:     volume,
    bottomArea: S_bottom,
    topArea:    S_top,
    midArea:    S_mid
  };
}

/**
 * 基坑安全等级划分（依据 GB 50497 第 3.1.3 条原则）
 * 注：实际等级须结合破坏后果、周边环境综合判定，此处仅按深度给出初步参考。
 *
 * @param {number} depth - 基坑深度（m）
 * @returns {{level:number, label:string, note:string}}
 */
function classifyPitLevel(depth) {
  if (typeof depth !== 'number' || !isFinite(depth) || depth <= 0) {
    throw new Error('depth 必须为有限正数');
  }
  if (depth > 10) {
    return { level: 1, label: '一级', note: '深度 > 10m，或周边环境复杂' };
  }
  if (depth >= 7) {
    return { level: 2, label: '二级', note: '深度 7~10m' };
  }
  return { level: 3, label: '三级', note: '深度 < 7m，环境简单' };
}

/**
 * 根据基坑条件推荐支护方式（参考 JGJ 120 选型原则）
 * 说明：本函数仅给出初步建议，最终方案须由注册岩土工程师结合勘察、
 *       周边环境、地下水等条件确定。
 *
 * @param {Object} params
 * @param {number} params.depth          - 基坑深度（m）
 * @param {string} params.soilType       - 土质类型（SOIL_TYPE）
 * @param {boolean} [params.hasGroundwater=false] - 是否存在地下水
 * @param {boolean} [params.complexEnv=false]     - 周边环境是否复杂（邻近建筑/管线）
 * @param {boolean} [params.allowSlope=true]      - 场地是否允许放坡
 * @returns {{methods:Array<{name:string, applicable:string, note:string}>, level:Object}}
 */
function selectSupportMethod(params) {
  if (!params || typeof params !== 'object') {
    throw new Error('params 必须为对象');
  }
  var depth = params.depth;
  var soilType = params.soilType;
  var hasGroundwater = !!params.hasGroundwater;
  var complexEnv = !!params.complexEnv;
  var allowSlope = params.allowSlope !== false;

  if (typeof depth !== 'number' || !isFinite(depth) || depth <= 0) {
    throw new Error('depth 必须为有限正数');
  }
  if (!SLOPE_COEFFICIENT_TABLE[soilType]) {
    throw new Error('未识别的土质类型：' + soilType);
  }

  var level = classifyPitLevel(depth);
  var methods = [];

  // 软土 / 松散砂土：一般不推荐纯放坡
  var isWeakSoil = (soilType === SOIL_TYPE.SOFT_SOIL || soilType === SOIL_TYPE.LOOSE_SAND);

  if (allowSlope && !isWeakSoil && depth <= 5 && !complexEnv && !hasGroundwater) {
    methods.push({
      name: '放坡开挖',
      applicable: '场地开阔、土质较好、深度较浅',
      note: '经济性好，但须保证坡顶无堆载、无邻近建筑'
    });
  }

  if (depth <= 6 && !isWeakSoil && !complexEnv) {
    methods.push({
      name: '土钉墙',
      applicable: '深度 ≤ 6m，非软土、非高水位',
      note: '造价较低，施工快；软土、高水位地区慎用'
    });
  }

  if (depth <= 8 && !complexEnv) {
    methods.push({
      name: '水泥土重力式挡墙',
      applicable: '深度 ≤ 8m，软土地区常用',
      note: '整体性好，抗渗性较好；宽度较大，占地多'
    });
  }

  if (depth >= 5 && depth <= 12) {
    methods.push({
      name: '排桩（悬臂 / 桩锚）',
      applicable: '深度 5~12m，适用多数土层',
      note: '刚度大、变形可控；造价较高'
    });
  }

  if (depth > 10 || complexEnv || hasGroundwater) {
    methods.push({
      name: '地下连续墙',
      applicable: '深度 > 10m，或周边环境复杂、高水位',
      note: '刚度大、止水好；造价最高，施工周期长'
    });
  }

  if (depth > 8 && !complexEnv) {
    methods.push({
      name: 'SMW 工法桩（型钢水泥土搅拌墙）',
      applicable: '深度 8~15m，软土地区',
      note: '兼具挡土与止水，型钢可回收'
    });
  }

  if (methods.length === 0) {
    methods.push({
      name: '需专项论证',
      applicable: '当前条件组合较复杂',
      note: '建议由注册岩土工程师进行专项设计'
    });
  }

  return { methods: methods, level: level };
}

/**
 * 估算放坡开挖的坡面面积（单侧矩形坡面）
 * 公式：S = L × √(H² + b²)，其中 b = m·H
 *
 * @param {number} length - 坡面沿基坑边方向长度（m）
 * @param {number} depth  - 深度（m）
 * @param {number} m      - 放坡系数
 * @returns {number} 坡面面积（m²）
 */
function calculateSlopeSurfaceArea(length, depth, m) {
  [length, depth, m].forEach(function (v, i) {
    if (typeof v !== 'number' || !isFinite(v) || v <= 0) {
      throw new Error('第 ' + (i + 1) + ' 个参数必须为有限正数');
    }
  });
  var b = m * depth;
  return length * Math.sqrt(depth * depth + b * b);
}

/**
 * 计算放坡开挖土方量并给出合理误差范围
 * 说明：由于土体松散系数、超挖、边坡修整等因素，
 *       实际土方量与理论值存在偏差，本函数返回 ±5%~10% 的参考区间。
 *
 * @param {number} A - 底部长边（m）
 * @param {number} B - 底部短边（m）
 * @param {number} H - 深度（m）
 * @param {number} m - 放坡系数
 * @returns {{volume:number, rangeMin:number, rangeMax:number, note:string}}
 */
function calculateVolumeWithTolerance(A, B, H, m) {
  var result = calculateExcavationVolume(A, B, H, m);
  var v = result.volume;
  // 工程经验：考虑超挖、土体松散、边坡修整等，误差约 ±8%
  return {
    volume:   v,
    rangeMin: v * 0.92,
    rangeMax: v * 1.08,
    note: '理论值 ±8%（考虑超挖、松散、修整等施工因素）'
  };
}

// ---------- 简易断言工具 ----------
var _passed = 0, _failed = 0, _total = 0, _log = [];

function assert(condition, msg) {
  _total++;
  if (condition) {
    _passed++;
    _log.push('  ✓ ' + msg);
  } else {
    _failed++;
    _log.push('  ✗ ' + msg);
  }
}

function assertEq(actual, expected, msg, tol) {
  tol = tol || 1e-9;
  var ok = Math.abs(actual - expected) < tol;
  assert(ok, msg + ' （期望 ' + expected + '，实际 ' + actual + '）');
}

function assertThrows(fn, msg) {
  var threw = false;
  try { fn(); } catch (e) { threw = true; }
  assert(threw, msg);
}

// ---------- 1. getSlopeCoefficient ----------
(function () {
  var r1 = getSlopeCoefficient('hard_clay');
  assertEq(r1.min, 0.25, '坚硬黏土 min=0.25');
  assertEq(r1.max, 0.33, '坚硬黏土 max=0.33');

  var r2 = getSlopeCoefficient('soft_soil');
  assertEq(r2.min, 1.25, '软土 min=1.25');
  assertEq(r2.max, 1.75, '软土 max=1.75');

  var r3 = getSlopeCoefficient('rock');
  assertEq(r3.min, 0.10, '岩石 min=0.10');

  assertThrows(function () { getSlopeCoefficient('unknown'); },
    '非法土质类型抛错');
  assertThrows(function () { getSlopeCoefficient(''); },
    '空字符串抛错');
  assertThrows(function () { getSlopeCoefficient(null); },
    'null 抛错');
  assertThrows(function () { getSlopeCoefficient(123); },
    '非字符串抛错');
})();

// ---------- 2. calculateSlopeWidth ----------
(function () {
  assertEq(calculateSlopeWidth(5, 0.5), 2.5, '深度5、系数0.5 → 宽2.5');
  assertEq(calculateSlopeWidth(10, 1.0), 10, '深度10、系数1.0 → 宽10');
  assertEq(calculateSlopeWidth(0.1, 0.3), 0.03, '小深度边界');
  assertEq(calculateSlopeWidth(100, 2), 200, '大深度边界');

  assertThrows(function () { calculateSlopeWidth(0, 0.5); },
    '深度为 0 抛错');
  assertThrows(function () { calculateSlopeWidth(-1, 0.5); },
    '深度为负抛错');
  assertThrows(function () { calculateSlopeWidth(5, 0); },
    '系数为 0 抛错');
  assertThrows(function () { calculateSlopeWidth(5, -0.5); },
    '系数为负抛错');
  assertThrows(function () { calculateSlopeWidth(Infinity, 0.5); },
    '深度为 Infinity 抛错');
})();

// ---------- 3. calculateTopDimensions ----------
(function () {
  var r = calculateTopDimensions(10, 6, 5, 0.5);
  assertEq(r.topLength, 15, '顶部长边 = 10 + 2×0.5×5 = 15');
  assertEq(r.topWidth,  11, '顶部短边 = 6 + 2×0.5×5 = 11');
  assertEq(r.slopeWidth, 2.5, '单侧放坡宽 2.5');

  assertThrows(function () { calculateTopDimensions(0, 6, 5, 0.5); },
    '底部长边为 0 抛错');
  assertThrows(function () { calculateTopDimensions(10, 6, 5, -0.1); },
    '系数为负抛错');
})();

// ---------- 4. calculateExcavationVolume ----------
(function () {
  // 验证：A=10, B=6, H=5, m=0.5
  // slopeWidth = 2.5
  // topA = 15, topB = 11
  // midA = 12.5, midB = 8.5
  // S_bottom = 60, S_top = 165, S_mid = 106.25
  // V = 5/6 × (60 + 165 + 4×106.25) = 5/6 × 650 = 541.666...
  var r = calculateExcavationVolume(10, 6, 5, 0.5);
  assertEq(r.bottomArea, 60, '底面积 60');
  assertEq(r.topArea, 165, '顶面积 165');
  assertEq(r.midArea, 106.25, '中截面面积 106.25');
  assertEq(r.volume, 541.6666666666666, '体积 ≈ 541.67', 1e-6);

  // 当 m=0 时退化为长方体（但 m 必须 >0，故用极小值近似）
  var r2 = calculateExcavationVolume(10, 6, 5, 0.0001);
  assertEq(r2.volume, 300, 'm→0 时体积趋近 A×B×H=300', 0.5);

  // 精度：大数相乘
  var r3 = calculateExcavationVolume(100, 80, 20, 1);
  // slopeWidth=20, topA=140, topB=120, midA=120, midB=100
  // S_b=8000, S_t=16800, S_m=12000
  // V = 20/6 × (8000 + 16800 + 48000) = 20/6 × 72800 = 242666.666...
  assertEq(r3.volume, 242666.66666666666, '大尺寸体积精度', 1e-3);

  assertThrows(function () { calculateExcavationVolume(0, 6, 5, 0.5); },
    'A=0 抛错');
  assertThrows(function () { calculateExcavationVolume(10, 6, 0, 0.5); },
    'H=0 抛错');
  assertThrows(function () { calculateExcavationVolume(10, 6, 5, NaN); },
    'm=NaN 抛错');
})();

// ---------- 6. selectSupportMethod ----------
(function () {
  // 场景 1：浅基坑、好土、无地下水、环境简单 → 放坡 + 土钉墙
  var r1 = selectSupportMethod({
    depth: 4, soilType: 'hard_plastic',
    hasGroundwater: false, complexEnv: false, allowSlope: true
  });
  var names1 = r1.methods.map(function (m) { return m.name; });
  assert(names1.indexOf('放坡开挖') >= 0, '浅基坑推荐放坡');
  assert(names1.indexOf('土钉墙') >= 0, '浅基坑推荐土钉墙');
  assertEq(r1.level.level, 3, '浅基坑等级三级');

  // 场景 2：深基坑、复杂环境 → 地下连续墙
  var r2 = selectSupportMethod({
    depth: 15, soilType: 'soft_soil',
    hasGroundwater: true, complexEnv: true, allowSlope: false
  });
  var names2 = r2.methods.map(function (m) { return m.name; });
  assert(names2.indexOf('地下连续墙') >= 0, '深基坑+复杂环境推荐地下连续墙');
  assert(names2.indexOf('放坡开挖') === -1, '不允许放坡时不推荐放坡');
  assertEq(r2.level.level, 1, '深基坑等级一级');

  // 场景 3：软土浅基坑 → 不推荐放坡
  var r3 = selectSupportMethod({
    depth: 3, soilType: 'soft_soil',
    hasGroundwater: false, complexEnv: false, allowSlope: true
  });
  var names3 = r3.methods.map(function (m) { return m.name; });

一、工具用途

本工具面向土木工程施工技术人员、造价人员、监理人员及注册岩土工程师，提供基坑放坡相关的三项基础计算：

  1. 放坡系数查询：根据土质类别给出 1:m 中 m 值的参考区间；
  2. 开挖土方量计算：基于矩形基坑棱台公式，计算放坡开挖的理论土方量，并给出合理误差范围；
  3. 支护方式选型建议：根据基坑深度、土质、地下水、周边环境等条件，给出初步支护方案推荐。

本工具适用于方案阶段、投标估算、施工组织的初步测算，不能替代正式的基坑支护设计文件。正式工程须由具备相应资质的单位出具专项设计，并经专家论证（一级基坑）。

二、参数详解

2.1 放坡系数 m

放坡系数定义为基坑边坡高度 H 与水平投影宽度 b 之比，即 1:m = H:b，因此 b = m × H。m 值越大，边坡越缓，占地越多但越安全；m 值越小，边坡越陡，占地少但稳定性差。

土质类别m 参考区间说明
坚硬黏土0.25 ~ 0.33整体性好，可较陡
硬塑粉质黏土 / 黏土0.33 ~ 0.50常见一般黏性土
可塑粉质黏土0.50 ~ 0.75中等塑性
软塑黏土0.75 ~ 1.00含水量较高
密实砂土、碎石类土0.50 ~ 0.75内摩擦角较大
中密砂土0.75 ~ 1.00—
松散砂土1.00 ~ 1.50易坍塌
淤泥、软土1.25 ~ 1.75一般不推荐纯放坡
微风化 / 中风化岩石0.10 ~ 0.25可近直立
⚠ 上表为工程经验参考值，具体取值须结合现场勘察报告、地下水位、坡顶荷载、开挖暴露时间等因素，查 JGJ 120、GB 50497 等标准原文确定。

2.2 开挖土方量参数

  • A、B：基坑底部长边、短边（m），指结构外墙（含工作面）外轮廓尺寸；
  • H：开挖深度（m），自自然地面算至坑底；
  • m：放坡系数。

计算公式采用棱台体积公式：

V = H/6 × [S底 + S顶 + 4·S中]

其中 S底 = A×B，S顶 = (A+2mH)×(B+2mH)，S中 = (A+mH)×(B+mH)。

2.3 支护选型参数

  • 基坑深度：决定安全等级（GB 50497 第 3.1.3 条：>10m 或环境复杂为一级，7~10m 为二级，<7m 且环境简单为三级）；
  • 土质类型：软土、松散砂土一般不推荐纯放坡；
  • 地下水：高水位地区须考虑止水帷幕；
  • 周边环境：邻近建筑、重要管线时优先选用刚度大、变形小的支护形式；
  • 场地条件：是否允许放坡（红线、邻近建筑距离）。

三、使用场景（5 例）

场景 1：住宅小区地下室浅基坑

条件：深度 4m，硬塑粉质黏土，场地开阔无邻近建筑，无地下水。

操作：土质选「硬塑粉质黏土」→ m 取 0.5；底边 30×20m → 顶边 34×24m；体积约 3200 m³；推荐放坡开挖 + 土钉墙备选。

场景 2：城市地铁车站深基坑

条件：深度 16m，软土地区，高水位，紧邻既有建筑与市政管线。

操作：安全等级一级；推荐地下连续墙 + 内支撑，或排桩 + 止水帷幕；放坡开挖不适用。

场景 3：山区公路挡墙基坑

条件：深度 3m，中风化岩石，场地受限。

操作：岩石 m 可取 0.1~0.25，近乎直立开挖；体积较小；一般无需专门支护，必要时喷锚。

场景 4：沿海工业区管廊基坑

条件：深度 6m，中密砂土，地下水位较高，周边有管线。

操作：m 取 1.0 左右；推荐 SMW 工法桩或排桩 + 止水帷幕；放坡开挖风险较大。

场景 5：投标阶段快速估算

条件：仅知深度 8m、底边 40×25m、土质为可塑粉质黏土。

操作：m 取 0.6 → 体积约 7000 m³（±8%）；用于投标土方量报价参考，最终按实结算。

四、常见错误

  1. 混淆 m 与坡度：m 是高宽比 1:m 中的 m，不是坡度百分比；
  2. 忽略工作面：底边 A、B 应含结构外墙 + 工作面（一般每边 0.6~1.0m），而非结构净尺寸；
  3. 用长方体公式估算放坡基坑：放坡后为棱台，体积明显大于 A×B×H；
  4. 软土地区盲目放坡：淤泥、软塑黏土放坡极易滑坡，须专项论证；
  5. 忽视地下水：高水位地区放坡须配合降水或止水，否则边坡失稳；
  6. 坡顶堆载：坡顶 1~2m 范围内严禁堆载，否则显著降低稳定性；
  7. 将本工具结果作为施工图依据：本工具仅用于初步测算，正式工程须专项设计。

六、精度与误差说明（有限精准原则）

现实工程中的变量是无限的（土体非均质、地下水动态变化、施工偏差、荷载不确定性……），本工具遵循「方法准、输入项准、结果给误差范围」的原则，不承诺绝对精确。

6.1 算准了什么

  • 几何计算部分（放坡宽度、顶面尺寸、棱台体积）在输入参数准确的前提下，数学上是精确的（浮点误差 < 1e-10）；
  • 放坡系数区间、支护选型建议符合 JGJ 120、GB 50497 的通用原则。

6.2 哪些因素没算进去

  • 土体实际非均质性、夹层、裂隙；
  • 地下水位动态、渗流力；
  • 坡顶实际荷载（施工机械、堆载、邻近建筑）；
  • 开挖顺序、暴露时间、雨季影响；
  • 施工超挖、边坡修整偏差；
  • 土体松散系数（挖方与实方的差异）；
  • 地震、爆破等动力荷载。

6.3 误差大概多大

  • 土方量：理论值 ±8% 为合理施工误差范围（考虑超挖、松散、修整）；
  • 放坡系数：表中区间本身即为参考范围，实际取值须由勘察确定，偏差可能超过 ±20%；
  • 支护选型：仅为初步建议，最终方案须专项设计，不可直接作为施工图依据。
⚠ 本工具不承诺「精确计算」「绝对准确」「100% 无误」。所有结果仅供初步测算参考，正式工程须由具备资质的单位出具专项设计文件。

七、局限性

  1. 仅支持矩形基坑，异形基坑（圆形、多边形、阶梯断面）不适用；
  2. 未考虑分层开挖、多级放坡、平台设置；
  3. 未进行边坡稳定性验算（须用瑞典圆弧法、Bishop 法等）；
  4. 未考虑降水、止水帷幕设计；
  5. 未进行内力变形计算（须用理正、PLAXIS、MIDAS 等专业软件）；
  6. 土质分类较粗，无法替代详细勘察报告；
  7. 本工具为辅助测算工具，不能替代注册岩土工程师的专项设计。

八、结语

基坑工程是土木工程中风险最高的分部工程之一，「十次事故九次基坑」。本工具旨在帮助技术人员在方案阶段快速形成合理估算，减少低级计算错误，但绝不能替代勘察、设计、论证、监测等完整的技术流程。使用者应始终牢记：计算只是手段，安全才是目的。
