📚 数据来源
  • 流量公式 Q = v·A，A = πd²/4：连续性方程，见《工程流体力学》（闻德荪 主编，高等教育出版社）。
  • 雷诺数 Re = vd/ν： Osborne Reynolds 经典定义，临界值 Recr≈2000（层流）、Re≥4000（湍流），过渡区 2000~4000。
  • 层流沿程阻力系数 λ = 64/Re：圆管层流 Hagen-Poiseuille 流动理论解。
  • 湍流沿程阻力系数：Colebrook-White 公式（1939），
    1/√λ = -2·lg[ε/(3.7d) + 2.51/(Re·√λ)]，
    参见 C.F. Colebrook, "Turbulent flow in pipes, with particular reference to the transition region between the smooth and rough pipe laws", Journal of the ICE, 1939。
  • 沿程水头损失 hf = λ·(L/d)·v²/(2g)：Darcy-Weisbach 公式。
  • 水的运动粘度：数据取自《工程流体力学》教材附录及 CRC Handbook of Chemistry and Physics 中水的物性表（1 atm）。
  • 重力加速度 g = 9.81 m/s²（标准值）。
  • 管壁粗糙度参考值：新钢管 ε≈0.045~0.05mm，旧钢管≈0.1~0.2mm，铸铁管≈0.25mm，塑料/玻璃管≈0.001~0.01mm，参见《给水排水设计手册》。
