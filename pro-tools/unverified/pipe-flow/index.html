一、工具简介

        
本工具用于圆形满管压力流体的水力计算，覆盖以下核心问题：

        
    
          
  • 流量-流速-管径互算：基于连续性方程 Q = v·A，A = πd²/4，已知三者之二求第三。
    • 
          
  • 雷诺数 Re：Re = vd/ν，用于判别流态（层流 / 过渡区 / 湍流）。
    • 
          
  • 沿程阻力系数 λ：层流按 λ = 64/Re（Hagen-Poiseuille）；湍流按 Colebrook-White 隐式方程迭代求解，光滑管区亦提供 Blasius 经验公式作为参考。
    • 
          
  • 沿程水头损失 hf：按 Darcy-Weisbach 公式 hf = λ·(L/d)·(v²/2g)。
    • 
          
  • 水的运动粘度 ν：按温度（0~100℃）查表并线性插值，数据源自 IAPWS 推荐值。
    • 
        

        
适用介质：常压清水。适用流态：层流、湍流（过渡区结果仅供参考，工程上通常按湍流处理或避免在该区运行）。

      


      

        
二、参数说明

        

          
参数符号单位取值范围含义

          
管内径dm> 0管道内径。注意：公称直径 DN 不等于内径，需查对应管材标准（如 GB/T 17395、GB/T 13663）。

          
流速vm/s≥ 0断面平均流速。经济流速：生活给水 1.0~1.5 m/s（GB 50015），消防给水 ≤ 2.5 m/s。

          
流量Qm³/s≥ 0体积流量。1 m³/s = 3600 m³/h = 1000 L/s。

          
水温T℃0 ~ 100用于查表得运动粘度 ν。超出范围将抛出异常。

          
管长Lm≥ 0计算沿程损失的直管段长度。

          
绝对粗糙度εmm≥ 0管壁粗糙突起平均高度。新钢管 0.05~0.1 mm；旧钢管 0.5~1.0 mm；塑料管 0.001~0.01 mm；混凝土管 0.3~3.0 mm。

          
运动粘度νm²/s—由水温查表得到，20℃清水约 1.004×10⁻⁶ m²/s。

          
重力加速度gm/s²9.81本工具固定取 9.81 m/s²。

        

      


      

        
三、实际使用场景


        

          
场景 1：已知管径与流速，求流量（住宅给水立管校核）

          
背景：某住宅楼给水立管采用 DN100 镀锌钢管（内径约 0.106 m），设计流速取 1.2 m/s，水温 15℃，校核流量是否满足 12 L/s 的供水需求。

          
输入：d = 0.106 m，v = 1.2 m/s，T = 15℃

          
结果：A = π×0.106²/4 ≈ 0.008825 m²；Q = 1.2 × 0.008825 ≈ 0.01059 m³/s = 10.59 L/s。

          
结论：流量略小于 12 L/s 的设计需求，需提高流速或加大管径。

        


        

          
场景 2：已知流量与管径，求流速及水头损失（消防主管校核）

          
背景：某厂区消防主管 DN150（内径 0.154 m），长度 200 m，设计流量 30 L/s，水温 20℃，管材为使用 5 年的焊接钢管（ε = 0.2 mm），校核流速与沿程水头损失。

          
输入：Q = 0.03 m³/s，d = 0.154 m，L = 200 m，T = 20℃，ε = 0.2 mm

          
结果：v = Q/A ≈ 1.61 m/s；Re ≈ 2.47×10⁵（湍流）；λ ≈ 0.0173（Colebrook）；hf ≈ 5.62 m。

          
结论：流速在消防规范允许范围（≤2.5 m/s）内；沿程损失 5.62 m 需计入水泵扬程。

        


        

          
场景 3：已知流量与流速，反算管径（新建给水管选型）

          
背景：某小区入户总管设计流量 50 m³/h（≈ 0.01389 m³/s），经济流速取 1.2 m/s，求所需管径。

          
输入：Q = 0.01389 m³/s，v = 1.2 m/s

          
结果：d = √(4Q/(πv)) ≈ 0.1208 m = 120.8 mm。

          
结论：向上取标准管径，选 DN125（内径约 0.13 m）或 DN150，实际流速将低于经济流速。

        


        

          
场景 4：高温水系统（采暖供回水 80℃）

          
背景：某采暖系统供水管 DN80（内径 0.08 m），流量 5 m³/h，水温 80℃，管长 50 m，钢管 ε = 0.1 mm，求水头损失。

          
输入：Q = 5/3600 ≈ 0.001389 m³/s，d = 0.08 m，T = 80℃，L = 50 m，ε = 0.1 mm

          
结果：v ≈ 0.276 m/s；ν(80℃) ≈ 3.65×10⁻⁷ m²/s；Re ≈ 6.04×10⁴（湍流）；λ ≈ 0.0201；hf ≈ 0.43 m。

          
结论：高温水粘度低，Re 较大；水头损失较小，循环泵选型可按此估算。

        


        

          
场景 5：层流工况验证（小管径高粘度流体）

          
背景：实验室毛细管 d = 0.002 m，流速 0.05 m/s，水温 5℃（ν ≈ 1.519×10⁻⁶ m²/s），验证层流公式。

          
输入：v = 0.05 m/s，d = 0.002 m，T = 5℃

          
结果：Re = 0.05×0.002/1.519e-6 ≈ 65.8（层流）；λ = 64/Re ≈ 0.972。

          
结论：Re 远小于 2000，确为层流，λ 按 Hagen-Poiseuille 公式计算。

        

      


      

        
四、常见错误与排查

        
    
          
  • 单位错误：最常见。管径必须输入米（m），不是毫米；流量必须输入 m³/s，不是 L/s 或 m³/h。工具内部不做单位换算，请在输入前自行换算。
    • 
          
  • 公称直径 DN 当作内径：DN100 钢管的实际内径因壁厚不同而异（约 100~106 mm），需查 GB/T 17395 或管材样本。
    • 
          
  • 粗糙度单位：本工具粗糙度输入单位为 mm，需转换为 m 参与计算（内部已处理）。
    • 
          
  • 温度超范围：水温必须在 0~100℃ 之间，超出将报错。常压水超过 100℃ 为汽态，本工具不适用。
    • 
          
  • 过渡区（2000 ≤ Re ≤ 4000）：流态不稳定，λ 计算结果仅供参考，工程设计应避免在此区运行。
    • 
          
  • 局部损失未计入：本工具仅计算沿程损失，弯头、阀门、变径等局部损失需按 ζ·v²/(2g) 另行计算并叠加。
    • 
          
  • 非圆形管道：本工具仅适用于圆形满管。矩形风管、非满流排水管需用水力直径 Dh = 4A/P 近似，精度有限。
    • 
        

      


      

        
五、数据来源与标准依据

        
    
          
  • 连续性方程 Q = v·A：质量守恒在不可压缩流体中的表达，任何《流体力学》教科书（如吴望一《流体力学》、张兆顺《湍流》、Frank M. White《Fluid Mechanics》）均有推导。
    • 
          
  • 层流 λ = 64/Re：Hagen-Poiseuille 定律的无量纲形式，理论精确解。
    • 
          
  • Colebrook-White 方程：C.F. Colebrook (1939) 提出的湍流阻力系数隐式方程，被 ISO、ASME、GB 广泛采纳。
    • 
          
  • Blasius 公式 λ = 0.3164/Re^0.25：适用于光滑管 4000 < Re < 10⁵ 的经验公式。
    • 
          
  • Darcy-Weisbach 公式：hf = λ·(L/d)·(v²/2g)，国际通用的沿程损失计算公式。
    • 
          
  • 水的运动粘度查表：数据源自 IAPWS（国际水和水蒸汽性质协会）推荐值，与《传热学》（Incropera）、《流体力学》（Cengel）附录一致。
    • 
          
  • 相关国标：
            
      
              
    • GB 50015-2019《建筑给水排水设计标准》——生活给水经济流速
      • 
              
    • GB 50013-2018《室外给水设计标准》——输配水管网水力计算
      • 
              
    • GB 50974-2014《消防给水及消火栓系统技术规范》——消防管流速限制
      • 
              
    • GB/T 17395-2008《无缝钢管尺寸、外形、重量及允许偏差》——钢管内径查取
      • 
              
    • GB/T 13663-2018《给水用聚乙烯（PE）管材》——PE 管内径查取

六、局限性说明

        
    
          
  • 仅适用于圆形满管压力流：非圆形截面、非满流（如排水重力流）、明渠流不适用。
    • 
          
  • 仅适用于清水：含沙水、污水、油类、高粘度流体的 ν 不同，本工具不提供相应查表。
    • 
          
  • 不计算局部损失：弯头、三通、阀门、变径等局部水头损失需另行计算。
    • 
          
  • 不计算水泵扬程与管网平差：仅做单管段水力计算，复杂管网需用 Hardy-Cross 等方法。
    • 
          
  • 温度范围受限：仅支持 0~100℃ 常压液态水；高温高压水、蒸汽需用水蒸汽物性表。
    • 
          
  • 过渡区结果不可靠：2000 ≤ Re ≤ 4000 区间流态不稳定，λ 计算值仅供参考。
    • 
          
  • 粗糙度取值主观：实际管道粗糙度随使用年限、结垢、腐蚀变化，本工具按输入值计算，不自动修正。
    • 
          
  • 不考虑管道坡度与高程差：位置水头变化需用户自行在伯努利方程中处理。
    • 
          
  • 浮点精度：JavaScript 使用 IEEE 754 双精度，极小/极大数值可能出现舍入误差，工程计算中建议保留 4~6 位有效数字。
    • 
        

        
本工具用于工程估算与教学演示，重要工程设计请以注册工程师签字的计算书为准，并符合现行国家/行业标准。
