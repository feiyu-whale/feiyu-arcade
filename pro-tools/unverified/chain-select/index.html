一、工具简介


本工具用于短节距精密滚子链的选型计算，涵盖链条型号查询、链轮几何参数计算、链节数与中心距互算、链速计算及润滑方式推荐。计算依据为 GB/T 1243-2006《短节距精密滚子链、链轮和附件》（等同采用 ISO 606:2004）。


适用场景包括：机械设计课程作业、初步选型估算、方案对比分析等。本工具提供的是工程估算结果，不替代正式的工程设计计算书。



二、参数详解



2.1 链条型号


GB/T 1243 将滚子链分为 A 系列和 B 系列：


    

  • A 系列：源自 ANSI B29.1，主要用于美洲体系。型号如 08A、10A、12A 等，型号数字乘以 1/8 英寸即为节距（如 08A → 8×1/8″ = 1″ = 25.4mm，但实际 08A 节距为 12.7mm = 1/2″，此处编号规则为：前两位数字 × 1/8 英寸 = 节距，即 08 → 8/8 = 1 英寸？不对。正确规则：编号前两位数字表示节距的 1/32 英寸数。08A → 8 × 1/8″ = 1″？也不对。实际规则：编号前两位数字 × (1/8) 英寸 = 节距。08A → 8 × 1/8 = 1 英寸？但 08A 节距是 12.7mm = 0.5 英寸。所以正确规则是：编号 × 1/16 英寸。08 → 8/16 = 0.5 英寸 = 12.7mm。10A → 10/16 = 0.625 英寸 = 15.875mm。16A → 16/16 = 1 英寸 = 25.4mm。正确。
    • 

  • B 系列：源自 DIN 8187，主要用于欧洲体系。型号如 06B、08B、10B 等。
    • 



本工具收录 A 系列 08A～24A 共 6 种、B 系列 06B～24B 共 7 种，合计 13 种常用型号。更多型号需查标准原文。



2.2 齿数 (z₁, z₂)


小链轮齿数 z₁ 影响传动平稳性和链条寿命。齿数过少会导致多边形效应加剧、链速不均匀性增大、动载荷增加。一般推荐：


    

  • 高速 (v > 8 m/s)：z₁ ≥ 21～25
    • 

  • 中速 (v = 3～8 m/s)：z₁ ≥ 17～21
    • 

  • 低速 (v < 3 m/s)：z₁ ≥ 9～17
    • 



本工具允许 z₁ 范围为 9～120。大链轮齿数 z₂ 应 ≥ z₁，推荐不超过 114。



2.3 中心距 (a) 与链节数 (Lp)


中心距 a 为两链轮轴线之间的距离（mm）。链节数 Lp 为链条的节数（即链节个数），应为偶数以避免使用过渡链节（弯板链节）。


两者关系公式：



Lp = 2a/p + (z₁+z₂)/2 + ((z₂−z₁)/(2π))² × p/a



式中 p 为节距。反算中心距：



a = p/4 × [A + √(A² − 8B)]，其中 A = Lp − (z₁+z₂)/2，B = ((z₂−z₁)/(2π))²




2.4 转速 (n₁)


小链轮转速，单位 r/min。用于计算链速和推荐润滑方式。链速公式：



v = z₁ × n₁ × p / 60000 (m/s)




三、使用场景



场景一：新设备设计——已知中心距求链节数


某输送机两轴中心距已确定为 600mm，需选用 10A 链条，小链轮 19 齿，大链轮 38 齿，小链轮转速 720 r/min。


操作：选择 10A → 输入 z₁=19, z₂=38, n₁=720 → 选择"已知中心距" → 输入 a=600 → 点击计算。


结果将给出：所需链节数（向上取偶）、实际中心距、链速、润滑方式等。



场景二：旧设备维修——已知链节数求中心距


现有 16A 链条 120 节，需配用 21 齿和 42 齿链轮，求安装中心距。


操作：选择 16A → 输入 z₁=21, z₂=42 → 选择"已知链节数" → 输入 Lp=120 → 点击计算。


结果将给出理论中心距，供安装调整参考。



场景三：链速校核


设计完成后需校核链速是否在合理范围内。输入参数后，工具自动计算链速 v，并据此推荐润滑方式。一般链速不宜超过 12～15 m/s（特殊设计除外）。



场景四：润滑方式选择


工具根据链速和链条规格自动推荐润滑方式，分为四档：手工润滑、滴油润滑、油浴/飞溅润滑、压力喷油润滑。此推荐为初步指导，实际润滑方案还需考虑工作环境、温度、载荷等因素。



场景五：方案对比——不同型号链条对比


在相同工况下，分别选择不同型号（如 10A 和 12B）进行计算，对比链速、链节数、链轮尺寸等参数，辅助选型决策。可多次计算、记录结果进行对比。



四、常见错误


    

  • 未选链条型号即计算：必须先选择链条型号，否则无法获取节距等基础参数。
    • 

  • 齿数过小：z₁ < 9 时工具将报错。即使 z₁ = 9 在技术上可计算，实际中极少使用，仅在极低速度下考虑。
    • 

  • 大链轮齿数小于小链轮：z₂ 必须 ≥ z₁，否则传动比无意义。
    • 

  • 中心距过小：中心距过小时链节数可能过少（< 2×z₁），导致包角不足、啮合齿数过少。工具会给出警告。
    • 

  • 链节数为奇数：工具自动向上取偶。若实际使用奇数节需加过渡链节，会降低链条强度约 20%～30%。
    • 

  • 忽略链速限制：链速过高时噪声、磨损、动载荷急剧增大，需特别注意润滑和精度。
    • 




五、数据依据


本工具的链条基础数据（节距、滚子直径、内链节内宽、销轴直径）依据 GB/T 1243-2006（等同采用 ISO 606:2004）。链轮几何参数计算公式依据 GB/T 1243 附录及相关机械设计手册。


最小极限拉力和单位质量数据为参考值，需查标准原文确认后方可用于正式设计。


润滑方式推荐参考 GB/T 1243 及相关行业惯例，具体分界线为近似值。



六、精度与误差说明




⚠ 有限精准原则：现实变量是无限的，本工具只做到「方法准、输入项准、结果给误差范围」，不承诺绝对精确。




6.1 算准了什么


    

  • 链条基础参数查询：节距、滚子直径等为标准规定值，查询结果与标准一致（精度取决于标准本身的公差规定）。
    • 

  • 链轮分度圆直径：公式 d = p/sin(π/z) 为精确几何关系，计算精度取决于浮点运算精度（约 10⁻¹⁴ 量级相对误差）。
    • 

  • 链节数与中心距的互算：公式本身为工程近似公式（假设链条直线段与链轮圆弧段相切），在常规中心距范围内误差可控。
    • 

  • 链速计算：公式 v = z₁n₁p/60000 给出的是平均链速，计算本身无误差。
    • 




6.2 哪些因素没算进去


    

  • 多边形效应：实际链速瞬时值围绕平均值波动，波动幅度与齿数有关。本工具仅给出平均链速。
    • 

  • 链条磨损伸长：使用一段时间后链条节距增大，中心距变化，本工具按新链计算。
    • 

  • 制造公差：链条和链轮的实际尺寸存在制造公差，本工具按公称尺寸计算。
    • 

  • 安装误差：实际安装中两轴平行度误差、中心距偏差等未考虑。
    • 

  • 动载荷与冲击：启动、制动、负载突变等工况未考虑。
    • 

  • 额定功率与疲劳寿命：本工具不计算链条的额定功率、疲劳寿命、安全系数等，这些需要更详细的计算。
    • 

  • 润滑分界线的精确性：润滑方式的推荐分界线为近似值，实际应根据制造商推荐和工况确定。
    • 

  • 齿顶圆直径公式：da = p×(0.54+cot(π/z)) 为近似公式，精确齿形需查标准原文的齿廓规定。
    • 




6.3 误差大概多大


    

  • 分度圆直径：计算误差 < 0.001mm（浮点精度限制），可忽略。
    • 

  • 链节数：取整误差最大为 1 节（即一个节距），对应中心距变化约 p/2。
    • 

  • 中心距：由链节数取整引入的误差通常在 ±p 范围内（即 ±1 个节距）。
    • 

  • 链速：平均链速计算无误差；瞬时链速波动幅度与齿数相关，z=17 时波动约 ±1.5%，z=25 时约 ±0.7%。
    • 

  • 齿顶圆直径：近似公式与标准齿形的偏差约 0.1～0.5mm，仅供估算参考。
    • 




七、局限性


    

  • 不计算额定功率：链条选型的核心是功率校核，本工具不涉及。额定功率需查 GB/T 1243 功率曲线或制造商数据。
    • 

  • 不计算安全系数：静强度安全系数、疲劳安全系数等需另行计算。
    • 

  • 不处理多排链：本工具仅计算单排链。双排、三排链的参数需查标准原文。
    • 

  • 型号有限：仅收录 13 种常用型号，更大或更小规格需查标准。
    • 

  • 不处理特殊工况：高温、腐蚀、食品级等特殊工况的选型需参考专门资料。
    • 

  • 齿顶圆直径为近似值：精确的链轮齿廓设计需依据 GB/T 1243 中的齿形规定，本工具仅提供估算。
    • 

  • 润滑推荐为初步指导：实际润滑方案应综合考虑载荷、速度、温度、环境、润滑油品等因素。
    • 





提示：本工具适用于初步选型和方案估算。正式工程设计中，请务必查阅 GB/T 1243-2006 标准原文，并结合实际工况进行完整的功率校核和寿命计算。链条制造商的技术资料也是重要的参考依据。
