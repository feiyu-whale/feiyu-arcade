📖 公式说明

弹簧刚度：
k = G·d⁴ / (8·D³·n)
切应力（含曲率与直剪修正的简化式）：
τ = (8·F·D) / (π·d³) × (1 + 0.5/c)
旋绕比：
c = D / d
Wahl 精确曲度系数（参考）：
KW = (4c−1)/(4c−4) + 0.615/c
