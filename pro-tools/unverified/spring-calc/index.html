一、工具简介


本工具用于圆柱螺旋压缩弹簧（及拉伸弹簧）的核心力学参数计算，涵盖弹簧刚度（k）和弹簧丝截面切应力（τ）两大关键指标。计算依据为中华人民共和国国家标准 GB/T 23935《圆柱螺旋弹簧设计计算》中给出的基本公式。


在弹簧设计过程中，工程师需要反复校核弹簧的刚度是否满足系统要求，以及在工作载荷下弹簧丝内的切应力是否低于材料的许用切应力。本工具将这两个核心计算封装为纯函数，支持在线交互计算，也提供可复用的 JavaScript 源码供集成到其他系统中。


本工具适用于等截面圆丝圆柱螺旋弹簧的初步设计校核阶段。对于变截面、变节距、非线性特性等特殊弹簧，本工具不适用。



二、公式与参数说明


2.1 弹簧刚度公式


k = G · d⁴ / (8 · D³ · n)




参数符号单位含义典型取值范围


切变模量GMPa (N/mm²)弹簧材料的剪切弹性模量，反映材料抵抗剪切变形的能力碳素弹簧钢丝约 79000～81000；奥氏体不锈钢丝约 69000～71000（需查标准原文确认具体牌号对应值）


钢丝直径dmm弹簧钢丝的公称直径0.2 ～ 60 mm（常见范围，需查标准原文确认系列值）


弹簧中径Dmm弹簧线圈的平均直径，D = D_outer - d = D_inner + d通常 2 ～ 500 mm


有效圈数n—（无量纲）参与弹性变形的弹簧圈数，不含支撑圈通常 3 ～ 30 圈


弹簧刚度kN/mm弹簧产生单位变形量所需的力，即弹簧的"软硬程度"计算结果





2.2 切应力公式


τ = (8 · F · D) / (π · d³) × (1 + 0.5 / c)


c = D / d（弹簧指数，又称旋绕比）




参数符号单位含义典型取值范围


工作载荷FN作用在弹簧上的轴向力根据实际工况确定


弹簧中径Dmm同上同上


钢丝直径dmm同上同上


弹簧指数c—（无量纲）中径与钢丝直径之比，反映弹簧的"卷绕紧密程度"推荐 4 ～ 16，过小制造困难，过大易失稳


切应力τMPa弹簧丝截面上的最大切应力（已考虑曲度修正）计算结果，需与材料许用切应力比较






关于曲度系数：公式中的 (1 + 0.5/c) 是曲度系数的简化近似形式。GB/T 23935 中给出的完整曲度系数（Wahl 修正系数）为 K = (4c-1)/(4c-4) + 0.615/c。当 c ≥ 4 时，简化公式与完整公式的偏差通常在工程可接受范围内（约 2%～5%）。对于 c < 4 的弹簧，建议使用完整 Wahl 公式另行校核。




三、实际使用场景



场景 1：验证现有弹簧刚度是否达标




背景


某振动筛设备需要刚度为 5 N/mm 的减振弹簧。现有弹簧参数：碳素弹簧钢丝，d = 5 mm，D = 50 mm，有效圈数 n = 10。


输入


G = 80000 MPa，d = 5 mm，D = 50 mm，n = 10


计算结果


k = 80000 × 5⁴ / (8 × 50³ × 10) = 80000 × 625 / (8 × 125000 × 10) = 50000000 / 10000000 = 5.000 N/mm


弹簧指数 c = 50/5 = 10，在推荐范围 4～16 内，合理。


结论


该弹簧刚度恰好为 5 N/mm，满足设计要求。





场景 2：校核弹簧强度是否安全




背景


某阀门弹簧在工作时承受 200 N 的载荷，弹簧参数：d = 3 mm，D = 30 mm。材料为碳素弹簧钢丝，许用切应力 [τ] = 600 MPa。


输入


F = 200 N，D = 30 mm，d = 3 mm


计算结果


c = 30/3 = 10


τ = 8 × 200 × 30 / (π × 3³) × (1 + 0.5/10) = 48000 / (π × 27) × 1.05 = 48000 / 84.823 × 1.05 ≈ 565.88 × 1.05 ≈ 594.18 MPa


结论


594.18 MPa < 600 MPa，强度满足要求，但裕量较小（仅约 1%），建议适当增大钢丝直径或减小载荷。





场景 3：反求所需有效圈数




背景


设计目标刚度 k = 3.5 N/mm，已有材料 G = 79000 MPa，钢丝 d = 4 mm，中径 D = 40 mm。问需要多少有效圈数？


计算过程


由 k = Gd⁴/(8D³n) 反推：n = Gd⁴/(8D³k)


n = 79000 × 4⁴ / (8 × 40³ × 3.5) = 79000 × 256 / (8 × 64000 × 3.5) = 20224000 / 1792000 = 11.286 圈


结论


取 n = 11 圈时，k = 79000 × 256 / (8 × 64000 × 11) = 20224000 / 5632000 ≈ 3.591 N/mm；取 n = 12 圈时，k ≈ 3.292 N/mm。可根据实际需要选择，或使用本工具反复试算。





场景 4：不锈钢弹簧的刚度计算




背景


食品机械中使用奥氏体不锈钢弹簧（SUS304），d = 2 mm，D = 20 mm，n = 8，工作载荷 F = 50 N。不锈钢切变模量约 G = 70000 MPa。


输入


G = 70000 MPa，d = 2 mm，D = 20 mm，n = 8，F = 50 N


计算结果


k = 70000 × 2⁴ / (8 × 20³ × 8) = 70000 × 16 / (8 × 8000 × 8) = 1120000 / 512000 = 2.1875 N/mm


c = 20/2 = 10


τ = 8 × 50 × 20 / (π × 2³) × (1 + 0.5/10) = 8000 / (π × 8) × 1.05 = 8000 / 25.133 × 1.05 ≈ 318.31 × 1.05 ≈ 334.23 MPa


结论


不锈钢弹簧刚度约 2.19 N/mm，切应力约 334 MPa。SUS304 弹簧丝许用切应力需查标准原文或材料供应商数据表。





场景 5：大载荷重型弹簧校核




背景


铁路车辆悬挂弹簧，d = 28 mm，D = 180 mm，n = 6，G = 79000 MPa，最大工作载荷 F = 15000 N。


输入


G = 79000 MPa，d = 28 mm，D = 180 mm，n = 6，F = 15000 N


计算结果


k = 79000 × 28⁴ / (8 × 180³ × 6) = 79000 × 614656 / (8 × 5832000 × 6) = 48557824000 / 279936000 ≈ 173.46 N/mm


c = 180/28 ≈ 6.429


τ = 8 × 15000 × 180 / (π × 28³) × (1 + 0.5/6.429) = 21600000 / (π × 21952) × 1.07778 = 21600000 / 68959.64 × 1.07778 ≈ 313.22 × 1.07778 ≈ 337.59 MPa


结论


弹簧指数 c ≈ 6.43，在推荐范围内。刚度约 173.46 N/mm，切应力约 337.59 MPa。需根据具体材料牌号查取许用切应力进行最终判定。





四、常见错误与排查




错误现象可能原因排查方法


计算结果报错"参数必须为正数"输入了 0 或负数检查所有参数是否 > 0。钢丝直径、中径、有效圈数、切变模量、载荷均须为正数。


计算结果报错"参数不能为空"输入框为空或传入了 null/undefined确保所有输入框都已填写数值。


刚度值异常偏大或偏小单位搞错（如 G 用了 Pa 而非 MPa，或 d 用了 m 而非 mm）本工具统一使用 mm-N-MPa 单位制。G 的单位是 MPa（即 N/mm²），d 和 D 的单位是 mm。


切应力结果与手册不符曲度系数取值差异本工具使用简化公式 (1+0.5/c)。若 c < 4，偏差可能较大，建议用完整 Wahl 公式 K=(4c-1)/(4c-4)+0.615/c 复核。


弹簧指数 c 不在推荐范围c < 4 或 c > 16c < 4 时卷绕困难、曲度修正量大；c > 16 时弹簧易失稳。建议调整 d 或 D 使 c 落在 4～16 之间。


输入 NaN 或非数字前端未做输入校验本工具函数对非 number 类型或 NaN 会抛出异常。调用前请确保输入已转为有效数字。

六、局限性说明


本工具存在以下局限性，使用者应充分了解：


1. 仅适用于等截面圆丝圆柱螺旋弹簧。对于变截面（如锥形弹簧、中凸形弹簧）、变节距弹簧、矩形截面丝弹簧等，本工具的公式不适用。


2. 曲度系数采用简化公式。本工具使用 (1+0.5/c) 作为曲度修正系数，而非完整的 Wahl 公式 K=(4c-1)/(4c-4)+0.615/c。当弹簧指数 c < 4 时，两者偏差可达 5% 以上，此时应使用完整公式另行校核。


3. 不考虑疲劳寿命。本工具仅计算静态切应力，不涉及疲劳强度校核。对于承受交变载荷的弹簧，需按 GB/T 23935 中的疲劳验算方法另行计算。


4. 不考虑稳定性。对于高径比（自由高度/中径）较大的压缩弹簧，可能存在侧向失稳问题。本工具不进行稳定性校核。


5. 不考虑温度影响。切变模量 G 随温度变化。本工具假设用户输入的 G 值已考虑工作温度修正，工具本身不做温度补偿。


6. 不包含材料数据库。不同牌号、不同直径的弹簧钢丝，其许用切应力和切变模量不同。本工具不内置这些数据，需用户自行查阅标准或供应商资料。


7. 计算精度受浮点数限制。JavaScript 使用 IEEE 754 双精度浮点数，在极端数值（极大或极小）情况下可能存在精度损失。对于工程应用，建议结果保留 3～4 位有效数字即可。


8. 不进行制造工艺校核。弹簧的制造可行性（如最小弯曲半径、回弹量等）不在本工具考虑范围内。
