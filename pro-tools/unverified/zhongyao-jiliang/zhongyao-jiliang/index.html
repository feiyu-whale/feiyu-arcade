📚 数据依据
  1. 计量折算标准：1979年起，根据国务院批转卫生部《关于中药处方用药计量采用公制的问题》的通知，中药计量统一采用公制（克）。旧方折算时，按 1斤 = 500g、1斤 = 16两 的旧制关系，得 1两 = 31.25g。此折算方法被后续各版《中华人民共和国药典》沿用。
  2. 药典依据：《中华人民共和国药典》（2020年版一部），各药材项下标注的常用剂量单位为克（g）。
  3. 地区差异说明：部分地区历史上使用的"老秤""药秤"中 1两 ≈ 37.3g（约等于 595g/16），此数值属民间通行说法，无全国统一强制标准，具体需查地方计量史料。
  4. 进制关系：旧制十六两秤，1斤 = 16两，1两 = 10钱，1钱 = 10分，1分 = 10厘，为十进制细分。
