一、工具简介

  
本工具是一个纯 JavaScript 实现的法定计量单位换算库，用于在浏览器环境下完成长度、面积、体积、质量、压力、功率、温度七大类物理量的单位换算。核心算法采用「基准单位中转」模式：每个类别选定一个 SI 基准单位，所有输入值先换算到基准单位，再从基准单位换算到目标单位，从而将 N×N 的两两换算简化为 N 次线性映射。

  
该工具解决的核心问题：在工程计算、报表生成、数据可视化、表单录入等场景中，不同来源的数据往往使用不同单位（如国内工程用 MPa，进口设备用 psi；国内土地用亩，国际标准用公顷）。本工具提供统一、可复用的换算能力，避免业务代码中重复编写换算逻辑。


  
二、核心 API

  
2.1 convert(value, fromUnit, toUnit, category)

  

    
参数类型取值范围含义

    
valuenumber有限数值（非 NaN、非 Infinity）待换算的数值

    
fromUnitstring见下方单位表源单位符号

    
toUnitstring见下方单位表目标单位符号

    
categorystring'length'|'area'|'volume'|'mass'|'pressure'|'power'|'temperature'物理量类别

  

  
返回值：number，换算后的数值。

  
异常：参数类型错误、单位不存在、类别不存在时抛出 Error。

三、实际使用场景


  

    
场景 1：进口设备压力参数转换

    
背景：某进口液压泵铭牌标注工作压力 3000 psi，需转换为国内工程常用的 MPa 用于选型。

    
输入：convert(3000, 'psi', 'MPa', 'pressure')

    
结果：约 20.684 MPa（精确值 3000 × 6894.757293168 / 1e6）

    
说明：1 psi = 6894.757293168 Pa，该系数源自 1 lbf/in² 的英制定义。

  


  

    
场景 2：土地面积亩与公顷互换

    
背景：国土部门数据以「亩」登记，需换算为「公顷」用于国际报告。

    
输入：convert(1500, '亩', 'ha', 'area')

    
结果：100 ha（精确值：1500 × 2000/3 / 10000 = 100）

    
说明：1 亩 = 2000/3 m² ≈ 666.6667 m²，1 公顷 = 10000 m²。

  


  

    
场景 3：汽车发动机功率换算

    
背景：德系车标注 150 PS（公制马力），需换算为 kW 用于国内参数表。

    
输入：convert(150, 'PS', 'kW', 'power')

    
结果：约 110.325 kW（精确值 150 × 735.49875 / 1000）

    
说明：PS 为公制马力（Pferdestärke），1 PS = 735.49875 W；注意与英制马力 hp（1 hp ≈ 745.7 W）区分。

  


  

    
场景 4：体温单位转换

    
背景：海外医疗资料使用华氏度，需转换为摄氏度。

    
输入：convert(98.6, '°F', '°C', 'temperature')

    
结果：37 °C（精确值：(98.6 − 32) × 5/9 = 37）

    
说明：温度换算为非线性，需先转到开尔文基准再转出。

  


  

    
场景 5：木材体积从立方英寸转升

    
背景：进口木材规格以 in³ 标注，需换算为 L 用于仓储计算。

    
输入：convert(1000, 'in', 'm', 'length') 先换算边长，再立方；或直接体积换算：

    
直接输入：convert(61.0237, 'in', 'cm', 'length') 不适用体积，应使用体积类：

    由于本工具体积单位未直接包含 in³，可先换算长度再立方：1 in = 2.54 cm = 0.0254 m，故 1 in³ = (0.0254)³ m³ ≈ 1.6387×10⁻⁵ m³ = 0.016387 L。

    
说明：如需 in³ 直接换算，可在业务层扩展单位表。

  


  
四、常见错误与排查

  

    
错误现象可能原因排查方法

    
抛出 "Unknown category"category 拼写错误或不在七类之中检查 category 是否为 'length'|'area'|'volume'|'mass'|'pressure'|'power'|'temperature' 之一

    
抛出 "Unknown unit"单位符号拼写错误或大小写不符单位符号区分大小写，如 'MPa' 不能写成 'mpa'；中文单位如 '亩' 需完整输入

    
结果出现 0.30000000000000004IEEE 754 浮点精度问题业务层按需使用 Number(result.toFixed(n)) 截断

    
温度换算结果异常混淆了线性与非线性换算温度必须使用 'temperature' 类别，不能当作线性量处理

    
传入 null/undefined 报错参数校验失败调用前确保 value 为有限数字

  


  
五、数据来源与标准依据

  
    
    
  • GB 3100-1993《国际单位制及其应用》—— 等效采用 ISO 1000:1992，规定 SI 基本单位、导出单位及 SI 词头。
    • 
    
  • GB 3101-1993《有关量、单位和符号的一般原则》—— 等效采用 ISO 31-0:1992。
    • 
    
  • GB 3102.1-1993 至 GB 3102.13-1993 —— 各物理量的具体单位定义。
    • 
    
  • 市制单位（里、丈、尺、寸、斤、两、钱、亩）依据《中华人民共和国法定计量单位》（1984 年国务院发布）及国家计量总局相关解释。
    • 
    
  • 英制/美制单位换算系数（mile、ft、in、psi、hp、atm、mmHg）采用 NIST（美国国家标准与技术研究院）公布的精确值。
    • 
    
  • 公制马力 PS 采用 DIN 1302 / ISO 80000-5 定义：1 PS = 735.49875 W。
    • 
  

  
注：所有换算系数均为定义值或国际协议值，非测量值，因此不存在不确定度。如需核对原始定义，请查阅上述标准原文。


  
六、局限性说明

  

    本工具不能做以下事情，请勿超范围使用：
    
    
      
  • 不支持跨类别换算（如长度不能换算为面积，即便数值上看似可行）。物理量纲不同，跨类换算无物理意义。
    • 
      
  • 不支持「市制特殊行业单位」，如中药的「钱」在不同历史时期定义不同（本工具采用 1 钱 = 5 g 的现代市制定义，不适用于明清古方换算）。
    • 
      
  • 不支持「英制体积单位」（gal、ft³、in³ 等），如需使用请自行扩展单位表。
    • 
      
  • 不支持「能量/热量」类别（J、cal、BTU、kWh 等），因需求未列出。
    • 
      
  • 不支持「时间」「电流」「物质的量」「发光强度」等其他 SI 基本量。
    • 
      
  • 不处理「有效数字」与「测量不确定度」。本工具仅做数学换算，不对输入数据的有效位数做保留或传播。
    • 
      
  • 浮点精度受 IEEE 754 双精度限制，极大值（>1e300）或极小值（<1e-300）可能出现溢出或下溢。
    • 
      
  • 温度换算仅支持 K、°C、°F、°R 四种，不支持 Réaumur、Rankine 变体等罕见温标。
    • 
      
  • 本工具不保证在 Node.js 以外 JS 运行时（如 QuickJS、Duktape）的行为一致，但理论上兼容 ES5+ 环境。
    • 
      
  • 本工具不对「单位符号的书写规范」做校验，例如 'm2' 与 'm²' 视为不同符号，用户需按表中符号严格输入。
    •
