一、工具简介

    
本工具用于计算滚动轴承的基本额定寿命 L10 与小时寿命 L10h，同时提供当量动载荷 P 的辅助计算功能。计算依据为现行国家标准 GB/T 6391-2013《滚动轴承 额定动载荷和额定寿命》（等同采用 ISO 281:2007）。

    
滚动轴承寿命计算是机械设计中轴承选型的关键环节。工程师在选定轴承型号后，需要验证其在工作载荷与转速下的预期寿命是否满足设备设计要求。本工具将标准中的核心公式封装为可直接调用的纯函数，既可作为网页计算器使用，也可作为 JS 模块嵌入到其他工程计算系统中。

    
工具解决的核心问题：

    
    
      
  • 已知轴承额定动载荷 C 与当量动载荷 P，求 L10（百万转）与 L10h（小时）；
    • 
      
  • 已知径向载荷 Fr、轴向载荷 Fa 及系数 X、Y，求当量动载荷 P；
    • 
      
  • 根据轴承类型（球轴承 / 滚子轴承）自动选取寿命指数 ε。
    •

三、核心公式

    
3.1 基本额定寿命（百万转）

    
L10 = (C / P)ε  [百万转]

    
实际转数为 L10 × 106 转。L10 表示一批相同轴承在相同条件下运转，其中 90% 的轴承在发生疲劳点蚀前能达到或超过的寿命（即 10% 失效率）。


    
3.2 小时寿命

    
L10h = (106 / (60 · n)) · (C / P)ε  [小时]

    
其中 n 为工作转速（r/min）。


    
3.3 当量动载荷

    
P = X · Fr + Y · Fa

    
其中 Fr 为径向载荷，Fa 为轴向载荷，X、Y 为载荷系数，需根据轴承类型、接触角、Fa/Fr 比值等查 GB/T 6391 附表或轴承厂商样本。

  


  

    
四、参数详解

    

      
参数含义单位取值范围说明

      
C基本额定动载荷NC > 0由轴承厂商提供，可从产品样本中查得。代表轴承在额定寿命 100 万转下能承受的恒定载荷。

      
P当量动载荷NP > 0等效于实际复合载荷的假想恒定径向（或轴向）载荷。必须为正数，否则公式无意义。

      
n工作转速r/minn > 0轴承实际运转转速。计算 L10h 时必须提供。

      
ε寿命指数—3 或 10/3球轴承取 3；滚子轴承取 10/3。由轴承类型决定。

      
Fr径向载荷NFr ≥ 0作用在轴承上的径向方向载荷。

      
Fa轴向载荷NFa ≥ 0作用在轴承上的轴向方向载荷。

      
X径向系数—0 < X ≤ 1查 GB/T 6391 附表或厂商手册。

      
Y轴向系数—Y > 0查 GB/T 6391 附表或厂商手册。

    

    
⚠ 重要：X、Y 系数并非固定值，需根据轴承类型、Fa/Fr 与判别系数 e 的关系查表确定。本工具不内置 X、Y 表，需用户自行查取后输入。

  


  

    
五、实际使用场景


    
场景 1：深沟球轴承寿命校核

    
背景：某电机选用 6208 深沟球轴承，厂商样本给出 C = 32500 N，工作转速 n = 1500 r/min，当量动载荷 P = 4500 N。要求校核其小时寿命。

    
输入：轴承类型 = 球轴承；C = 32500；P = 4500；n = 1500

    
计算过程：

    
C/P = 32500/4500 ≈ 7.222
L10 = 7.2223 ≈ 376.7 百万转
L10h = 106/(60×1500) × 376.7 ≈ 4186 小时

    
结论：该轴承预期小时寿命约 4186 小时。若设备要求寿命 5000 小时，则需更换更大规格轴承或降低载荷。


    
场景 2：圆柱滚子轴承寿命计算

    
背景：某齿轮箱选用 NU210 圆柱滚子轴承，C = 61800 N，n = 900 r/min，P = 12000 N。

    
输入：轴承类型 = 滚子轴承（ε = 10/3）；C = 61800；P = 12000；n = 900

    
计算过程：

    
C/P = 61800/12000 = 5.15
L10 = 5.1510/3 ≈ 235.9 百万转
L10h = 106/(60×900) × 235.9 ≈ 4368 小时

    
结论：预期寿命约 4368 小时，满足一般工业齿轮箱 3000~5000 小时的设计要求。


    
场景 3：由 Fr、Fa 计算当量动载荷 P

    
背景：某角接触球轴承承受 Fr = 3000 N、Fa = 800 N。查厂商手册得 X = 0.56、Y = 1.55。

    
输入：Fr = 3000；Fa = 800；X = 0.56；Y = 1.55

    
计算过程：

    
P = 0.56 × 3000 + 1.55 × 800 = 1680 + 1240 = 2920 N

    
结论：当量动载荷 P = 2920 N，可代入寿命公式继续计算。


    
场景 4：高转速主轴轴承寿命评估

    
背景：某高速主轴 n = 12000 r/min，选用 7014C 角接触球轴承，C = 47500 N，P = 2200 N。

    
输入：球轴承；C = 47500；P = 2200；n = 12000

    
计算过程：

    
C/P ≈ 21.59
L10 = 21.593 ≈ 10065 百万转
L10h = 106/(60×12000) × 10065 ≈ 13979 小时

    
结论：高速下寿命仍可达约 13979 小时，但需注意高速工况下润滑、温升、极限转速等附加因素（本工具未考虑）。


    
场景 5：重载低速工况

    
背景：某起重机卷筒轴承，n = 30 r/min，C = 285000 N，P = 45000 N（滚子轴承）。

    
输入：滚子轴承；C = 285000；P = 45000；n = 30

    
计算过程：

    
C/P ≈ 6.333
L10 = 6.33310/3 ≈ 470.0 百万转
L10h = 106/(60×30) × 470.0 ≈ 261111 小时

    
结论：低速重载下小时寿命极长，但需校核静强度（GB/T 6391 中额定静载荷 C0 的计算不在本工具范围内）。

  


  

    
六、常见错误与排查

    

      
错误现象可能原因排查方法

      
报错 "C 必须为正数"输入了 0 或负数检查 C 值是否从厂商样本正确抄录，单位是否为 N

      
报错 "P 必须为正数"当量动载荷计算错误检查 X、Y 系数是否正确查表；Fr、Fa 是否漏项

      
报错 "n 必须为正数"转速输入为 0 或负数转速为 0 时轴承不转动，寿命公式无意义

      
计算结果异常大C/P 比值过大检查是否将 kN 误作 N 输入（1 kN = 1000 N）

      
计算结果异常小P 接近或超过 C说明轴承选型过小，需更换更大规格

      
X、Y 系数不知如何取未查表必须依据轴承类型、Fa/Fr 与 e 的关系查 GB/T 6391 附表或厂商样本

      
结果与厂商软件不一致未考虑修正系数厂商软件通常采用 ISO 281 修正寿命 Lnm = a1·aISO·L10，本工具仅计算基本 L10

八、局限性说明

    
本工具仅实现 GB/T 6391-2013 中的基本额定寿命计算，以下情况不适用或未实现：

    
    
      
  • 修正额定寿命 Lnm：GB/T 6391-2013 附录给出的 Lnm = a1 · aISO · L10 方法（考虑可靠性、润滑、污染等因素）未实现；
    • 
      
  • 额定静载荷 C0 与静强度校核：低速或冲击载荷工况需按 GB/T 6391 第 6 章校核静强度，本工具不支持；
    • 
      
  • 具体轴承型号参数：不内置任何型号的 C、X、Y、e 值，需用户查表；
    • 
      
  • 变工况寿命：当载荷或转速随时间变化时，需按累积损伤理论计算，本工具仅支持恒载恒速；
    • 
      
  • 温度修正：高温工况下 C 值需修正（通常 > 120°C 时需降额），本工具未考虑；
    • 
      
  • 极限转速校核：高速工况需校核轴承极限转速，本工具不涉及；
    • 
      
  • 润滑与密封：实际寿命受润滑、密封、安装精度影响极大，本工具仅给出理论疲劳寿命；
    • 
      
  • 特殊轴承：关节轴承、直线运动轴承等非滚动轴承不适用本公式。
    • 
    

    
本工具给出的 L10 仅为理论疲劳寿命的统计值，实际使用寿命受安装、润滑、维护、工况波动等多因素影响，通常需结合工程经验与厂商建议综合判断。重要场合请以轴承厂商官方计算软件或专业工程师校核为准。
