《屋面坡度与排水计算工具》使用说明书


    
一、工具用途

    
本工具面向建筑设计、施工、造价及审图人员，提供屋面坡度换算、天沟排水能力估算、雨水立管数量估算三项常用计算。计算依据为 GB 50015-2019《建筑给水排水设计标准》第 4.9 节"雨水"相关条款，以及水力学中的曼宁公式。

    
本工具适用于方案设计、初步设计阶段的快速估算，以及施工图阶段的辅助校核。最终设计应以具备资质的设计单位出具的正式图纸为准。


    
二、功能模块详解


    
2.1 坡度换算

    
屋面坡度在工程中有三种常见表示方式：

    
    
      
  • 百分比坡度：i = h/l × 100%，例如 2% 表示每 100 单位水平距离升高 2 单位；
    • 
      
  • 角度：坡面与水平面的夹角 α，单位度（°）；
    • 
      
  • 坡度系数 1:n：n = l/h，即水平距离与高差的比值，常见于结构图纸。
    • 
    

    
三者之间的换算关系为纯数学关系：百分比 = tan(α) × 100，n = 100 / 百分比。本模块按此关系实现，不涉及经验系数。


    
2.2 天沟排水量

    
天沟（檐沟）按明渠均匀流计算其过水能力。本工具采用曼宁公式：

    
v = (1/n) · R^(2/3) · i^(1/2)

    
Q = A · v

    
其中：

    
    
      
  • v —— 平均流速（m/s）；
    • 
      
  • n —— 粗糙系数，与天沟材质有关；
    • 
      
  • R —— 水力半径（m），R = A / P，P 为湿周；
    • 
      
  • i —— 天沟底坡（以小数计）；
    • 
      
  • A —— 过水断面面积（m²）；
    • 
      
  • Q —— 排水量（m³/s）。
    • 
    

    
本工具假设天沟断面为矩形，湿周 P = B + 2h。若为三角形或其他断面，需另行计算。


    
2.3 雨水管数量

    
依据 GB 50015-2019 表 4.9.20，不同管径的雨水立管对应不同的最大允许汇水面积。本工具内置常用管径的参考值（具体数值需查标准原文确认），按"数量 = 总汇水面积 / 单管允许面积"向上取整。

    

      注意：表 4.9.20 的数值与设计降雨强度、立管长度、管材等因素相关。本工具给出的为典型条件下的参考值，实际工程应查标准原文并结合当地气象数据复核。
    


    
三、参数详解

    

      
参数含义单位典型取值

      
百分比坡度坡面高差与水平距离之比 × 100%平屋面 1~3%，坡屋面 10~50

      
角度坡面与水平面夹角°平屋面 < 5°，坡屋面 10~45°

      
坡度系数 n1:n 中的 n—1:10、1:20 等

      
天沟宽度 B矩形天沟净宽m0.3 ~ 0.8

      
设计水深 h天沟内设计水位高度m一般取天沟深度的 2/3

      
天沟底坡 i天沟纵向坡度‰≥ 3‰（GB 50015 要求）

      
粗糙系数 n反映天沟内壁粗糙程度—金属 0.012，混凝土 0.013

      
汇水面积 F屋面投影面积（含高出屋面侧墙面积的一半）m²按建筑平面图计算

      
雨水立管管径立管公称直径mmDN100、DN150 等

    


    
四、使用场景


    
场景 1：平屋面坡度复核

    
某办公楼平屋面结构找坡 2%，建筑专业希望换算为角度以绘制剖面图。输入百分比 2，选择"百分比坡度"，得到角度约 1.15°，坡度系数约 50（即 1:50）。设计人员据此核对结构图纸与建筑图纸的一致性。


    
场景 2：坡屋面瓦材选型

    
某别墅坡屋面设计坡度 30°，需确认是否适合采用某型号水泥瓦（要求坡度 ≥ 22°）。输入角度 30，换算得百分比约 57.7%，坡度系数约 1.73（即 1:1.73）。满足瓦材要求。


    
场景 3：天沟断面校核

    
某厂房混凝土天沟宽 0.5m、深 0.3m，底坡 5‰，按 2/3 水深（0.2m）计算过水能力。输入 B=0.5、h=0.2、i=5、n=0.013，得到排水量约 0.055 m³/s = 55 L/s。结合当地暴雨强度公式复核是否满足屋面雨水设计流量。


    
场景 4：雨水立管数量估算

    
某住宅楼屋面投影面积 1200 m²，拟采用 DN100 雨水立管。输入面积 1200、管径 DN100，得到立管数量约 3 根（具体数值取决于内置参考值）。设计人员据此布置立管位置，并在施工图阶段按 GB 50015 表 4.9.20 复核。


    
场景 5：天沟材质比选

    
某项目在天沟材质比选中，需比较金属天沟（n=0.012）与混凝土天沟（n=0.013）的排水能力差异。保持其他参数不变，分别计算两种材质的排水量，金属天沟排水能力约高出 8%。结合造价、耐久性综合决策。


    
五、常见错误

    
    
      
  1. 混淆坡度表示方式：百分比坡度 5% 不等于角度 5°。5% 对应角度约 2.86°，5° 对应百分比约 8.75%。输入前务必确认图纸采用的表示方式。
    2. 
      
  2. 天沟底坡单位错误：本工具输入单位为 ‰（千分比），例如 3 表示 3‰ = 0.003。若误输入 0.003，则计算结果将严重偏小。
    3. 
      
  3. 设计水深取值过大：设计水深一般取天沟深度的 2/3 左右，需预留安全超高。若取等于天沟深度，则未考虑风浪、堵塞等因素。
    4. 
      
  4. 汇水面积漏算：GB 50015 规定，高出屋面的侧墙面积应按一半计入汇水面积。漏算会导致立管数量偏少。
    5. 
      
  5. 忽视当地暴雨强度：雨水立管数量与当地的暴雨强度公式密切相关。本工具给出的为典型参考值，不同城市差异较大，必须结合当地气象数据复核。
    6. 
      
  6. 将估算结果直接用于施工图：本工具用于方案估算与辅助校核，正式施工图应由设计单位按完整计算书出具。
    7. 
    


    
六、数据依据

    
    
      
  • GB 50015-2019《建筑给水排水设计标准》第 4.9 节"雨水"；
    •

    • 
      
  • 曼宁公式（Manning formula），水力学明渠均匀流基本公式；
    • 
      
  • 粗糙系数 n 的取值参考《给水排水设计手册》及相关水力学教材。
    •

七、精度与误差说明

    
现实工程中的变量是无限的，本工具遵循"方法准、输入项准、结果给误差范围"的原则，不承诺绝对精确。以下分项说明：


    
7.1 算准了什么

    
    
      
  • 坡度换算：基于严格的三角函数关系，计算过程无经验近似。在 JavaScript 双精度浮点数范围内（约 15~17 位有效数字），换算结果可视为数学意义上的精确值。工程应用中，保留 2~4 位小数已足够。
    • 
      
  • 曼宁公式计算：在给定输入参数（B、h、i、n）的前提下，公式计算过程是确定的，不存在随机误差。
    • 
      
  • 立管数量取整：向上取整逻辑是确定的，不存在歧义。
    • 
    


    
7.2 哪些因素没算进去

    
    
      
  • 天沟排水量：曼宁公式本身是经验公式，适用于均匀流。实际天沟中可能存在非均匀流、入口损失、弯道损失、杂物堵塞等因素，本工具均未考虑。
    • 
      
  • 雨水立管数量：未考虑立管实际长度、管件局部阻力、雨水斗型式、悬吊管坡度等因素。GB 50015 表 4.9.20 的数值本身已包含一定安全裕度，但具体适用条件需查标准原文。
    • 
      
  • 屋面雨水设计流量：本工具未直接计算屋面雨水设计流量（需结合当地暴雨强度公式、径流系数、汇水面积），仅在天沟校核时隐含了流量与过水能力的对比逻辑。
    • 
      
  • 风、雪、施工误差：实际屋面的积水深度、天沟的实际粗糙度、施工偏差等均未纳入。
    • 
    


    
7.3 误差大概多大

    
    
      
  • 坡度换算：数学误差可忽略（< 10⁻¹⁰ 量级）。工程误差主要来源于输入值的读数误差，通常 < 0.1%。
    • 
      
  • 天沟排水量：曼宁公式本身的经验误差约 ±10%~15%；粗糙系数 n 的选取误差可能带来 ±10%~20% 的偏差；综合误差估计在 ±20%~30% 范围内。本工具结果仅供方案比选与初步估算，不可作为最终设计依据。
    • 
      
  • 雨水立管数量：由于内置参考值为典型值，实际允许汇水面积可能因地区、管长、管件等因素有 ±20%~30% 的偏差。建议按计算结果适当增加安全裕度，并在施工图阶段按标准原文复核。
    • 
    


    
八、局限性

    
    
      
  1. 本工具仅覆盖 GB 50015-2019 的部分条款，不替代完整的设计计算书。
    2. 
      
  2. 天沟断面仅支持矩形，不支持三角形、梯形、弧形等异形断面。
    3. 
      
  3. 雨水立管数量估算基于典型参考值，未接入各地暴雨强度公式数据库。
    4. 
      
  4. 未考虑虹吸式雨水系统、重力流与压力流的差异。
    5. 
      
  5. 未考虑屋面绿化、雨水收集回用等海绵城市相关因素。
    6. 
      
  6. 本工具为前端纯 JS 实现，计算在浏览器本地完成，不联网、不存储用户输入。
    7. 
      
  7. 对于重要公共建筑、大跨度屋面、复杂造型屋面，应委托专业设计单位进行专项计算。
    8.
