📋 数据依据

  • 厚度测量方法：QB/T 2709-2005《皮革 物理和机械试验 厚度的测定》，规定了皮革厚度的测量方法及仪器要求。
  • 盎司(oz)换算：1 oz = 1/64 英寸 ≈ 0.396875mm，属皮革行业国际通行经验约定，无中国国家标准对此单位作出强制定义。各厂商口径可能有差异。
  • 英丝(thou)换算：1 thou = 1/1000 英寸 = 0.0254mm（1英寸 = 25.4mm 为国际精确约定值）。
  • 面积换算：1 平方英尺 = 9.290304 平方分米，基于 1 英寸 = 25.4mm（精确值）推导，为数学精确换算。
  • 常见皮革厚度范围：属行业通行经验数据，无统一国标强制规定具体数值。不同用途皮革的厚度要求可参见：
