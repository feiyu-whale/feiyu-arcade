🌙 更点制对照

夜间以"更"计时，每更约两小时，每更分五点，每点约24分钟。

更对应时辰现代时段别称
一更戌时19:00–21:00黄昏
二更亥时21:00–23:00人定
三更子时23:00–01:00夜半
四更丑时01:00–03:00鸡鸣
五更寅时03:00–05:00平旦
💡 更点细分：每更分五点。例如"三更三点"约为子时正中（0:00前后），"三更五点"约为0:24。每点约合现代24分钟。

📖 补充说明

关于"时辰初/正"：每个时辰分"初"和"正"两段，各一小时。如子初=23:00–00:00，子正=00:00–01:00。此制始于汉代，历代沿用。

关于生肖配时辰：依据动物活动习性配属地支，如鼠咬夜半（子）、牛耕黎明（丑）等，属传统民俗说法。

关于经络当令：源自中医子午流注理论，认为气血在不同时辰流注不同经脉。具体对应关系详见《黄帝内经》相关篇章。

📚 数据依据

  • 十二时辰名称与时段划分：依据《中国天文学史》（中国科学技术史·天文学卷，科学出版社）及历代历志记载，属传统天文历法通行说法。
  • 时辰别称（夜半、鸡鸣、平旦等）：见于《颜氏家训·书证》《左传》《诗经》等先秦两汉文献，为历代通行称谓。
  • 生肖配地支：见于东汉王充《论衡·物势》等，属民间通行说法，无强制标准。
  • 五行配地支：寅卯属木、巳午属火、申酉属金、亥子属水、辰戌丑未属土，为传统五行学说通行配法，见于《淮南子·天文训》等。
  • 经络当令（子午流注）：源自《黄帝内经》运气七篇及后世针灸文献，属中医传统理论，非国家强制标准。
  • 更点制：见于《新唐书·百官志》《宋史·天文志》等，为古代夜间计时通行制度。

⚠️ 以上均为传统文献记载与民间通行说法，非现行国家标准（GB）。具体细节因朝代、地域可能略有差异。
