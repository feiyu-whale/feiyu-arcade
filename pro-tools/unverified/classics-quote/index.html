一、工具简介

「经典名句出处」是一款面向中文古典文献的名句查询工具，覆盖四书（《大学》《中庸》《论语》《孟子》）与五经（《诗经》《尚书》《礼记》《周易》《春秋》）以及诸子百家（《道德经》《庄子》《荀子》《韩非子》《墨子》《管子》《列子》《吕氏春秋》等）中的经典名句。

本工具解决的核心问题是：当读者在阅读、写作或研究过程中遇到一句似曾相识的古文名句时，能够快速查到其原文出处（具体到篇目章节）、通行原文以及白话释义，免去翻检原典的繁琐。

所有原文数据以中华书局点校本为通行依据。中华书局点校本二十四史及先秦典籍整理本，是目前学术界和出版界公认的标准通行本，其标点、分段、校勘均经过严格审校。

二、功能参数详细说明

2.1 searchQuotes(query, options)

参数类型取值范围说明
querystring任意非空字符串，长度 1~200搜索关键字，支持名句片段、篇名、作者名等模糊匹配
options.sourcestring | undefined典籍名称或空字符串限定搜索范围的典籍名，如"论语""道德经"。为空则搜索全部典籍
options.categorystring | undefined分类名或空字符串限定名句分类，如"修身""治国""学习""哲理"等
options.limitnumber正整数，默认 50，范围 1~500返回结果的最大条数
options.pagenumber正整数，默认 1分页页码

2.2 getQuoteById(id)

参数类型取值范围说明
idstring名句唯一标识符，格式 "S" + 四位数字如 "S0001" 表示数据库中第一条名句

返回值：匹配的名句对象，或 null（未找到时）。

2.3 getQuotesBySource(sourceName)

参数类型说明
sourceNamestring典籍名称，需与数据库中存储的名称完全匹配

返回值：该典籍下所有名句的数组。

2.4 getQuotesByCategory(categoryName)

参数类型说明
categoryNamestring分类名称，如"修身""学习""哲理""治国""自然""教育"

2.5 formatQuote(quoteObj, formatType)

参数类型取值范围说明
quoteObjobject名句数据对象包含 text、source、chapter、explanation 等字段
formatTypestring"brief" | "full" | "citation"输出格式：简要（仅原文+出处）、完整（含释义）、引用格式（适合学术引用）

三、实际使用场景

场景一：写作引用查证

情境：在撰写论文时需要引用"己所不欲，勿施于人"，需确认原文出处及准确原文。

输入：query = "己所不欲"

预期结果：返回匹配结果，显示原文"己所不欲，勿施于人"，出处为《论语·颜渊》及《论语·卫灵公》（此句在两篇中均有出现），释义为"自己不想要的事物，不要强加给别人"。

场景二：按典籍浏览

情境：想系统了解《道德经》中收录了哪些名句。

输入：options.source = "道德经"，query = ""（空搜索）

预期结果：返回数据库中所有出自《道德经》的名句，如"上善若水""道可道，非常道""天网恢恢，疏而不失"等，每条均标注具体章节（如第一章、第八章等）。

场景三：按主题分类查找

情境：准备一场关于"学习"主题的演讲，需要收集相关经典名句。

输入：options.category = "学习"

预期结果：返回所有分类为"学习"的名句，如"学而时习之，不亦说乎"（《论语·学而》）、"学而不思则罔，思而不学则殆"（《论语·为政》）、"博学之，审问之，慎思之，明辨之，笃行之"（《中庸》第二十章）等。

场景四：生成学术引用格式

情境：需要在学术文章中规范引用"天行健，君子以自强不息"。

输入：先通过搜索找到该名句，再调用 formatQuote(quoteObj, "citation")

预期结果：输出引用格式文本，如：「天行健，君子以自强不息。」——《周易·乾卦·象传》（中华书局点校本）

场景五：模糊记忆查找

情境：只记得一句古文中含有"千里之行"四个字，但不确定完整原文和出处。

输入：query = "千里之行"

预期结果：返回"千里之行，始于足下"，出处《道德经》第六十四章，释义为"走一千里路，是从迈第一步开始的。比喻事情的成功是从小到大逐渐积累的"。

场景六：教学备课

情境：中学语文教师备课《论语》十二章，需要查找相关名句的释义辅助教学。

输入：options.source = "论语"，options.category = "教育"

预期结果：返回《论语》中与教育相关的名句，如"有教无类"（《论语·卫灵公》）、"因材施教"（源自朱熹对《论语》的注释概括，需注意此条可能不在原始数据库中）等，每条附带白话释义。

四、常见错误与排查

  1. 搜索无结果：检查关键字是否有错别字。本工具采用子串匹配，输入的字必须在名句原文中连续出现。例如搜索"已所不欲"（错用"已"）将无法匹配"己所不欲"。
  2. 出处与记忆不符：部分名句在不同典籍中有相似表述。例如"天行健"出自《周易》的《象传》部分，而非《彖传》。本工具标注的是中华书局点校本中的实际位置。如有疑义，请核对原书。
  3. 释义理解偏差：本工具提供的释义为通行白话翻译，力求准确但无法涵盖历代注疏的全部学术争议。如需深入研究，建议参阅《十三经注疏》（中华书局影印阮元校刻本）及各家的专门注本。
  4. 参数类型错误：query 参数必须为字符串类型，传入 null 或 undefined 会抛出 TypeError。limit 参数必须为正整数，传入负数或小数会被修正为默认值 50。
  5. 结果数量过多：如果搜索关键字过于宽泛（如单字"之""也"），可能返回大量结果。建议使用 limit 参数限制返回数量，或使用更具体的关键字。

五、数据来源与标准依据

本工具的数据来源与标准依据如下：

  1. 四书原文：以中华书局出版的《四书章句集注》（[宋]朱熹集注，1983年版）为底本。该书以清代阮元校刻《十三经注疏》本为底本进行点校，是目前学术界通行的标准版本。
  2. 五经原文：以中华书局《十三经注疏》（影印阮元校刻本，1980年版）为底本。其中《周易》用魏王弼注、唐孔颖达疏本；《诗经》用汉毛亨传、郑玄笺、唐孔颖达疏本；《尚书》用汉孔安国传、唐孔颖达疏本；《礼记》用汉郑玄注、唐孔颖达疏本；《春秋左传》用晋杜预注、唐孔颖达疏本。
  3. 诸子原文：以中华书局"新编诸子集成"系列丛书为底本。如《老子道德经注》（王卡点校，1993年）、《庄子集释》（郭庆藩撰，王孝鱼整理，1961年版）、《荀子集解》（王先谦撰，沈啸寰、王星贤整理，1988年版）等。
  4. 释义编写：白话释义参考了上述各书的通行译注本，并结合现代汉语表达习惯编写，力求准确简明。
  5. 标点规范：遵循 GB/T 15834—2011《标点符号用法》国家标准。古籍原文中的书名号使用全称，篇名与书名之间用间隔号"·"分隔。

注意：本工具收录的名句数量有限（当前版本约 50 条），远未穷尽四书五经与诸子百家的全部名句。如需更全面的检索，建议配合使用"中国基本古籍库"（北京爱如生数字化技术研究中心）等专业数据库。

六、局限性说明

  1. 收录范围有限：当前版本仅收录约 50 条名句，无法覆盖四书五经与诸子百家的全部经典语句。后续版本将逐步扩充。
  2. 版本差异未标注：不同版本的古籍在文字上可能存在异文（如通行本与出土简帛本的差异）。本工具仅展示中华书局点校本的通行文字，不标注版本异同。如需版本校勘信息，需查阅专门的校勘记。
  3. 释义一家之言：白话释义力求准确，但古籍释义历来存在学术争议。本工具提供的释义代表通行理解，不代表唯一正确的解释。例如《道德经》第一章"道可道，非常道"的释义，历代注家理解各异。
  4. 不支持全文检索：本工具仅检索已收录的名句数据库，不支持对原典全文的检索。如果某句话虽然出自某典籍但未被收录为"名句"，则无法查到。
  5. 不支持繁体/异体字检索：搜索时仅支持简体中文字符。如果用户输入繁体字或异体字，可能无法匹配。例如输入"學而時習之"将无法匹配"学而时习之"。
  6. 无离线数据更新机制：数据内嵌于 JavaScript 代码中，如需更新数据必须修改源码并重新部署。
  7. 不保证学术引用效力：本工具提供的出处信息仅供快速查阅参考，不能替代查阅原书。在正式学术写作中，仍需核对原书原文以确保准确无误。
