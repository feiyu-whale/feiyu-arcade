一、工具概述

本工具用于模拟一元强酸-强碱及一元弱酸-强碱滴定过程，通过逐步加入滴定剂（强碱）计算溶液 pH 值变化，生成完整滴定曲线。核心算法基于酸碱平衡理论，参考 Harris DC《Quantitative Chemical Analysis》第9版第6-7章的系统滴定理论。

滴定分析是分析化学中最基础的定量方法之一，在临床检验（如体液酸碱度分析）、制药工业（原料药含量测定）、环境监测（水质酸碱度）及食品科学等领域有广泛应用。准确预测滴定曲线有助于选择合适的指示剂、判断滴定终点、评估方法可行性。

二、核心公式与计算步骤

2.1 强酸-强碱滴定

强酸（如 HCl）在水中完全解离，强碱（如 NaOH）同样完全解离。滴定反应为：

H⁺ + OH⁻ → H₂O

计算分三个阶段（Harris, 9th ed., Chapter 7）：

  1. 等当点前（Vb < Ve）：溶液中存在过量 H⁺。
    [H⁺] = (nₐ - n_b) / V_total = (CₐVₐ - C_bV_b) / (Vₐ + V_b)
    pH = -log₁₀[H⁺]
  2. 等当点（Vb = Ve）：酸碱恰好完全中和，溶液为纯水（忽略盐效应）。
    pH = 7.000（25°C）
  3. 等当点后（Vb > Ve）：溶液中存在过量 OH⁻。
    [OH⁻] = (n_b - nₐ) / V_total = (C_bV_b - CₐVₐ) / (Vₐ + V_b)
    pH = 14.000 + log₁₀[OH⁻]

等当点体积：Ve = CₐVₐ / C_b

2.2 弱酸-强碱滴定

弱酸（如 CH₃COOH）部分解离，需考虑酸解离平衡。滴定反应为：

HA + OH⁻ → A⁻ + H₂O

计算分四个阶段（Harris, 9th ed., Chapter 7; Skoog et al., Analytical Chemistry, 9th ed.）：

  1. 初始点（Vb = 0）：纯弱酸溶液，用精确二次方程求解。
    Ka = [H⁺][A⁻] / [HA] = x² / (Cₐ - x)
    x² + Ka·x - Ka·Cₐ = 0 → x = [-Ka + √(Ka² + 4KaCₐ)] / 2
    pH = -log₁₀(x)

    其中 x = [H⁺]。此公式不采用近似 [H⁺] ≈ √(Ka·Cₐ)，而是精确求解二次方程，适用于 Ka 较大或 Cₐ 较小的情况。

  2. 缓冲区域（0 < Vb < Ve）：溶液含 HA 和 A⁻，构成缓冲体系。使用 Henderson-Hasselbalch 方程：
    pH = pKa + log₁₀(n_b / (nₐ - n_b)) = pKa + log₁₀(C_bV_b / (CₐVₐ - C_bV_b))

    注意：此处使用物质的量之比而非浓度之比，因为体积项在比值的分子分母中抵消。此公式在缓冲容量足够大时准确；当接近滴定起始点或接近等当点时，缓冲公式的近似性降低，本工具在这些区域仍使用 Henderson-Hasselbalch 方程，但用户应注意其精度下降。

  3. 等当点（Vb = Ve）：所有 HA 转化为 A⁻（共轭碱），溶液呈碱性。
    C_s = CₐVₐ / (Vₐ + V_e)（共轭碱浓度）
    K_b = K_w / Kₐ
    [OH⁻] = √(K_b · C_s)（精确解需解二次方程，此处用近似）
    pH = 14 + log₁₀[OH⁻]

    等价形式：pH = 7 + ½(pKa + log₁₀C_s)。此公式假设 [OH⁻] ≪ C_s，即共轭碱水解程度不大。当 C_s 极小或 Ka 极大（弱酸接近强酸）时，此近似失效。

  4. 等当点后（Vb > Ve）：过量 OH⁻ 抑制共轭碱水解，pH 由过量碱决定。
    [OH⁻] = (C_bV_b - CₐVₐ) / (Vₐ + V_b)
    pH = 14 + log₁₀[OH⁻]

三、临床与工程意义

3.1 临床检验领域：在临床生化检验中，酸碱滴定原理被用于多种检测项目。例如，体液总二氧化碳含量的测定（碱滴定法）、尿液可滴定酸的测定、胃液游离酸度分析等。准确理解滴定曲线有助于检验人员判断终点、选择指示剂、评估方法线性范围。

3.2 制药工业：原料药的含量测定常采用酸碱滴定法（《中国药典》通则 0701）。预测滴定曲线可帮助方法开发人员选择合适的滴定条件、判断是否存在干扰、优化终点检测方式（电位法 vs 指示剂法）。

3.3 环境工程：水处理中的碱度测定、废水中和处理的设计均需滴定曲线知识。通过模拟可预估中和所需碱量、判断缓冲能力、优化加药策略。

3.4 教学科研：本工具可作为分析化学教学的辅助手段，帮助学生直观理解滴定过程中 pH 变化规律、缓冲区域特征、等当点位置等核心概念。

四、精度与误差说明

① 算准了什么：

  • 在理想溶液假设下（活度系数 γ = 1），本工具的计算结果与理论值一致。
  • 强酸-强碱滴定：等当点前/后的 pH 计算精确到 ±0.01 pH 单位（在合理浓度范围内）。
  • 弱酸-强碱滴定：缓冲区域的 Henderson-Hasselbalch 方程在缓冲比 0.1~10 范围内误差 < 0.05 pH 单位。
  • 等当点体积的计算是精确的（基于化学计量关系）。

② 哪些因素没算进去：

  • 活度效应：所有计算基于浓度而非活度。当离子强度 I > 0.01 mol/L 时，活度系数显著偏离 1，pH 计算值与实测值可能出现 0.1~0.5 单位的偏差。需使用 Debye-Hückel 方程或 Davies 方程修正。
  • 温度效应：Kw = 1.0×10⁻¹⁴ 仅在 25°C 成立。温度变化时 Kw 改变（如 37°C 时 Kw ≈ 2.4×10⁻¹⁴），等当点 pH 不再为 7。
  • 多元酸碱：本工具仅处理一元酸碱。多元酸（如 H₃PO₄）需考虑逐级解离，本工具不适用。
  • CO₂ 溶解：实际滴定中空气中 CO₂ 溶入会影响稀溶液的 pH，尤其在高 pH 区域。
  • 体积非加和性：模型假设混合后体积等于两溶液体积之和。实际中混合可能有微小体积变化（通常 < 1%）。
  • 弱酸近似：等当点处 [OH⁻] = √(Kb·Cs) 是近似公式，当 Cs 极小或 Kb 较大时需解精确二次方程。

③ 误差估计：

  • 浓度 0.001~1 mol/L、离子强度 < 0.01 mol/L 时：pH 误差约 ±0.02 单位。
  • 浓度 > 0.1 mol/L 时：因活度效应，pH 误差可达 ±0.1~0.3 单位。
  • 极稀溶液（< 10⁻⁵ mol/L）：水的自解离不可忽略，本工具在强酸强碱情况下已考虑，但弱酸极稀情况下可能有额外误差。
  • 等当点附近（±0.01 mL 范围）：pH 变化剧烈，步长不够密时曲线可能不平滑。

五、适用场景与不适用场景

适用：

  • 一元强酸（HCl, HNO₃, HClO₄ 等）与一元强碱（NaOH, KOH 等）的滴定
  • 一元弱酸（CH₃COOH, HCOOH, C₆H₅COOH 等）与一元强碱的滴定
  • 浓度范围：10⁻⁵ ~ 5 mol/L（超出此范围误差增大）
  • 温度：25°C（其他温度需手动修正 Kw）
  • 稀溶液（离子强度 < 0.01 mol/L 时结果较可靠）

不适用：

  • 多元酸碱滴定（如 H₂SO₄, H₃PO₄, Na₂CO₃）
  • 弱碱-强酸滴定（需另行建模）
  • 弱酸-弱碱滴定（无明确等当点）
  • 非水溶液滴定
  • 高浓度溶液（> 1 mol/L，活度效应显著）
  • 含混合酸碱的复杂体系
  • 非 25°C 条件（除非手动修正 Kw 值）

六、已知局限与误差来源

  1. 理想溶液假设：Debye-Hückel 极限公式指出 log γ = -0.509z²√I / (1 + 3.29a√I)。当 I > 0.01 时，γ 偏离 1 超过 5%，pH 误差显著。本工具未做活度修正。
  2. Henderson-Hasselbalch 方程的局限：该方程假设 [HA] 和 [A⁻] 等于其分析浓度，忽略了水解离和水解的贡献。在极稀缓冲液或缓冲比极端（< 0.01 或 > 100）时误差增大。
  3. 等当点 pH 近似：pH = 7 + ½(pKa + log Cs) 假设 [OH⁻] ≪ Cs。当 Cs < 10⁻³ mol/L 或 pKa < 3 时，此近似可能产生 > 0.1 单位误差。
  4. 数值精度：JavaScript 使用 IEEE 754 双精度浮点数（约 15-16 位有效数字），在极端 pH 值（< 0 或 > 14）时可能产生舍入误差。
  5. 图表分辨率：SVG 图表在等当点附近的 pH 突跃可能因采样密度不足而显示不够尖锐。本工具在等当点附近自动加密采样点以缓解此问题。

模型假设条件

  • 理想溶液：活度系数 γ = 1，即离子间无相互作用。此假设在离子强度 I < 0.01 mol/L 时近似成立。
  • 完全解离：强酸强碱在水中 100% 解离。实际上即使在稀溶液中，离子对效应使有效浓度略低于分析浓度。
  • 体积可加：混合后总体积 = Vₐ + V_b。实际混合可能有 ±1% 的体积偏差。
  • 恒温 25°C：Kw = 1.0×10⁻¹⁴。温度变化时 Kw 改变，影响所有 pH 计算。
  • 一元酸碱：仅考虑一级解离，不适用于多元酸碱体系。
  • 无副反应：不考虑 CO₂ 溶解、金属离子水解、络合反应等副过程。

适用范围

本工具适用于以下条件的近似计算：

  • 一元强酸-强碱滴定：浓度 10⁻⁴ ~ 1 mol/L
  • 一元弱酸-强碱滴定：浓度 10⁻⁴ ~ 1 mol/L，pKa 范围 2~12
  • 温度 25°C，稀溶液（离子强度 < 0.01 mol/L）

超出上述范围时，计算结果仅供参考趋势，不可作为定量依据。
