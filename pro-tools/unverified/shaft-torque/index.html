📚 数据来源

  • 公式 T = 9550P/n 及轴径估算公式 d ≥ (16T/(π[τ]))^(1/3) 均出自《机械设计》（濮良贵、陈国定、吴立伟 编，高等教育出版社），第10版第15章"轴"。
  • 系数 9550 的推导：T = P/(ω) = P/(2πn/60) = 60P/(2πn) × 10³ ≈ 9549.3P/n，工程上取 9550。
  • 许用扭转切应力 [τ] 参考值出自上述教材中"按扭转强度条件估算轴的最小直径"相关表格（表15-3或相近编号，具体表号以教材版本为准）。
  • 轴径估算公式的力学基础：实心圆轴扭转切应力 τ = T/Wp = T/(πd³/16) = 16T/(πd³)，令 τ ≤ [τ] 即得 d ≥ (16T/(π[τ]))^(1/3)。
