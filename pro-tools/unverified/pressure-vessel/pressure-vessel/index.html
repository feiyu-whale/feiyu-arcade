🏭 压力容器圆筒壁厚计算

依据 GB/T 150.1-2011《压力容器 第1部分：通用要求》

📐 计算公式
圆筒计算厚度（内压）：
δ = P·Di / (2[σ]t·φ − P) + C
许用应力：
[σ]t = min( σb/nb , σs/ns )
其中：P—设计压力；Di—圆筒内径；φ—焊接接头系数；C—厚度附加量；
σb—抗拉强度；σs—屈服强度（或规定非比例延伸强度Rp0.2）；
nb—抗拉强度安全系数（≥2.7）；ns—屈服强度安全系数（≥1.5）

📖 数据来源

主要依据标准

  • GB/T 150.1-2011《压力容器 第1部分：通用要求》——规定了压力容器材料许用应力的确定方法、安全系数取值及内压圆筒壁厚计算公式。
  • GB/T 150.3-2011《压力容器 第3部分：设计》——给出了内压圆筒和球壳厚度计算的具体公式。

关键参数说明

  • 安全系数 nb ≥ 2.7：GB/T 150.1-2011 第4.2.2条规定，室温下抗拉强度安全系数 nb ≥ 2.7。
  • 安全系数 ns ≥ 1.5：GB/T 150.1-2011 第4.2.2条规定，室温下屈服强度安全系数 ns ≥ 1.5。
  • 焊接接头系数 φ：按 GB/T 150.1-2011 附录B（表B.1）选取，具体值取决于焊接接头型式和无损检测比例。
  • 厚度附加量 C：包括钢板厚度负偏差 C₁ 和腐蚀裕量 C₂，具体数值需根据材料标准和工艺条件查相应标准确定。

⚠️ 注意事项

  • 本工具仅计算内压圆筒的计算厚度，不适用于外压容器。
  • 实际设计中还需考虑最小厚度要求、开孔补强、支座处应力等，须由持证压力容器设计人员完成最终设计。
  • 材料许用应力 [σ]t 在设计温度下的具体数值需查 GB/T 150.2《压力容器 第2部分：材料》中的许用应力表，本工具仅按室温强度指标进行估算。
  • 本工具计算结果仅供参考，不得直接用于工程设计出图。
