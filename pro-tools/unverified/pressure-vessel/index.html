一、工具简介

本工具用于计算内压圆筒形压力容器的理论计算壁厚，计算依据为中华人民共和国国家标准 GB/T 150.1-2011《压力容器 第1部分：通用要求》 中关于内压圆筒壁厚计算的规定。

在压力容器设计过程中，壁厚计算是最基础也是最关键的环节之一。壁厚过薄会导致容器在运行中发生强度失效（如爆破、屈服），壁厚过厚则造成材料浪费、重量增加、制造难度上升。本工具通过输入材料力学性能、设计压力、几何尺寸、焊接接头系数和厚度附加量等参数，快速给出满足强度要求的计算壁厚，辅助设计人员进行初步方案评估和校核。

需要特别说明的是，本工具给出的是计算壁厚（即公式计算结果），并非最终的下料厚度或名义厚度。实际设计中还需根据钢板规格进行圆整，并满足最小壁厚、制造工艺等其它要求。

二、计算公式

δ = P·D / (2·[σ]t·φ − P) + C

式中：

  • δ —— 圆筒的计算厚度，mm；
  • P —— 设计压力，MPa；
  • D —— 圆筒内直径，mm；
  • [σ]t —— 设计温度下材料的许用应力，MPa；
  • φ —— 焊接接头系数；
  • C —— 厚度附加量，mm，C = C₁ + C₂。

许用应力的确定：

[σ]t = min( σb/nb , σs/ns )

依据 GB/T 150.1-2011 第 4.2.2 条，对碳钢、低合金钢等材料，室温下安全系数应满足：

  • nb ≥ 2.7（基于抗拉强度下限值 σb）
  • ns ≥ 1.5（基于屈服强度下限值 σs 或 σ0.2）
注：本工具按室温条件简化处理。当设计温度较高时，材料许用应力应取设计温度下的值，且高温安全系数的规定与室温不同，需查阅 GB/T 150.2 相关材料标准。

四、实际使用场景

场景 1：常规低压储罐

工况：一台用于储存常温水的立式圆筒形储罐，设计压力 0.6 MPa，内径 1200 mm，材料 Q345R，双面焊对接接头并进行 100% 射线检测，腐蚀裕量取 1 mm，钢板负偏差取 0.3 mm。

输入：

  • σb = 510 MPa，σs = 345 MPa（Q345R 室温下限值，需查 GB/T 150.2 确认）
  • nb = 2.7，ns = 1.5
  • P = 0.6 MPa，D = 1200 mm
  • φ = 1.0（双面焊 100% 检测）
  • C = 0.3 + 1 = 1.3 mm

计算过程：

  • [σ] = min(510/2.7, 345/1.5) = min(188.89, 230) = 188.89 MPa
  • δ = 0.6 × 1200 / (2 × 188.89 × 1.0 − 0.6) + 1.3
  • δ = 720 / (377.78 − 0.6) + 1.3 = 720 / 377.18 + 1.3 ≈ 1.91 + 1.3 = 3.21 mm

说明：计算壁厚 3.21 mm 较小，但实际设计中还需满足最小壁厚要求（一般不小于 3 mm，大型容器另有规定），并根据钢板规格向上圆整。

场景 2：中压反应釜

工况：一台化工反应釜，设计压力 1.6 MPa，内径 1600 mm，材料 Q345R，双面焊对接接头局部无损检测，介质有轻微腐蚀性，腐蚀裕量取 2 mm。

输入：

  • σb = 510 MPa，σs = 345 MPa
  • nb = 2.7，ns = 1.5
  • P = 1.6 MPa，D = 1600 mm
  • φ = 0.85（双面焊局部检测）
  • C = 0.3 + 2 = 2.3 mm

计算过程：

  • [σ] = 188.89 MPa
  • δ = 1.6 × 1600 / (2 × 188.89 × 0.85 − 1.6) + 2.3
  • δ = 2560 / (321.11 − 1.6) + 2.3 = 2560 / 319.51 + 2.3 ≈ 8.01 + 2.3 = 10.31 mm

说明：考虑钢板规格，名义厚度可圆整为 12 mm 或 14 mm。

场景 3：高压容器（使用高强度材料）

工况：一台高压气体容器，设计压力 4.0 MPa，内径 800 mm，材料 16MnDR（低温用钢，此处仅示意），双面焊 100% 检测，腐蚀裕量 1 mm。

输入：

  • σb = 590 MPa，σs = 390 MPa（示意值，需查材料标准）
  • nb = 2.7，ns = 1.5
  • P = 4.0 MPa，D = 800 mm
  • φ = 1.0
  • C = 0.3 + 1 = 1.3 mm

计算过程：

  • [σ] = min(590/2.7, 390/1.5) = min(218.52, 260) = 218.52 MPa
  • δ = 4.0 × 800 / (2 × 218.52 × 1.0 − 4.0) + 1.3
  • δ = 3200 / (437.04 − 4.0) + 1.3 = 3200 / 433.04 + 1.3 ≈ 7.39 + 1.3 = 8.69 mm
场景 4：大直径低压容器

工况：一台大型常压偏低压的储罐，设计压力 0.1 MPa，内径 3000 mm，材料 Q235B，单面焊（无垫板），腐蚀裕量 2 mm。

输入：

  • σb = 370 MPa，σs = 235 MPa（示意值，需查材料标准）
  • nb = 2.7，ns = 1.5
  • P = 0.1 MPa，D = 3000 mm
  • φ = 0.65（单面焊，需查标准原文确认）
  • C = 0.3 + 2 = 2.3 mm

计算过程：

  • [σ] = min(370/2.7, 235/1.5) = min(137.04, 156.67) = 137.04 MPa
  • δ = 0.1 × 3000 / (2 × 137.04 × 0.65 − 0.1) + 2.3
  • δ = 300 / (178.15 − 0.1) + 2.3 = 300 / 178.05 + 2.3 ≈ 1.68 + 2.3 = 3.98 mm
场景 5：仅校核许用应力

工况：设计人员希望先确认某种材料的许用应力，再决定后续方案。材料 σb = 450 MPa，σs = 280 MPa，按 GB/T 150.1 最低安全系数。

输入：

  • σb = 450 MPa，σs = 280 MPa
  • nb = 2.7，ns = 1.5

计算结果：

  • σb/nb = 450/2.7 ≈ 166.67 MPa
  • σs/ns = 280/1.5 ≈ 186.67 MPa
  • [σ] = min(166.67, 186.67) = 166.67 MPa

说明：此例中由抗拉强度控制许用应力。设计人员可据此继续计算壁厚。

五、常见错误与排查

  1. 提示"安全系数低于标准规定"：检查 nb 是否小于 2.7 或 ns 是否小于 1.5。GB/T 150.1 对室温下碳钢、低合金钢规定了下限，低于此值工具将拒绝计算以保证合规性。
  2. 提示"分母非正，无法计算"：当 2·[σ]·φ − P ≤ 0 时公式无意义。通常是因为设计压力 P 过高、材料许用应力过低或焊接接头系数过小。应检查参数是否合理，或考虑更换更高强度材料、提高焊接检测比例。
  3. 提示"焊接接头系数超出范围"：φ 必须满足 0 < φ ≤ 1。φ = 0 表示焊缝完全不可靠，φ > 1 无物理意义。
  4. 计算结果异常偏大：检查单位是否一致（P 用 MPa、D 用 mm、[σ] 用 MPa），切勿混用 Pa 或 kPa。
  5. 计算结果异常偏小：可能是漏加了厚度附加量 C，或 φ 取值过高。注意计算壁厚 δ 并不等于名义厚度，还需圆整并满足最小壁厚要求。
  6. 输入为空或非数字：工具会对 null、undefined、NaN、空字符串等非法输入抛出异常，请确保所有参数均为有效数字。

六、数据来源与标准依据

  • GB/T 150.1-2011《压力容器 第1部分：通用要求》—— 内压圆筒壁厚计算公式、安全系数下限、焊接接头系数选取原则。
  • GB/T 150.2-2011《压力容器 第2部分：材料》—— 各类压力容器用钢的许用应力表。
  • GB/T 150.3-2011《压力容器 第3部分：设计》—— 详细设计规则（本工具未涉及封头、开孔补强等）。
  • GB/T 709《热轧钢板和钢带的尺寸、外形、重量及允许偏差》—— 钢板厚度负偏差 C₁ 的取值依据。
注：本工具中的材料强度示例值（如 Q345R 的 σb=510 MPa、σs=345 MPa）仅为演示用途，实际设计必须查阅最新版 GB/T 150.2 或相应材料标准获取准确数据。焊接接头系数 φ 的具体取值亦需按 GB/T 150.1 表 4 及接头形式、检测比例确定。

七、局限性说明

本工具功能聚焦、实现简洁，但存在以下局限，使用者应充分了解：

  1. 仅适用于内压圆筒：不适用于外压圆筒（需按 GB/T 150.1 外压稳定计算）、球形壳体、椭圆形/碟形/锥形封头、平盖等其它受压元件。
  2. 仅考虑室温强度：未考虑设计温度下材料许用应力的变化、高温蠕变、低温脆断等问题。高温工况应查 GB/T 150.2 中对应温度下的许用应力表。
  3. 未考虑载荷组合：实际容器除内压外，还可能承受风载荷、地震载荷、自重、热应力等，需按 GB/T 150.3 进行综合校核。
  4. 未进行刚度、稳定性校核：对大直径薄壁容器，可能由刚度或稳定性控制壁厚，而非强度。
  5. 未考虑开孔补强：容器上开孔后需按 GB/T 150.3 进行补强计算，本工具不涉及。
  6. 未考虑疲劳分析：承受交变载荷的容器需按 JB 4732 或 GB/T 150 的疲劳分析规定进行评定。
  7. 未考虑腐蚀除外的材料劣化：如氢腐蚀、应力腐蚀开裂等需专门评估。
  8. 计算结果非最终设计厚度：计算壁厚需向上圆整至钢板规格，并满足最小壁厚要求，最终名义厚度应由持证设计人员确定。
  9. 本工具不能替代持证设计：压力容器设计须由取得相应资质的单位和人员按《固定式压力容器安全技术监察规程》（TSG 21）等法规执行，本工具仅供学习、估算、方案比选参考。
重要提示：本工具为辅助计算工具，计算结果不得直接作为压力容器施工或报检依据。正式设计文件须由具备相应资质的设计单位出具，并经审批、校核。
