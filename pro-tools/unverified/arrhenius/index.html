一、公式概述与文献出处

阿伦尼乌斯方程（Arrhenius equation）由瑞典化学家 Svante Arrhenius 于 1889 年提出，是化学动力学中描述温度对反应速率常数影响的最基本经验公式。其原始文献为：

Arrhenius S. Über die Reaktionsgeschwindigkeit bei der Inversion von Rohrzucker durch Säuren. Z Phys Chem. 1889;4:226-248.

该方程的数学表达式为：

k = A · exp(−Ea / (R · T))

其中各符号含义如下：

符号含义单位说明
k反应速率常数取决于反应级数一级反应为 s⁻¹，二级为 L/(mol·s)
A指前因子（pre-exponential factor）与 k 相同也称频率因子，反映单位时间内有效碰撞的频率上限
Ea活化能（activation energy）J/mol反应物分子达到过渡态所需的最小能量
R理想气体常数8.314 J/(mol·K)CODATA 2018 推荐值
T热力学温度K必须为绝对温度，不可使用摄氏度直接代入

二、适用场景与不适用场景

2.1 适用场景

  • 基元反应（elementary reactions）：阿伦尼乌斯方程最初即为基元反应而推导，此时 Ea 具有明确的物理意义——即反应物到过渡态的势垒高度。
  • 多数总包反应（overall reactions）：在有限温度范围内（通常 ±50~100 K），许多复杂反应的表观速率常数也近似遵循阿伦尼乌斯关系，此时 Ea 为表观活化能。
  • 药物稳定性预测：在药物化学和制药工程中，加速稳定性试验（accelerated stability testing）广泛使用阿伦尼乌斯方程外推常温下的降解速率。ICH Q1A(R2) 指南中推荐了该方法。
  • 食品科学：食品保质期预测中常用阿伦尼乌斯模型描述温度对腐败反应速率的影响。
  • 材料科学：聚合物老化、金属腐蚀等过程的速率与温度关系常可用阿伦尼乌斯方程拟合。
  • 生物化学：酶促反应在有限温度范围内（通常在酶变性温度以下）的速率变化可用此方程描述。

2.2 不适用场景

  • 扩散控制反应（diffusion-controlled reactions）：当反应速率受限于反应物分子的扩散速度而非化学活化过程时，温度依赖关系偏离阿伦尼乌斯行为。扩散系数的温度依赖通常遵循 Stokes-Einstein 关系，其表观"活化能"远低于化学活化能。
  • 隧道效应显著的低温反应：在极低温度下（如星际化学中的某些反应），量子隧穿效应使反应速率不再遵循经典的阿伦尼乌斯温度依赖。
  • 复杂多步机理中温度范围过大时：若温度范围跨越了反应机理的改变点（如从动力学控制转为扩散控制），则单一阿伦尼乌斯拟合将失效，Arrhenius 图（ln k vs 1/T）会出现折线。
  • 酶变性温度以上：酶促反应在高温下酶蛋白变性失活，速率急剧下降，此时 Arrhenius 图出现明显转折。
  • 爆炸反应和链式反应：存在链分支和链终止的竞争，表观速率与温度的关系可能极为复杂。
  • 负活化能反应：某些自由基复合反应等表现出负活化能，虽然数学上阿伦尼乌斯方程仍可给出结果，但物理意义需要特别解释。

三、计算步骤逐步解释

3.1 正向计算模式

  1. 输入参数验证：检查 A > 0（指前因子必须为正数）、Ea 为有限实数（可以为零或负值，但需物理上合理）、T > 0 K（绝对温度必须为正）。若任一条件不满足，返回错误信息。
  2. 计算指数项：计算 −Ea/(R·T)。当 Ea = 0 时，指数项为 0，k = A，表示无活化能垒的反应。
  3. 计算 k 值：k = A × exp(−Ea/(R·T))。注意当 Ea/(R·T) 极大时（如 Ea > 10⁶ J/mol 且 T 较小），指数项趋近于零，k 可能下溢为 0。
  4. 计算半衰期：
    • 一级反应：t₁/₂ = ln(2)/k
    • 二级反应：t₁/₂ = 1/(k·[A]₀)
    • 零级反应：t₁/₂ = [A]₀/(2k)
  5. 温度对比：自动计算 ±10 K 和 ±20 K 温度下的 k 值，展示温度敏感性。

3.2 双温度反推模式

  1. 输入验证：k₁ > 0, k₂ > 0, T₁ > 0, T₂ > 0, T₁ ≠ T₂。
  2. 计算 Ea：由 ln(k₂/k₁) = −(Ea/R)·(1/T₂ − 1/T₁)，解得 Ea = −R·ln(k₂/k₁)/(1/T₂ − 1/T₁)。
  3. 计算 A：将 Ea 代回原方程，A = k₁/exp(−Ea/(R·T₁)) = k₁·exp(Ea/(R·T₁))。
  4. 验证：用得到的 Ea 和 A 计算 T₂ 下的 k 值，确认与输入的 k₂ 一致（数值精度范围内）。

四、临床/工程意义

4.1 药物稳定性与有效期预测

在制药工业中，阿伦尼乌斯方程是加速稳定性试验的理论基础。通过在较高温度（如 40°C、60°C）下测定药物降解速率常数，外推至室温（25°C）或冷藏温度（5°C），从而预测药物的有效期（shelf life）。ICH Q1A(R2) 指南规定了长期试验和加速试验的条件。本工具可帮助研究人员快速完成从加速数据到常温预测的计算。

需要注意的是，外推温度范围不宜过大（通常建议不超过 20-30°C），否则降解机理可能发生变化，导致预测失效。

4.2 化学反应工程

在化工过程设计中，反应速率常数的温度依赖性是反应器设计和优化的核心参数。通过阿伦尼乌斯方程，工程师可以：确定最佳反应温度窗口、评估温度波动对产率的影响、设计换热系统以维持恒温条件。

4.3 食品与化妆品保质期

食品科学中，阿伦尼乌斯模型用于预测不同储存温度下食品的变质速率。化妆品行业同样使用加速老化试验来评估产品在储存条件下的稳定性。

4.4 环境科学

污染物的环境降解速率（如水解、光解的暗反应部分）通常具有温度依赖性，阿伦尼乌斯方程可用于评估不同气候条件下的环境归趋。

五、已知局限与误差来源

  • 经验公式的固有局限：阿伦尼乌斯方程本质上是经验公式。虽然过渡态理论（Eyring 方程）为其提供了理论支撑，但严格来说，指前因子 A 本身可能具有微弱的温度依赖性（A ∝ T^n，n 通常为 0.5~1），在宽温度范围内可能引入偏差。
  • 活化能的温度依赖性：严格来说，Ea 可能随温度变化。在窄温度范围内这一变化可忽略，但在宽温度范围（>200 K）内可能导致 Arrhenius 图的非线性。
  • 实验数据误差：双温度反推模式中，k 值的测量误差会被放大。特别是当 T₁ 和 T₂ 接近时，1/T₂ − 1/T₁ 很小，分母接近零会导致 Ea 的计算结果极不稳定。
  • 数值精度限制：JavaScript 使用 IEEE 754 双精度浮点数（约 15-17 位有效数字）。当 Ea/(R·T) 极大（>700）时，exp 函数将下溢为 0；当 Ea/(R·T) 极小（<−700）时，exp 函数将溢出为 Infinity。
  • 机理变化的忽略：本工具假设在整个温度范围内反应机理不变。若实际存在机理转变，计算结果将不具有物理意义。

六、精度与误差说明

① 算准了什么

本工具在给定输入参数（A、Ea、T）完全准确且阿伦尼乌斯方程严格适用的前提下，计算结果在 IEEE 754 双精度浮点数的精度范围内（相对误差约 10⁻¹⁵ 量级）是准确的。即：数学运算本身是精确的。

② 哪些因素没算进去

  • 指前因子 A 的温度依赖性（T^n 修正项）
  • 活化能 Ea 随温度的变化
  • 压力对液相反应速率的影响
  • 溶剂效应对活化能和指前因子的影响
  • 催化剂失活或中毒导致的速率变化
  • 传质限制（外扩散、内扩散）对表观速率的影响
  • 反应机理随温度变化的可能性

③ 误差大概多大
