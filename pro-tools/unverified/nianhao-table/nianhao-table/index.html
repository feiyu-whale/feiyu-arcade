📚 数据来源

  • 方诗铭编《中国历史纪年表》，上海辞书出版社。该书为历代年号、帝王、公元对照之权威工具书。
  • 李崇智《中国历代年号考》，中华书局。对年号起讫、改元时间有详细考证。
  • 本表收录自西汉建元（前140）至清末宣统（1911）主要年号，部分政权（如十六国、五代十国、南明等）仅收录主要年号，完整数据请查阅上述标准原文。
  • ⚠️ 年号起讫年份在不同史料中偶有争议（如跨年改元、逾年改元之别），本表采用通行说法，具体细节请核对原典。
