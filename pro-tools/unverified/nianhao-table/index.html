年号纪年表 · 使用说明书

    
    
一、工具简介

    
「年号纪年表」是一款基于《中国历史纪年表》（方诗铭编，上海辞书出版社）的专业历史纪年查询工具。本工具收录了从西汉武帝建元元年（公元前140年）至清末宣统三年（公元1911年）共两千余年间的主要帝王年号，支持年号与公元纪年的双向换算，以及按朝代、帝王、年号的多维度检索。

    
本工具适用于历史研究者、古籍整理者、历史教师、学生及广大历史爱好者。在阅读古籍、研究历史事件、考证文物年代时，常需将年号纪年转换为公元纪年，或反之。本工具提供快速、准确的换算服务，免去翻阅纸质工具书之劳。

    
    
二、核心功能与参数说明

    
    
1. 年号转公元（eraToGongYuan）

    
功能：将年号纪年转换为公元纪年。

    
参数：

    
    
      
  • eraName（字符串，必填）：年号名称，如"贞观"、"康熙"。取值范围为工具收录的所有年号名。
    • 
      
  • year（正整数，必填）：该年号内的第几年。元年为1，依次递增。例如"贞观元年"的 year 为1。
    • 
    

    
返回值：公元年份（整数）。正数表示公元后，负数表示公元前。例如627表示公元627年，-140表示公元前140年。

    
异常：年号不存在、年数超出范围、参数类型错误时抛出异常。

    
    
2. 公元转年号（gongYuanToEra）

    
功能：将公元纪年转换为对应的年号纪年。

    
参数：

    
    
      
  • year（整数，必填）：公元年份。正数表示公元后，负数表示公元前。注意：公元纪年没有0年，公元前1年之后直接是公元1年。
    • 
    

    
返回值：对象，包含以下字段：

    
    
      
  • dynasty：朝代名
    • 
      
  • emperor：帝王名
    • 
      
  • era：年号名
    • 
      
  • startYear：该年号起始公元年
    • 
      
  • endYear：该年号结束公元年
    • 
      
  • yearInEra：该年在年号内是第几年
    • 
    

    
异常：年份为0、年份超出收录范围、参数类型错误时抛出异常。

    
    
3. 年号反查（searchEra）

    
功能：按关键字搜索年号、帝王、朝代。

    
参数：

    
    
      
  • keyword（字符串，必填）：搜索关键字。支持模糊匹配，可输入年号名（如"贞观"）、帝王名（如"太宗"）、朝代名（如"唐"）。
    • 
    

    
返回值：数组，包含所有匹配的年号记录，每条记录格式同 gongYuanToEra 的返回值。

    
    
4. 按朝代浏览（listByDynasty）

    
功能：列出指定朝代的所有年号。

    
参数：

    
    
      
  • dynasty（字符串，必填）：朝代名，如"唐"、"西汉"、"清"。
    • 
    

    
返回值：数组，包含该朝代所有年号记录。

    
    
5. 按帝王浏览（listByEmperor）

    
功能：列出指定帝王的所有年号。

    
参数：

    
    
      
  • emperor（字符串，必填）：帝王名，如"太宗"、"康熙帝"、"武帝"。
    • 
    

    
返回值：数组，包含该帝王所有年号记录。

    
    
三、实际使用场景

    
    
场景1：阅读古籍时换算年号

    
情境：阅读《资治通鉴》时遇到"贞观十五年"，需知对应公元何年。

    
操作：在"年号转公元"功能中，选择年号"贞观"，输入年数15，点击转换。

    
结果：显示"贞观十五年 = 公元641年"。计算过程：贞观元年为公元627年，627 + 15 - 1 = 641。

    
    
场景2：查询某公元年份的年号

    
情境：研究公元755年的历史事件（安史之乱），需知当时年号。

    
操作：在"公元转年号"功能中，输入755，点击转换。

    
结果：显示"公元755年 = 唐玄宗天宝十四年"。天宝元年为742年，755 - 742 + 1 = 14。

    
    
场景3：研究某帝王在位期间的年号变更

    
情境：研究汉武帝在位期间的年号使用情况。

    
操作：在"按帝王浏览"功能中，选择"武帝"，点击查询。

    
结果：列出汉武帝所有年号：建元（前140-前135）、元光（前134-前129）、元朔（前128-前123）、元狩（前122-前117）、元鼎（前116-前111）、元封（前110-前105）、太初（前104-前101）、天汉（前100-前97）、太始（前96-前93）、征和（前92-前89）、后元（前88-前87）。共11个年号，在位54年。

    
    
场景4：比较不同朝代的同名年号

    
情境：发现"建元"年号在多个朝代出现，需区分。

    
操作：在"年号反查"功能中，输入"建元"，点击搜索。

    
结果：列出所有"建元"年号：西汉武帝建元（前140-前135）、东晋康帝建元（343-344）等。可清楚看到不同朝代的"建元"对应不同公元年份。

    
    
场景5：历史教学辅助

    
情境：教师准备"唐朝历史"课程，需列出唐朝所有年号及对应帝王。

    
操作：在"按朝代浏览"功能中，选择"唐"，点击查询。

    
结果：列出唐朝所有年号，按时间顺序排列，包括高祖武德、太宗贞观、高宗永徽、玄宗开元天宝、代宗大历、德宗贞元、宪宗元和、武宗会昌、宣宗大中、僖宗乾符等，共约60个年号，涵盖唐朝近300年历史。

    
    
四、常见错误与排查

    
    
错误1：年号名输入错误

    
现象：提示"未找到年号"。

    
原因：年号名拼写错误，或使用了简称。

    
解决：使用完整年号名。如"康熙"而非"康"，"贞观"而非"贞"。可通过"年号反查"功能模糊搜索。

    
    
错误2：公元0年不存在

    
现象：输入0年时提示错误。

    
原因：公元纪年体系中没有0年。公元前1年（记为-1）之后直接是公元1年。

    
解决：公元前年份使用负数表示，如公元前140年输入-140。

    
    
错误3：年号重名混淆

    
现象：查询"建元"年号时，返回多个结果。

    
原因：历史上多个帝王使用过相同年号名。

    
解决：使用"年号反查"功能查看所有同名年号，结合朝代、帝王信息区分。或在"年号转公元"时注意选择正确的年号。

    
    
错误4：年数超出范围

    
现象：提示"年数超出范围"。

    
原因：输入的年数超过了该年号实际使用的年数。

    
解决：查看该年号的起止年份，确认实际使用年数。如"贞观"共23年（627-649），输入年数不能超过23。

    
    
错误5：参数类型错误

    
现象：提示参数类型错误。

    
原因：传入了null、undefined、NaN等非预期类型。

    
解决：确保传入正确类型的参数。年号名为字符串，年数为正整数，公元年份为整数。

    
    
五、数据来源与标准依据

    
本工具的数据主要依据以下权威资料：

    
    
      
  • 《中国历史纪年表》，方诗铭编，上海辞书出版社出版。这是国内最权威的历史纪年工具书之一，被广泛应用于历史研究、古籍整理、历史教学等领域。
    • 
      
  • 《二十四史》各帝本纪中的年号记载。
    • 
      
  • 《资治通鉴》中的年号纪年。
    • 
    

    
关于国家标准，目前中国尚未发布专门针对历史纪年换算的国家标准（GB）。本工具的数据以学术权威著作为准，力求准确。对于部分存在争议的年号（如某些年号的起止年份在不同史料中有出入），本工具采用《中国历史纪年表》的记载。如需查证原始史料，建议查阅相关正史本纪。

    

      注：部分年号的使用时间在不同史料中可能存在细微差异（如改元的具体月份），本工具以年份为单位，不涉及月份级别的精度。如需更精确的日期换算，需查标准原文。
    

    
    
六、局限性说明

    
本工具虽然力求全面准确，但仍存在以下局限性，使用者需注意：

    
    
1. 收录范围有限

    
本工具主要收录中原王朝及主要割据政权的年号，对于以下情况未完全收录：

    
    
      
  • 部分少数民族政权（如吐蕃、南诏、大理等）的年号收录不全。
    • 
      
  • 农民起义政权（如黄巾、黄巢、李自成、太平天国等）的年号未收录或收录不全。太平天国虽存在14年，但以其国号纪年，无传统年号。
    • 
      
  • 伪政权（如伪满洲国、汪伪政权等）的年号未收录。
    • 
    

    
    
2. 年号重名问题

    
历史上存在多个年号重名的情况（如"建元"、"建兴"、"永和"等在不同朝代多次使用）。本工具在"年号转公元"时返回第一个匹配结果，可能不是用户期望的那个。建议结合朝代、帝王信息确认。

    
    
3. 精度限制

    
本工具以"年"为最小单位，不涉及月、日级别的换算。部分年号改元发生在年中（如某年七月改元），该年可能同时属于两个年号。本工具按整年处理，不区分月份。

    
    
4. 特殊纪年方式

    
部分时期使用特殊纪年方式，本工具未完全支持：

    
    
      
  • 西汉武帝之前使用帝王在位年数纪年（如"某王某年"），未收录。
    • 
      
  • 西周共和行政时期（前841-前828）使用"共和"纪年，未收录。
    • 
      
  • 民国时期使用"民国"纪年（1912-1949），本工具仅收录"民国"作为一个特殊年号。
    • 
    

    
    
5. 数据准确性

    
尽管本工具力求准确，但历史纪年本身存在争议。部分年号的起止年份在不同史料中有出入，本工具采用《中国历史纪年表》的记载。如需最权威的数据，建议查阅原始史料或专业工具书。

    
    

      重要提示：本工具仅供学习研究参考，不作为学术引用的最终依据。对于重要的历史研究，建议查阅原始史料或专业学术著作。
    

    
    
七、技术实现说明

    
本工具采用纯 JavaScript 实现，不依赖任何外部库，可直接在浏览器中运行。核心算法包括：

    
    
      
  • 年号转公元：通过查找年号记录，计算 startYear + year - 1 得到公元年份。
    • 
      
  • 公元转年号：遍历所有年号记录，查找 startYear ≤ year ≤ endYear 的记录。
    • 
      
  • 年号反查：对年号名、帝王名、朝代名进行模糊匹配。
    • 
    

    
所有函数均包含完整的 JSDoc 注释，并通过41个单元测试用例验证，覆盖正常值、边界值、异常输入等场景。
