一、工具简介

  
「中文文本可读性分析工具」是一个纯前端 JavaScript 工具，用于对中文文本进行基础可读性量化分析。它解决的核心问题是：如何在不依赖外部服务的前提下，快速得到一段中文文本在"长度、句式、用字多样性、难度等级"四个维度上的客观指标。

  
典型使用场景包括：语文教师评估课文难度、内容编辑判断文章是否适合目标读者、家长判断绘本或读物是否匹配孩子年级、开发者为内容管理系统增加"阅读难度"标签、研究人员做语料预处理等。

  
本工具不依赖任何第三方库，所有计算在浏览器本地完成，文本不会上传到任何服务器。


  
二、输出指标与参数说明

  

    
指标含义单位 / 取值计算方式

    
总字数 totalChars文本中所有非空白字符的数量个，≥0 整数去除 \s 后字符长度

    
汉字数 chineseChars属于 CJK 统一汉字基本区的字符数个，≥0 整数匹配 [\u4e00-\u9fff]

    
标点数 punctuation中英文标点总数个，≥0 整数匹配预定义标点字符集

    
句数 sentences以句末标点切分得到的句子数句，≥0 整数按 。！？… 切分并过滤空段

    
平均句长 avgSentenceLength每句平均汉字数字/句，浮点数chineseChars / sentences；句数为 0 时返回 NaN

    
词汇丰富度 lexicalRichness不同汉字占总汉字的比例（type-token ratio）[0, 1] 浮点数uniqueChinese / chineseChars；汉字数为 0 时返回 NaN

    
常用字比例 commonCharRatio汉字中属于内置常用字表的比例[0, 1] 浮点数命中常用字表的汉字数 / 汉字数

    
难度分级 difficultyLevel综合平均句长与常用字比例得到的等级1~5 整数，或 null见下文分级规则

  


  
难度分级规则

  
分级同时参考两个维度：平均句长（反映句式复杂度）与常用字比例（反映用字难度）。取两者中较高等级作为最终等级，避免单一指标失真。

  

    
等级适用对象平均句长常用字比例

    
1小学低年级（1~2 年级）≤ 10≥ 0.95

    
2小学中高年级（3~6 年级）≤ 15≥ 0.90

    
3初中≤ 20≥ 0.80

    
4高中 / 一般读物≤ 28≥ 0.70

    
5大学 / 专业文献> 28 或 < 0.70< 0.70

  

  
说明：上述阈值参考了《义务教育语文课程标准（2022 年版）》对各学段识字量与阅读量的要求，以及国家汉办《汉语水平词汇与汉字等级大纲》的分级思路，但并非直接引用某一条国标条款。如需用于正式学术或出版场景，需查标准原文并做本地化校准。


  
三、实际使用场景


  
场景 1：评估小学低年级课文

  
输入："小鸟飞。小花开了。太阳出来了。"

  
预期结果：汉字数 11，句数 3，平均句长 ≈ 3.67，词汇丰富度 ≈ 0.91（10 个不同字 / 11 字），常用字比例 1.0，难度等级 = 1。

  
解读：句短、字常用，符合低年级阅读材料特征。


  
场景 2：评估中学语文课文片段

  
输入："曲曲折折的荷塘上面，弥望的是田田的叶子。叶子出水很高，像亭亭的舞女的裙。"（朱自清《荷塘月色》节选）

  
预期结果：汉字数约 38，句数 2，平均句长约 19，词汇丰富度约 0.79，常用字比例约 0.95，难度等级 = 3。

  
解读：句式较长但用字仍较常用，符合初中至高中过渡段难度。


  
场景 3：评估专业论文摘要

  
输入：一段含"熵""卷积""特征向量"等术语的摘要（约 120 字，3 句）。

  
预期结果：平均句长约 40，常用字比例可能降至 0.65 左右，难度等级 = 5。

  
解读：术语密集、句式复杂，符合专业文献特征。


  
场景 4：判断绘本是否适合 5 岁儿童

  
输入："妈妈爱我。我爱妈妈。"

  
预期结果：汉字数 8，句数 2，平均句长 4，词汇丰富度 0.375（3 个不同字 / 8 字），常用字比例 1.0，难度等级 = 1。

  
解读：极低难度，适合学龄前亲子共读。注意：词汇丰富度低在这里是优点（重复强化），不代表文本质量差。


  
场景 5：内容管理系统批量打标

  
输入：CMS 后台对每篇文章调用 analyzeReadability(article.body)，将返回的 difficultyLevel 写入数据库字段 reading_grade。

  
预期结果：每篇文章得到一个 1~5 的整数标签，前端据此筛选"适合小学三年级"的文章。

  
解读：工具返回纯数据，便于集成；但需人工抽检，避免分级误判。


  
四、常见错误与排查

  

    
现象原因处理

    
返回 NaN输入为空字符串或不含汉字调用前先判空；句数/汉字数为 0 时 avgSentenceLength 与 lexicalRichness 按设计返回 NaN

    
汉字数比预期少文本含繁体字或 CJK 扩展区字（如"𪚥"）当前仅识别基本区 \u4e00-\u9fff，扩展区需另行扩展正则

    
句数异常多文本中大量使用省略号 …… 或感叹号省略号按两个字符计，但作为句末标点只计一次；可结合业务调整

    
难度等级偏高文本含大量专有名词、人名、地名常用字表未收录专有名词，会拉低常用字比例；这是工具局限，非 bug

    
传入 null 报错未做入参校验函数内部对非字符串输入会抛出 TypeError，调用方需先 typeof text === 'string'

  


  
五、数据来源与标准依据

  
    
    
  • 常用字表：内置约 800 个高频汉字，来源为《现代汉语常用字表》（国家语委 1988 年发布）前 800 字的简化采样。完整版需查原表，本工具未做全量收录。
    • 
    
  • 分级思路：参考《义务教育语文课程标准（2022 年版）》（教育部发布，课程标〔2022〕1 号）对各学段识字量与阅读量的描述，以及国家汉办《汉语水平词汇与汉字等级大纲》（1992）的分级框架。
    • 
    
  • 词汇丰富度（TTR）：语言学通用指标 type-token ratio，非中国独有标准。
    • 
    
  • 平均句长：可读性研究通用指标，参考英文 Flesch  Reading Ease 的句长维度，结合汉语特点以"汉字数/句"为单位。
    • 
  

  
严谨性声明：本工具的分级阈值是工程化近似，未直接对应某一条强制性国家标准条款。如需用于教材审定、出版分级等正式场景，建议以课程标准原文为准并做本地化回归测试。


  
六、局限性说明

  
    
    
  1. 不评估语义难度：工具只看字面统计，无法判断"概念是否抽象""逻辑是否复杂"。同样字数的句子，"猫跳了"与"量子纠缠"难度天差地别，工具无法区分。
    2. 
    
  2. 常用字表不完整：仅内置约 800 字，远低于《通用规范汉字表》一级字表的 3500 字。对高中以上文本，常用字比例会系统性偏低。
    3. 
    
  3. 不识别繁体字与扩展区汉字：正则仅覆盖 CJK 基本区，港澳台文本、古籍文本统计会偏低。
    4. 
    
  4. 不处理特殊排版：HTML 标签、Markdown 符号、Emoji 会被计入"总字数"但不计入"汉字数"，调用方需先做清洗。
    5. 
    
  5. 句数切分规则简化：仅按 。！？… 切分，不处理引号内嵌套句、对话分行等复杂情况。
    6. 
    
  6. 未做分词："词汇丰富度"实际是"字丰富度"，不是真正的词丰富度。汉语分词需要词典或模型，本工具未实现。
    7. 
    
  7. 分级阈值未经大规模语料回归：当前阈值为经验值，未在不同文体（新闻、小说、论文、公文）上做过系统性校准。
    8. 
    
  8. 不支持其他语言：仅针对中文设计，英文、日文、韩文文本结果无意义。
    9.
