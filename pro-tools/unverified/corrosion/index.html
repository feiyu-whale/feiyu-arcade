一、工具用途

  
本工具用于按失重法计算金属材料的腐蚀速率，并依据十级耐蚀标准进行评级。适用于实验室腐蚀试验数据处理、工程材料选型、腐蚀寿命评估、腐蚀防护方案制定等场景。

  
计算依据为 GB/T 19292《金属和合金的腐蚀 大气环境腐蚀性分类》系列标准及 HB/Z 101 航空工业指导性技术文件中关于失重法的相关规定。工具输出两个核心结果：

  
    
    
  1. 腐蚀速率：单位 mm/a（毫米每年），表征材料在特定环境下的平均腐蚀速度
    2. 
    
  2. 耐蚀等级：1-10级，1级最优（完全耐蚀），10级最差（完全不耐蚀）
    3. 
  

  

    适用场景：大气腐蚀、海水浸泡、化工介质腐蚀、高温氧化等均匀腐蚀场景的初步评估。
  


  
二、参数详解

  
  
2.1 失重 ΔW（单位：g）

  
失重是指试样在腐蚀前后质量的差值，是计算腐蚀速率的核心参数。测量方法如下：

  
    
    
  • 腐蚀前称重：试样经清洗、干燥后称重，记为 W₀
    • 
    
  • 腐蚀后称重：去除腐蚀产物后称重，记为 W₁
    • 
    
  • 失重计算：ΔW = W₀ - W₁
    • 
  

  
注意事项：

  
    
    
  • 失重必须 ≥ 0，若为负值说明测量有误或腐蚀产物未清除干净
    • 
    
  • 称重精度建议达到 0.1 mg（0.0001 g），使用校准过的分析天平
    • 
    
  • 腐蚀产物清除方法需按标准执行（如化学清洗、机械清理等），避免损伤基体
    • 
  


  
2.2 试样面积 A（单位：cm²）

  
试样面积指与腐蚀介质接触的总表面积。对于规则试样：

  
    
    
  • 平板试样：A = 2 × (长×宽 + 长×厚 + 宽×厚)
    • 
    
  • 圆柱试样：A = 2πr² + 2πrh（r为半径，h为高度）
    • 
    
  • 其他形状：按几何公式计算所有暴露表面
    • 
  

  
注意事项：

  
    
    
  • 必须计算所有暴露表面，不能只算单面或忽略侧面
    • 
    
  • 面积单位必须是 cm²，若测量值为 mm² 需除以 100 转换
    • 
    
  • 面积必须 > 0，否则公式无意义
    • 
  


  
2.3 暴露时间 T（单位：h）

  
试样在腐蚀介质中的总暴露时间，单位为小时。

  
注意事项：

  
    
    
  • 时间单位必须是小时，若为天数需乘以 24，若为分钟需除以 60
    • 
    
  • 时间必须 > 0
    • 
    
  • 对于间歇暴露试验，应累计总暴露时间
    • 
    
  • 长期试验需考虑时间记录的准确性
    •

常见金属密度参考值：

碳钢7.85

    
不锈钢（304）7.93

注意事项：

  
    
    
  • 密度必须 > 0
    • 
    
  • 合金密度需按实际成分计算或查材料手册，不能简单用纯金属密度代替
    • 
    
  • 对于未知材料，建议实测密度
    • 
  


  
三、使用场景


  
场景1：大气暴露试验评估

  
某工程需在沿海地区使用碳钢构件，进行大气暴露试验：

  
    
    
  • 试样尺寸：50mm × 30mm × 2mm
    • 
    
  • 暴露时间：8760 h（1年）
    • 
    
  • 腐蚀前质量：23.5000 g
    • 
    
  • 腐蚀后质量（除锈后）：23.3800 g
    • 
  

  
计算过程：

  
    
    
  • 面积 A = 2 × (5×3 + 5×0.2 + 3×0.2) = 2 × (15 + 1 + 0.6) = 33.2 cm²
    • 
    
  • 失重 ΔW = 23.5000 - 23.3800 = 0.1200 g
    • 
    
  • 密度 ρ = 7.85 g/cm³
    • 
    
  • 腐蚀速率 v = 8.76×10⁴ × 0.12 / (33.2 × 8760 × 7.85) ≈ 0.0347 mm/a
    • 
    
  • 评级：3级（耐蚀）
    • 
  

  
结论：该碳钢在沿海大气环境下耐蚀性良好，可用于一般工程结构，但需定期检测。


  
场景2：海水浸泡试验对比

  
对比三种材料在海水中的耐蚀性：

  

    
材料腐蚀速率 (mm/a)耐蚀等级评价

    
碳钢0.454级较耐蚀

    
304不锈钢0.0082级很耐蚀

    
铜合金0.0253级耐蚀

  

  
结论：304不锈钢耐蚀性最优，铜合金次之，碳钢最差。对于海水环境关键部件，应优先选用不锈钢。


  
场景3：化工介质腐蚀评估

  
某化工设备需接触酸性介质，进行挂片试验：

  
    
    
  • 试样面积：20 cm²
    • 
    
  • 暴露时间：720 h（30天）
    • 
    
  • 失重：0.85 g
    • 
    
  • 材料密度：7.93 g/cm³
    • 
  

  
计算：

  
    
    
  • v = 8.76×10⁴ × 0.85 / (20 × 720 × 7.93) ≈ 6.55 mm/a
    • 
    
  • 评级：7级（不耐蚀）
    • 
  

  
结论：该材料在此酸性介质中不耐蚀，需更换材料或采取防腐措施（如涂层、阴极保护等）。


  
场景4：高温氧化评估

  
某高温部件在 600°C 空气中长期运行：

  
    
    
  • 试样面积：15 cm²
    • 
    
  • 暴露时间：2000 h
    • 
    
  • 失重：0.03 g（假设已转换为失重）
    • 
    
  • 材料密度：7.85 g/cm³
    • 
  

  
计算：

  
    
    
  • v = 8.76×10⁴ × 0.03 / (15 × 2000 × 7.85) ≈ 0.0112 mm/a
    • 
    
  • 评级：3级（耐蚀）
    • 
  

  
结论：该材料在高温氧化环境下耐蚀性良好，可用于高温部件。

为某工程选材，对比四种候选材料：

四、常见错误


  
错误1：单位不统一

  
最常见错误是单位混乱：

  
    
    
  • 面积用 mm² 而非 cm²（需除以100转换）
    • 
    
  • 时间用天而非小时（需乘以24转换）
    • 
    
  • 密度用 kg/m³ 而非 g/cm³（需除以1000转换）
    • 
  

  
修正：统一使用 g、cm²、h、g/cm³。


  
错误2：面积计算错误

  
常见错误：

  
    
    
  • 只计算单面面积，忽略侧面和背面
    • 
    
  • 未考虑试样形状，用简单公式代替
    • 
    
  • 单位转换错误
    • 
  

  
修正：计算所有暴露表面的总面积，注意单位转换。


  
错误3：腐蚀产物未清除

  
问题：

  
    
    
  • 腐蚀后称重包含腐蚀产物，导致失重偏小，计算结果偏低
    • 
    
  • 清除腐蚀产物时损伤基体，导致失重偏大，计算结果偏高
    • 
  

  
修正：按标准方法（如 GB/T 19292 规定）清除腐蚀产物，必要时使用缓蚀剂保护基体。


  
错误4：密度取值不准

  
问题：

  
    
    
  • 使用纯金属密度代替合金密度
    • 
    
  • 未考虑材料实际成分和热处理状态
    • 
  

  
修正：按实际材料成分查密度，或实测密度。


  
错误5：忽略边缘效应

  
问题：

  
    
    
  • 试样边缘腐蚀速率可能不同于表面
    • 
    
  • 小试样边缘占比大，误差更大
    • 
  

  
修正：使用足够大的试样，或单独评估边缘效应。

六、精度与误差说明

  

    重要提示：现实变量是无限的，本工具只做到"方法准、输入项准、结果给误差范围"，不承诺绝对精确。禁止使用"精确计算""绝对准确""100% 无误"等表述。
  


  
6.1 算准了什么

  
本工具在以下方面是准确的：

  
    
    
  • 数学计算：按给定公式精确计算，无算法误差（在浮点数精度范围内）
    • 
    
  • 单位换算：K = 8.76×10⁴ 是精确的单位换算常数
    • 
    
  • 评级逻辑：按十级标准严格划分等级，逻辑无误
    • 
    
  • 输入验证：对非法输入（负数、零、NaN等）进行严格校验
    • 
  


  
6.2 哪些因素没算进去

  
本工具未考虑以下实际因素：

  
    
    
  • 测量误差：称重、面积测量、时间记录都有误差
    • 
    
  • 材料不均匀性：实际材料成分、组织可能不均匀
    • 
    
  • 环境波动：温度、湿度、介质浓度可能变化
    • 
    
  • 局部腐蚀：点蚀、缝隙腐蚀等局部腐蚀无法用平均速率表征
    • 
    
  • 腐蚀产物影响：腐蚀产物可能阻碍或加速腐蚀
    • 
    
  • 时间效应：腐蚀速率可能随时间变化（加速或减速）
    • 
    
  • 应力影响：应力腐蚀、腐蚀疲劳等未考虑
    • 
    
  • 多因素耦合：多种腐蚀因素共同作用时的协同效应
    • 
  


  
6.3 误差大概多大

  
按误差传递公式，若各参数相对误差为：

  
    
    
  • 失重：±1%
    • 
    
  • 面积：±2%
    • 
    
  • 时间：±1%
    • 
    
  • 密度：±1%
    • 
  

  
则腐蚀速率的相对误差约为 ±5%。

  
实际应用中，由于上述未考虑因素，总误差可能达到 ±10% ~ ±30%，甚至更大。对于复杂环境或不均匀腐蚀，误差可能超过 ±50%。

  
  

    使用建议：
    
    
      
  • 本工具提供的是估算值，不是精确值
    • 
      
  • 结果应视为参考，不能用于精确设计
    • 
      
  • 关键工程应用需结合实测数据和专家判断
    • 
      
  • 建议使用误差范围计算功能评估结果可靠性
    • 
    

  


  
七、局限性

  
    
    
  1. 仅适用于均匀腐蚀：对于局部腐蚀（点蚀、缝隙腐蚀等），平均腐蚀速率不能反映真实情况，需结合最大腐蚀深度等指标。
    2. 
    
  2. 仅适用于失重法：其他方法（如电化学法、增重法、容量法）需使用相应公式，本工具不适用。
    3. 
    
  3. 仅适用于稳态腐蚀：腐蚀速率随时间变化的情况，本工具只能给出平均值，不能反映变化趋势。
    4. 
    
  4. 评级标准简化：十级标准是简化模型，实际工程需结合具体标准要求和应用场景判断。
    5. 
    
  5. 不考虑协同效应：多种腐蚀因素共同作用时，实际腐蚀可能更严重，本工具未考虑。
    6. 
    
  6. 数据依赖输入质量：输入数据不准确，结果必然不准确（"垃圾进，垃圾出"）。
    7. 
    
  7. 不替代专业判断：本工具是辅助工具，不能替代腐蚀专家的专业判断和工程经验。
    8. 
    
  8. 不适用于极端条件：超高温、超高压、强辐射等极端条件下的腐蚀行为可能偏离本模型。
    9.
