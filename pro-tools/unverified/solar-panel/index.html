一、工具用途



  本工具用于在规划阶段对并网光伏电站的年发电量进行快速估算。输入装机容量（kWp）、当地峰值日照时数（h/年）、系统效率（PR，无量纲），即可得到年发电量的估算值与误差范围。




  适用对象：项目前期可行性研究、投资回报粗算、方案比选、教学演示。不适用于施工图设计、并网验收、电费结算等需要精确数据的场景。




二、核心公式


本工具采用的核心公式为：



  E = P × H × PR



    
  
  • E：年发电量，单位 kWh（千瓦时，即"度"）
    • 
  
  • P：装机容量，单位 kWp（峰值功率，STC 条件下）
    • 
  
  • H：年峰值日照时数，单位 h（等价于年总辐射量 kWh/m²，因为 1 kW/m² × 1 h = 1 kWh/m²）
    • 
  
  • PR：Performance Ratio，系统效率，取值 0–1
    • 




  该公式是光伏行业通用的简化估算模型，在 IEC 61724-1:2017《Photovoltaic system performance monitoring – Guidelines for measurement, data exchange and analysis》以及国内 GB/T 50797-2012《光伏发电站设计规范》中均有对应表述（具体条款号需查标准原文）。




三、参数详解



3.1 装机容量 P（kWp）



  指光伏组件在标准测试条件（STC：辐照度 1000 W/m²、电池温度 25°C、AM1.5 光谱）下的标称功率总和。例如一块 550 Wp 的组件 20 块，总装机容量为 11 kWp。




  取值要求：必须为正数，单位 kWp。若以 Wp 输入需先除以 1000 转换。




3.2 峰值日照时数 H（h/年）



  定义：将当地全年实际接收到的太阳总辐射量（kWh/m²）等效为标准辐照度 1 kW/m² 下的小时数。例如某地年总辐射量为 1500 kWh/m²，则 H = 1500 h。




  数据来源：



    
  
  • 中国气象局太阳能资源数据（需申请）
    • 
  
  • NASA POWER 数据库（power.larc.nasa.gov，免费）
    • 
  
  • Meteonorm、PVGIS 等商业/开源工具
    • 
  
  • GB/T 31155-2014《太阳能资源等级 总辐射》中给出的中国各地资源区划可作为参考
    • 




  注意：本工具不内置任何地区的辐射数据，避免数据过期或不适用于具体场址。用户需自行查询权威数据源。




3.3 系统效率 PR（Performance Ratio）



  PR 是光伏系统实际输出能量与理论最大输出能量之比，综合反映了所有损失。依据 IEC 61724-1:2017 定义：




  PR = Yf / Yr = (Eactual / P) / (H)




  典型取值范围：




  
系统类型PR 参考范围说明

  
大型地面电站（良好维护）0.80 – 0.86需查 IEC 61724-1 实测统计

  
工商业分布式0.78 – 0.84屋顶温度较高，PR 偏低

  
户用小型系统0.75 – 0.82设备档次与维护水平差异大





  PR 的主要构成损失包括：组件温度损失、组件衰减、灰尘遮挡、逆变器转换损失、直流/交流线损、阴影遮挡、弱光损失、失配损失等。本工具提供 calculatePerformanceRatio(lossFactors) 函数，可由用户按分项损失累加得到 PR。




四、使用场景（5 例）



场景 1：户用屋顶初步估算



  用户：华北某地居民，屋顶可装 10 kWp，想了解一年能发多少电。

  输入：P = 10 kWp，H = 1200 h（华北典型值，需查当地数据），PR = 0.80。

  输出：E = 10 × 1200 × 0.80 = 9600 kWh/年，考虑 ±10% 误差范围为 8640 – 10560 kWh/年。




场景 2：工商业项目方案比选



  用户：工厂屋顶 500 kWp，比较两种组件方案。

  方案 A：H = 1100 h，PR = 0.82 → E = 451,000 kWh

  方案 B：H = 1100 h，PR = 0.84 → E = 462,000 kWh

  结论：方案 B 年多发电约 1.1 万度，可据此评估组件溢价是否合理。




场景 3：投资回报粗算



  用户：1 MW 地面电站，当地 H = 1400 h，PR = 0.83，电价 0.35 元/kWh。

  E = 1000 × 1400 × 0.83 = 1,162,000 kWh ≈ 116.2 万度/年。

  年收入 ≈ 40.67 万元。可进一步结合投资成本估算回收期（需另算，本工具不含财务模型）。




场景 4：由分项损失推导 PR



  用户已知：温度损失 8%、衰减 2%、灰尘 3%、逆变器 3%、线损 2%、阴影 1%。

  调用 calculatePerformanceRatio({temperature:0.08, degradation:0.02, soiling:0.03, inverter:0.03, wiring:0.02, shading:0.01})

  总损失 = 0.19，PR = 0.81。再代入主公式计算发电量。




场景 5：敏感性分析



  用户想了解 PR 每变化 1% 对发电量的影响。

  固定 P = 100 kWp，H = 1300 h，PR 从 0.78 到 0.85 遍历，调用 estimateRange 得到每个点的 ±10% 区间，绘制曲线即可。




五、常见错误


    
  
  1. 单位混淆：把 Wp 当 kWp 输入（差 1000 倍），或把 MW 当 kW。务必先统一单位。
    2. 
  
  2. 把"日照小时数"当"峰值日照时数"：气象预报的"晴天 10 小时"是日照时数，不等于峰值日照时数。后者需由总辐射量换算。
    3. 
  
  3. PR 取值过高：超过 0.90 的 PR 在现实中极为罕见，通常意味着输入有误或损失考虑不全。
    4. 
  
  4. 忽略温度损失：高温地区 PR 会显著下降，直接套用 0.85 会高估发电量。
    5. 
  
  5. 使用过期辐射数据：辐射数据应使用至少 10 年以上长期平均值，单年数据波动大。
    6. 
  
  6. 把估算当结算：本工具结果不能用于电费结算、补贴申报、合同承诺。
    7. 




六、数据依据


    
  
  • IEC 61724-1:2017：光伏系统性能监测国际标准，定义了 PR、Yf、Yr 等核心指标。
    • 
  
  • GB/T 50797-2012：《光伏发电站设计规范》，国内光伏电站设计的权威标准，包含发电量计算方法。
    • 
  
  • GB/T 31155-2014：《太阳能资源等级 总辐射》，用于中国太阳能资源区划。
    • 
  
  • NASA POWER：美国航空航天局提供的全球气象与辐射数据，免费公开。
    • 




  上述标准的具体条款号、PR 推荐值、辐射数据精度等细节，需查标准原文，本说明书不作转述以避免断章取义。




七、精度与误差说明（有限精准原则）



  核心声明：现实世界的光伏发电受无限多变量影响（分钟级辐照波动、组件个体差异、局部微气候、灰尘累积曲线、逆变器 MPPT 跟踪精度、电网限电……），本工具不承诺绝对精确，仅做到"方法准、输入项准、结果给误差范围"。




7.1 算准了什么


    
  
  • 算术计算本身：在 IEEE 754 双精度浮点范围内，P × H × PR 的数学结果是准确的。
    • 
  
  • 输入校验：对非法输入（负数、NaN、越界 PR 等）能正确拒绝并报错。
    • 
  
  • 单位换算与格式化：kWh / MWh / GWh 的换算逻辑无误。
    • 




7.2 哪些因素没算进去


    
  
  • 逐时辐照变化与温度耦合效应（需 PVsyst、SAM 等专业软件）
    • 
  
  • 组件年衰减曲线（首年衰减与后续年衰减不同）
    • 
  
  • 积雪、沙尘暴、鸟粪等偶发事件
    • 
  
  • 电网限电、检修停机
    • 
  
  • 双面组件背面增益、跟踪支架增益
    • 
  
  • 具体场址的微地形、微气候
    • 




7.3 误差大概多大



  在输入数据质量良好的前提下（辐射数据为 10 年以上月均值、PR 由实测或详细分项推导），年发电量估算的典型误差范围为 ±10% 至 ±15%。若辐射数据仅取单年或 PR 凭经验拍脑袋，误差可能扩大到 ±20% 甚至更大。




  本工具默认提供 ±10% 的误差区间（可通过 estimateRange 的 tolerance 参数调整），用户应结合项目实际情况判断该区间是否合理。




八、局限性


    
  
  1. 仅适用于并网光伏系统：离网系统涉及蓄电池充放电效率、负载特性，本公式不适用。
    2. 
  
  2. 仅做年发电量估算：不提供逐月、逐日、逐时输出，无法分析自发自用比例、峰谷电价匹配。
    3. 
  
  3. 不含财务模型：不计算投资回收期、IRR、LCOE，需另行建模。
    4. 
  
  4. 不含设备选型：不推荐具体组件、逆变器型号。
    5. 
  
  5. 不含结构设计：不计算风载、雪载、支架强度。
    6. 
  
  6. 不含电气设计：不计算电缆截面、保护配置。
    7. 
  
  7. 不替代专业软件：对于大型电站或复杂场景，应使用 PVsyst、SAM、Meteonorm 等专业工具进行详细模拟。
    8. 





  最终提醒：本工具为教学与前期估算用途。任何涉及合同签订、融资决策、并网申请的正式文件，必须由具备资质的设计单位依据现行国家标准出具，不可仅凭本工具结果。
