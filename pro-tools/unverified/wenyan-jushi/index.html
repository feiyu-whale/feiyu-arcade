📜 文言特殊句式识别

判断句 · 被动句 · 宾语前置 · 状语后置 · 定语后置

🔍 句式速查

📘 判断句

常见格式：
① …者，…也。
② …，…也。
③ …者，…。
④ 用副词"乃、即、则、皆、必、素、诚"等表判断。
⑤ 用动词"为、是"表判断（"是"作判断词较晚起）。
《史记·陈涉世家》
陈胜者，阳城人也。
解析："…者，…也"式判断句。"者"表提顿，"也"表判断语气。译为：陈胜是阳城人。
《史记·项羽本纪》
此亡秦之续也。
解析："…，…也"式。句末"也"表判断。译为：这是已亡的秦朝的延续。
《三国志·诸葛亮传》
诸葛孔明者，卧龙也。
解析："…者，…也"式判断句。译为：诸葛孔明是卧龙。
《史记·项羽本纪》
吾令人望其气，乃龙虎，成五彩。
解析：用副词"乃"表判断，相当于"是、就是"。

📘 被动句

常见格式：
① 为 + 施事 + 所 + 动词（为…所…）
② 见 + 动词 + 于 + 施事（见…于…）
③ 为 + 施事 + 动词
④ 于 + 施事（动词 + 于…）
⑤ 被 + 动词（后起）
⑥ 无标志的语义被动（意念被动）
《史记·项羽本纪》
不者，若属皆且为所虏。
解析："为所…"式，"为"后省略施事"之"。译为：你们都将被（他）俘虏。
《史记·廉颇蔺相如列传》
臣诚恐见欺于王而负赵。
解析："见…于…"式。"见"表被动，"于"引出施事"王"。译为：我实在怕被大王欺骗而辜负赵国。
《韩非子·五蠹》
兔不可复得，而身为宋国笑。
解析："为 + 施事 + 动词"式。译为：而自身被宋国人嘲笑。
《史记·屈原贾生列传》
内惑于郑袖，外欺于张仪。
解析："动词 + 于 + 施事"式。"于"引出动作的发出者。译为：在内被郑袖迷惑，在外被张仪欺骗。

📘 宾语前置

三种主要情况：
① 疑问句中，疑问代词（谁、孰、何、胡、曷、安、恶）作宾语，前置。
② 否定句中，代词（余、吾、尔、之、是）作宾语，前置。
③ 用"之""是"作提宾标志：
· 何…之有 / 句读之不知
· 唯…是… / 唯利是图
《左传·庄公十年》（曹刿论战）
何以战？
解析：疑问代词"何"作介词"以"的宾语前置。正常语序："以何战？"译为：凭借什么作战？
《论语·子罕》
吾谁欺？欺天乎？
解析：疑问代词"谁"作动词"欺"的宾语前置。正常语序："吾欺谁？"
《左传·僖公二十四年》
古之人不余欺也。
解析：否定句（"不"）中代词"余"作宾语前置。正常语序："古之人不欺余也。"
《墨子·公输》
宋何罪之有？
解析："何…之有"式，"之"为提宾标志。正常语序："宋有何罪？"
成语
唯利是图 / 唯命是听
解析："唯…是…"式，"是"为提宾标志。正常语序："唯图利 / 唯听命"。

📘 状语后置（介词结构后置）

格式：动词 + 于/以/乎 + 名词（介词结构放在动词后作补语）
说明：现代汉语中此类介词结构一般置于动词前作状语，故称"后置"。
《荀子·劝学》
青，取之于蓝，而青于蓝。
解析："于蓝"置于动词"取"后；第二个"于蓝"置于形容词"青"后表比较。译为：靛青从蓝草中提取，却比蓝草更青。
《史记·廉颇蔺相如列传》
以勇气闻于诸侯。
解析："于诸侯"置于动词"闻"后。译为：凭借勇气在诸侯中闻名。
《论语·先进》（子路、曾皙、冉有、公西华侍坐）
浴乎沂，风乎舞雩，咏而归。
解析："乎"相当于"于"，介词结构后置。译为：在沂水里洗澡，在舞雩台上吹风。
《荀子·劝学》
具告以事。
解析："以事"置于动词"告"后。正常语序："以事具告"。译为：把事情全部告诉（他）。

📘 定语后置

常见格式：
① 中心词 + 之 + 定语 + 者（马之千里者）
② 中心词 + 而 + 定语 + 者
③ 中心词 + 定语 + 者（约数/数量后置亦归此类讨论）
④ 中心词 + 之 + 定语（蚓无爪牙之利，筋骨之强）
韩愈《马说》
马之千里者，一食或尽粟一石。
解析："马之千里者"＝"千里之马"。"之"为定语后置标志，"者"为后置定语的煞尾。译为：能跑千里的马。
《荀子·劝学》
蚓无爪牙之利，筋骨之强。
解析："爪牙之利"＝"利之爪牙"（锋利的爪牙）。"之"为定语后置标志。译为：蚯蚓没有锋利的爪牙、强健的筋骨。
《史记·项羽本纪》
我持白璧一双，欲献项王；玉斗一双，欲与亚父。
解析：数量词"一双"置于中心词"白璧""玉斗"之后，属定语后置的一种（数量定语后置）。译为：我拿一双白璧、一双玉斗。
《史记·廉颇蔺相如列传》
求人可使报秦者，未得。
解析："人可使报秦者"＝"可使报秦之人"。"者"字结构作后置定语。译为：寻找可以出使回复秦国的人。
