分流分压电阻计算器

一、串联分压计算

输入总电压和串联电阻值，计算每个电阻上的分压。公式：Vi = Vtotal × Ri / ΣR

二、并联分流计算

输入总电流和并联电阻值，计算每个支路的分流。公式：Ii = Itotal × (Req / Ri)

三、反向计算：已知目标电压求电阻

两电阻串联分压，已知总电压、目标电压和另一电阻，求所需电阻。公式：Rtarget = Vtarget × Rother / (Vtotal - Vtarget)

四、反向计算：已知目标电流求电阻

两电阻并联分流，已知总电流、目标支路电流和另一电阻，求所需电阻。公式：Rtarget = Rother × (Itotal - Itarget) / Itarget

一、工具简介

「分流分压电阻计算器」是一款面向电子工程师、电气技术人员、高校师生及电子爱好者的在线计算工具，用于解决直流电路中两类最基础也最常用的电阻网络计算问题：

  • 串联分压：已知总电压和若干串联电阻，求每个电阻两端的电压降。
  • 并联分流：已知总电流和若干并联电阻，求流过每个支路的电流。
  • 反向设计：已知期望的分压或分流结果，反推所需的电阻值。

该工具解决的核心问题是：在实际电路设计、调试、维修过程中，工程师经常需要快速估算或精确计算分压/分流网络中各节点的电压或各支路的电流，以选择合适的电阻标称值、评估功耗、校验设计裕量。手工计算容易出错，尤其在多电阻网络或需要反复迭代调整时，本工具可以显著提升效率。

本工具基于理想电阻模型，遵循欧姆定律与基尔霍夫定律，不考虑温度系数、寄生电感/电容、高频效应、电阻公差等非理想因素。计算结果适用于低频、直流、小信号场景的初步设计与估算。

二、参数详细说明

2.1 串联分压模块

参数含义单位取值范围说明
Vtotal总电压伏特 (V)任意实数施加在串联电阻网络两端的电压。可以为 0、负数（表示反向偏置），但实际工程中通常为正。
Ri第 i 个电阻欧姆 (Ω)> 0必须为正数。0 或负数在物理上无意义（0 表示短路，负数表示有源器件，均超出本工具范围）。支持科学计数法，如 1e3 表示 1kΩ。

输出：每个电阻上的电压 Vi，单位伏特 (V)。所有 Vi 之和应等于 Vtotal（在浮点精度范围内）。

输出：每个支路上的电流 Ii，单位安培 (A)。所有 Ii 之和应等于 Itotal（在浮点精度范围内）。

2.3 反向计算模块

反向计算仅支持两电阻网络（一目标电阻 + 一已知电阻），因为多电阻情况下解不唯一。

三、实际使用场景

场景 1：LED 限流电阻设计

问题：使用 5V 单片机 IO 口驱动一只红色 LED（正向压降约 2V，期望工作电流 10mA），需要串联多大电阻？

建模：将 LED 视为一个固定 2V 压降的元件，则电阻上的分压为 5V - 2V = 3V。这是一个两电阻串联分压问题：RLED 等效压降 2V，Rlimit 期望压降 3V。

使用反向计算：Vtotal = 5V，Vtarget = 3V（电阻上的电压），Rother 未知。但更直接的方式：已知电流 10mA，电阻上电压 3V，由欧姆定律 R = V/I = 3V / 0.01A = 300Ω。

本工具用法：在「反向计算：已知目标电压求电阻」中，若将 LED 等效为另一电阻（需先估算其动态电阻），可反推限流电阻。但更推荐直接用欧姆定律。本工具适合验证：输入 Vtotal=5V，R1=300Ω（限流），R2=200Ω（LED 等效），则 V2=2V，符合预期。

场景 2：传感器信号分压衰减

问题：某传感器输出 0~10V 信号，需要接入 0~3.3V 的 ADC 输入，设计分压网络。

建模：两电阻串联分压，要求 Vout/Vin = 3.3/10 = 0.33。即 R2/(R1+R2) = 0.33。

使用本工具：在「反向计算」中输入 Vtotal=10V，Vtarget=3.3V，Rother=10kΩ（上拉电阻，取值兼顾功耗与 ADC 输入阻抗），计算得 Rtarget = 3.3 × 10000 / (10 - 3.3) ≈ 4925Ω。选取 E24 标称值 4.99kΩ 或 5.1kΩ。

验证：在「串联分压」中输入 Vtotal=10V，R1=10000Ω，R2=4990Ω，得到 V2≈3.327V，满足 3.3V ADC 量程要求。

场景 3：电流表扩程（分流器设计）

问题：有一只满偏电流 1mA、内阻 100Ω 的表头，需要改装为量程 1A 的电流表，求分流电阻。

建模：表头与分流电阻并联。总电流 1A 时，表头支路电流 1mA，分流电阻支路电流 999mA。

使用本工具：在「反向计算：已知目标电流求电阻」中输入 Itotal=1A，Itarget=0.001A（表头电流），Rother=100Ω（表头内阻），计算得 Rtarget = 100 × (1 - 0.001) / 0.001 = 99900Ω？不对，这里 Itarget 是目标支路（分流电阻）的电流，应为 0.999A。重新输入：Itotal=1A，Itarget=0.999A，Rother=100Ω，得 Rtarget = 100 × (1 - 0.999) / 0.999 ≈ 0.1001Ω。

验证：在「并联分流」中输入 Itotal=1A，R1=100Ω（表头），R2=0.1001Ω（分流器），得 I1≈0.001A，I2≈0.999A，符合预期。

场景 4：多路 LED 并联均流

问题：3 只 LED 并联由同一电源供电，各支路串联不同电阻以实现不同亮度比例（1:2:3）。

建模：设电源电压 12V，LED 正向压降均为 2V，则各支路电阻上压降均为 10V。要使电流比为 1:2:3，电阻比应为 3:2:1（电流与电阻成反比）。设基准电流 5mA，则 R1=10V/5mA=2kΩ，R2=10V/10mA=1kΩ，R3=10V/15mA≈667Ω。总电流 30mA。

使用本工具：在「并联分流」中输入 Itotal=0.03A，R1=2000Ω，R2=1000Ω，R3=667Ω，验证各支路电流是否约为 5mA、10mA、15mA。实际计算：等效电阻 Req ≈ 307.9Ω，I1=0.03×307.9/2000≈4.62mA，I2≈9.24mA，I3≈13.8mA。比例约为 1:2:3，但因 667Ω 非精确值，存在偏差。可调整 R3=666.7Ω 使比例更精确。

场景 5：运放反馈网络分压比校验

问题：非反相运放电路中，反馈网络由 R1=10kΩ 和 R2=1kΩ 串联组成，输入信号加在 R2 上（分压后送入反相端），校验分压比。

建模：两电阻串联，输入 1V 信号，期望 R2 上分压为 1V × 1k/(10k+1k) ≈ 0.0909V。

使用本工具：在「串联分压」中输入 Vtotal=1V，R1=10000Ω，R2=1000Ω，得 V1=0.909V，V2=0.0909V。分压比 0.0909，对应运放增益 1 + R1/R2 = 11 倍，符合设计预期。

四、常见错误与排查

  1. 输入电阻为 0 或负数：工具会抛出错误。物理上 0Ω 表示短路，负数表示有源器件，均超出本工具的理想电阻模型范围。请检查输入值。
  2. 反向计算中目标电压等于总电压：此时所需电阻为无穷大（开路），工具会返回 Infinity 或抛出错误。请检查设计目标是否合理。
  3. 反向计算中目标电流等于总电流：此时所需电阻为 0（短路），工具会返回 0。请确认是否真的需要短路该支路。
  4. 浮点精度导致的微小误差：例如计算结果应为 3.3V，实际显示 3.3000000000000003V。这是 IEEE 754 双精度浮点数的固有限制，不影响工程判断。工具内部使用 1e-9 的容差进行相等判断。
  5. 多电阻并联时某电阻极小：会导致等效电阻接近该极小值，其他支路电流接近 0。这是正常物理现象，但要注意数值稳定性。
  6. 单位混淆：工具统一使用国际单位制（V、A、Ω）。输入 mA 需转换为 A（如 10mA = 0.01A），输入 kΩ 需转换为 Ω（如 10kΩ = 10000Ω）。工具不做单位自动转换。
  7. 空电阻数组：工具会抛出错误。至少需要一个电阻才能构成电路。

五、数据来源与标准依据

本工具的计算公式基于经典电路理论，主要依据：

  • 欧姆定律：V = I × R，是直流电阻电路分析的基础。
  • 基尔霍夫电压定律 (KVL)：串联电路中各元件电压之和等于总电压。
  • 基尔霍夫电流定律 (KCL)：并联电路中各支路电流之和等于总电流。
  • IEC 60063:2015：《电阻器和电容器的标称值系列》，规定了 E 系列（E6、E12、E24、E48、E96、E192）优选值。本工具不直接提供标称值选取功能，但用户可参考该标准将计算结果圆整到最接近的标称值。
  • GB/T 5729-2003：《电子设备用固定电阻器》，等同采用 IEC 60115-1，规定了固定电阻器的通用规范。本工具不涉及电阻器的具体性能指标，但用户选型时可参考该标准。
  • GB/T 1234-2017（需查标准原文确认最新版本号）：电子设备用固定电阻器分规范。

本工具不直接引用任何国家强制性标准，因为分压分流计算属于基础电路理论，不涉及安全、电磁兼容等强制要求。但在实际工程应用中，电阻选型需考虑功率额定值、温度系数、精度等级、耐压等参数，这些需参考具体电阻器产品标准。

六、局限性说明

本工具存在以下局限性，用户在使用时应充分了解：

  1. 理想电阻模型：假设电阻为纯阻性，不考虑寄生电感（ESL）和寄生电容（EPC）。在高频（通常 > 10MHz）或快速脉冲电路中，实际阻抗会偏离标称值，本工具结果不适用。
  2. 不考虑温度系数：实际电阻值随温度变化（温度系数 TCR，单位 ppm/°C）。本工具假设电阻值恒定，不适用于高温或大功率发热场景的精确计算。
  3. 不考虑功率耗散：本工具不计算电阻上的功率 P = V²/R 或 P = I²R，用户需自行校验所选电阻的额定功率是否足够，避免过热损坏。
  4. 不考虑电阻公差：实际电阻有精度等级（如 ±1%、±5%），本工具使用标称值计算，不分析公差对分压/分流比的影响。精密电路需进行最坏情况（WCA）或蒙特卡洛分析。
  5. 仅支持直流/低频：本工具基于直流电路理论，不适用于交流电路（需考虑阻抗、相位）、瞬态分析（需考虑电容/电感）。
  6. 反向计算仅限两电阻：多电阻反向设计问题解不唯一，本工具未提供多电阻反向计算功能。
  7. 不提供标称值圆整：计算结果可能为非标称值（如 4925Ω），用户需自行参照 IEC 60063 的 E 系列选取最接近的标称值，并重新校验分压/分流比是否满足要求。
  8. 浮点精度限制：JavaScript 使用 IEEE 754 双精度浮点数，有效数字约 15~17 位。极端大或极端小的数值（如 1e-20 或 1e20）可能产生精度损失或溢出。
  9. 不支持非线性元件：二极管、晶体管、热敏电阻等非线性元件的 V-I 关系不是线性的，本工具不适用。
  10. 不验证电路可行性：本工具只做数学计算，不判断电路是否物理可实现（如功率是否超标、电压是否击穿、电流是否超过导线载流量等）。

综上，本工具适用于低频、直流、小信号、理想电阻场景的初步设计与估算。对于精密、高频、大功率、高可靠性应用，需结合专业 EDA 工具（如 SPICE 仿真）和详细的手稿计算进行验证。

七、附录：公式汇总

串联分压

总电阻：Rtotal = R1 + R2 + ... + Rn

第 i 个电阻上的电压：Vi = Vtotal × Ri / Rtotal

并联分流

等效电阻：1/Req = 1/R1 + 1/R2 + ... + 1/Rn

第 i 个支路的电流：Ii = Itotal × Req / Ri

两电阻特例：I1 = Itotal × R2 / (R1 + R2)，I2 = Itotal × R1 / (R1 + R2)

反向计算（两电阻）

分压：Rtarget = Vtarget × Rother / (Vtotal - Vtarget)

分流：Rtarget = Rother × (Itotal - Itarget) / Itarget
