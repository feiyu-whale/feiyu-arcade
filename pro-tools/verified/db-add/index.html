一、工具简介

  

    「分贝叠加工具」是一个面向声学工程、环境噪声监测、产品噪声评估等场景的纯前端计算工具。它解决的核心问题是：多个独立声源共同作用时，总声级如何计算？不同声学量（声压、声强、声功率、声压级、声强级、声功率级）之间如何换算？
  

  

    分贝（decibel, dB）本身是一个对数比值，不能直接相加。例如两个 60 dB 的声源叠加，结果不是 120 dB，而是约 63 dB。本工具严格按照声学物理公式实现，所有核心算法均为纯函数，无外部依赖，可直接在浏览器中运行。
  


  
二、核心概念

  
2.1 分贝的本质

  

    分贝是贝尔（Bel）的十分之一，用于表示两个同类物理量比值的对数。在声学中，根据被比较物理量的性质（能量型 vs. 场量型），公式不同：
  

  
    
    
  • 能量型量（声强 I、声功率 W）：L = 10·log₁₀(Q/Q₀)
    • 
    
  • 场量型量（声压 p、质点速度 v）：L = 20·log₁₀(Q/Q₀)，因为能量与场量的平方成正比
    • 
  


  
2.2 三种声级

  

    
名称符号定义参考值（空气）

    
声压级Lp20·log₁₀(p/p₀)p₀ = 20 μPa = 2×10⁻⁵ Pa

    
声强级LI10·log₁₀(I/I₀)I₀ = 10⁻¹² W/m²

    
声功率级LW10·log₁₀(W/W₀)W₀ = 10⁻¹² W

  

  

    在自由平面波或球面波条件下（远场、无反射），空气中声压级与声强级数值近似相等。这是工程上常用声压级代替声强级测量的物理基础。
  


  
2.3 多声源叠加原理

  

    对于不相干声源（绝大多数工程场景，如多台设备、交通噪声），能量线性叠加：
  

  
L_total = 10 · log₁₀( Σ 10^(L_i / 10) )

  

    对于相干声源（同频率、固定相位差，如扬声器阵列），需要按声压（场量）叠加并考虑相位，本工具不处理相干叠加场景（详见局限性）。
  


  
三、函数与参数说明

  

    
函数参数单位取值范围说明

    

      decibelSum(levels)
      levels: number[]dB
      任意实数，建议 -200 ~ 250
      多个分贝值能量叠加。空数组抛异常。
    

    

      pressureToSPL(p, pRef)
      p: number（声压）
pRef: number（参考声压，默认 2e-5）		
      Pa / Pa
      p ≥ 0；pRef > 0
      声压 → 声压级。p=0 返回 -Infinity。
    

    

      SPLToPressure(Lp, pRef)
      Lp: number（声压级）
pRef: number		
      dB / Pa
      任意实数；pRef > 0
      声压级 → 声压。
    

    

      intensityToSIL(I, IRef)
      I: number（声强）
IRef: number（默认 1e-12）		
      W/m² / W/m²
      I ≥ 0；IRef > 0
      声强 → 声强级。
    

    

      SILToIntensity(LI, IRef)
      LI: number
IRef: number		
      dB / W/m²
      任意实数；IRef > 0
      声强级 → 声强。
    

    

      powerToSWL(W, WRef)
      W: number（声功率）
WRef: number（默认 1e-12）		
      W / W
      W ≥ 0；WRef > 0
      声功率 → 声功率级。
    

    

      SWLToPower(LW, WRef)
      LW: number
WRef: number		
      dB / W
      任意实数；WRef > 0
      声功率级 → 声功率。
    

    

      distanceAttenuation(L1, r1, r2)
      L1: number（r1 处声压级）
r1, r2: number（距离）		
      dB / m / m
      r1, r2 > 0
      点声源自由场球面波衰减：L2 = L1 - 20·log₁₀(r2/r1)。倍距离约 -6 dB。
    

    

      subtractDecibels(Ltotal, Lbg)
      Ltotal: number（总声级）
Lbg: number（背景声级）		
      dB / dB
      Ltotal > Lbg；差值建议 ≥ 3 dB
      从总测量值中扣除背景噪声，得到声源净声级。差值 < 3 dB 时修正不确定度显著增大。
    

  


  
四、实际使用场景


  
场景 1：车间多台设备噪声叠加

  
问题：车间内有 3 台设备，各自在操作位产生的 A 计权声级分别为 82 dB、85 dB、88 dB，求总声级。

  
输入：decibelSum([82, 85, 88])

  
计算过程：10·log₁₀(10^8.2 + 10^8.5 + 10^8.8) = 10·log₁₀(1.585e8 + 3.162e8 + 6.310e8) = 10·log₁₀(1.106e9) ≈ 90.44 dB

  
结果：约 90.4 dB。可见总声级主要由最大声源（88 dB）贡献，叠加后仅增加约 2.4 dB。

  
工程意义：降噪应优先治理最大声源，治理 82 dB 设备对总声级影响甚微。


  
场景 2：声压与声压级互转

  
问题：某麦克风测得声压有效值为 0.632 Pa，求声压级；反之，110 dB 对应多大声压？

  
输入 1：pressureToSPL(0.632) → 约 100 dB（因为 0.632 / 2e-5 = 31600，20·log₁₀(31600) ≈ 90？需精确：20·log₁₀(31600) = 20 × 4.4997 = 89.99 ≈ 90 dB。修正：0.632 Pa 对应约 90 dB；100 dB 对应 2 Pa）

  
输入 2：SPLToPressure(100) → 2 Pa

  
输入 3：SPLToPressure(110) → 约 6.32 Pa

  
注意：默认参考声压为空气中 20 μPa；若为水听器应用，需传入 pRef = 1e-6（1 μPa）。


  
场景 3：点声源距离衰减估算

  
问题：某设备在 1 m 处测得 95 dB，求 5 m 处和 10 m 处的声级（自由场近似）。

  
输入 1：distanceAttenuation(95, 1, 5) → 95 - 20·log₁₀(5) ≈ 95 - 13.98 = 81.0 dB

  
输入 2：distanceAttenuation(95, 1, 10) → 95 - 20 = 75 dB

  
适用条件：自由场（无反射）、点声源（距离远大于声源尺寸）、无地面吸收与空气吸收。室内混响场不适用。


  
场景 4：背景噪声修正

  
问题：测量某机器噪声，开机时总声级 78 dB，停机时背景声级 73 dB，求机器本身声级。

  
输入：subtractDecibels(78, 73)

  
计算：10·log₁₀(10^7.8 - 10^7.3) = 10·log₁₀(6.310e7 - 1.995e7) = 10·log₁₀(4.315e7) ≈ 76.3 dB

  
结果：机器净声级约 76.3 dB。

  
注意：差值 5 dB，修正量 1.7 dB，可接受。按 GB/T 3767（等效 ISO 3744），差值 < 3 dB 时测量无效，3~10 dB 需修正，> 10 dB 修正可忽略。


  
场景 5：声功率级估算远处声压级

  
问题：某设备声功率级 LW = 105 dB，在半自由场（地面反射，指向性因子 Q=2，半球辐射），求 4 m 处的声压级。

  
公式：Lp = LW - 20·log₁₀(r) - 11 + DI（半球面，DI = 10·log₁₀(Q/(4π)) + 11 ≈ 3 dB 当 Q=2）

  
更直接：半球面 Lp = LW - 20·log₁₀(r) - 8（Q=2 时）

  
计算：105 - 20·log₁₀(4) - 8 = 105 - 12.04 - 8 = 84.96 dB

  
说明：此场景需结合 powerToSWL、SWLToPower 与距离衰减公式联合使用，本工具提供基础换算，复杂指向性与环境修正需用户自行组合。


  
场景 6：N 个相同声源叠加

  
问题：10 台相同风机，每台 65 dB，求总声级。

  
输入：decibelSum(Array(10).fill(65)) → 65 + 10·log₁₀(10) = 75 dB

  
规律：N 个相同声源叠加，总声级增加 10·log₁₀(N)。N=2 → +3 dB；N=4 → +6 dB；N=10 → +10 dB；N=100 → +20 dB。


  
五、常见错误与排查

  

    
现象原因处理

    
直接相加 60+60=120 dB分贝是对数量，不能直接相加必须使用 decibelSum

    
pressureToSPL(0) 返回 NaNlog₁₀(0) 无定义函数返回 -Infinity，调用方需判断

    
pressureToSPL(-1) 返回 NaN声压为负无物理意义传入声压有效值（RMS），必为非负

    
subtractDecibels 返回 NaNLtotal ≤ Lbg检查测量：总声级必须大于背景声级

    
距离衰减结果偏大室内混响场不适用球面波公式室内需考虑房间常数，使用赛宾/伊林公式

    
结果与实测偏差 > 3 dB未做背景修正、气象条件、地面吸收等按 GB/T 3767 进行环境修正

    
decibelSum 抛 "levels must be a non-empty array"传入空数组或非数组确保传入至少一个数值的数组

    
浮点误差导致 3.0103000000000004IEEE 754 双精度固有特性显示时建议 toFixed(1) 或 toFixed(2)

    • 
    
  • GB 3096-2008《声环境质量标准》—— 环境噪声评价量
    • 
    
  • GB/T 3767-2016（等效 ISO 3744:2010）《声学 声压法测定噪声源声功率级》—— 背景噪声修正规则（差值 < 3 dB 无效，3~10 dB 修正，> 10 dB 忽略）
    • 
    
  • GB/T 15173-2010（等效 IEC 60942）《声校准器》—— 参考声压 20 μPa
    • 
    
  • ISO 9613-2:1996《声学 户外声传播衰减 第 2 部分：一般计算方法》—— 点声源几何衰减
    • 
    
  • 参考声压：空气 20 μPa（人耳听阈），水中 1 μPa（需显式传入）
    • 
    
  • 参考声强：10⁻¹² W/m²
    • 
    
  • 参考声功率：10⁻¹² W
    • 
  

  

    注：标准原文中关于 A 计权、C 计权频率响应曲线、倍频程/1/3 倍频程合成等细节，本工具未实现，需查标准原文（GB/T 15173、IEC 61672-1）。
  


  
七、局限性说明

  

    本工具不能做以下事情，请勿超范围使用：
  

  
    
    
  1. 不处理相干声源叠加：同频同相位声源（如扬声器阵列）需按声压矢量叠加并考虑相位差，本工具仅支持不相干声源能量叠加。
    2. 
    
  2. 不做频率计权：A 计权、C 计权、Z 计权需对频谱数据逐频点加权后合成，本工具仅处理总声级标量。
    3. 
    
  3. 不做倍频程/1/3 倍频程合成：频谱数据的能量合成需用户自行按频带调用 decibelSum。
    4. 
    
  4. 不考虑空气吸收、地面吸收、气象衰减：距离衰减仅计算几何衰减（球面波 -6 dB/倍距离），长距离传播需按 ISO 9613-2 补充。
    5. 
    
  5. 不考虑房间混响：室内声场需使用房间常数 R 与指向性因子 Q 修正，本工具仅提供自由场公式。
    6. 
    
  6. 不处理脉冲噪声、统计声级（L10/L50/L90）：需时间序列数据，本工具仅处理稳态声级。
    7. 
    
  7. 不替代专业声级计：本工具为理论计算，工程验收必须以经计量检定的声级计实测为准（GB/T 3785.1）。
    8. 
    
  8. 不处理水中声学：默认参考值为空气，水中应用需显式传入 pRef=1e-6，且部分公式（如声强与声压关系）需考虑特性阻抗差异。
    9. 
    
  9. 浮点精度限制：极大分贝差（如 200 dB 与 0 dB 叠加）可能因 IEEE 754 精度损失导致小值被吞没，工程上可忽略。
    10.
