使用说明书


  
一、本工具干什么用

  
本工具面向个人储户、贷款借款人、财务学习者与小型机构业务人员，提供四类最常见的存贷款利息计算能力：

  
    
    
  1. 单利计算：适用于短期存款、国债、部分票据贴现等按单利计息的场景。
    2. 
    
  2. 复利计算：适用于定期复投、理财滚存、长期储蓄等按复利滚算的场景。
    3. 
    
  3. 等额本息还款：适用于房贷、车贷、消费贷等每月还款额固定的场景。
    4. 
    
  4. 等额本金还款：适用于每月偿还本金固定、利息逐月递减的场景。
    5. 
  

  
工具同时支持对四种方式进行横向对比，帮助使用者在贷款方案选择、存款产品比较时获得直观的数量级参考。


  
二、参数详解

  

    
参数含义单位取值范围

    
本金 P初始存入或借入的金额元（人民币）≥ 0，建议 ≤ 10^12

    
年利率 r名义年利率小数（如 0.05 表示 5%）≥ 0

    
期限 t存贷款期限年（支持小数，如 0.5 表示半年）≥ 0

    
复利频次 n每年复利次数次/年正整数（1/2/4/12/365 等）

    
还款月数 N贷款总期数月正整数

  


  
三、计算公式与依据

  
单利：I = P × r × t，本息和 A = P + I。

  
复利：A = P × (1 + r/n)^(n×t)。

  
等额本息月供：PMT = P × i × (1+i)^N / ((1+i)^N − 1)，其中 i 为月利率（年利率/12）。

  
等额本金月供：每月本金 = P / N；第 k 月利息 = (P − (k−1)×P/N) × i。

  
上述公式为数学标准形式。实际银行计息可能涉及「算头不算尾」「实际天数/360」「实际天数/365」等规则，参见中国人民银行《人民币利率管理规定》（银发〔1999〕77 号，后续有修订，具体以最新有效版本为准，需查标准原文）。本工具未内置日历天数折算，仅按年化/月化比例计算。


  
四、使用场景（5 例）

  

    
场景 1：三年期定存到期收益估算

    
存入 10 万元，年利率 2.5%，三年到期。选择「单利」，输入 P=100000、r=0.025、t=3，可得利息约 7500 元，本息和 107500 元。注意：国内银行定期存款通常按单利计息，到期一次付息，本场景匹配度较高。

  

  

    
场景 2：理财产品按季复投

    
投入 5 万元，年化 4%，按季复利，持有 2 年。选择「复利」，n=4，可得本息和约 54142.87 元。与单利（54000 元）对比，复利多出约 142.87 元，体现复利效应。

  

  

    
场景 3：房贷等额本息方案

    
贷款 100 万元，年利率 4.2%，30 年（360 期）。选择「等额本息」，可得月供约 4889.94 元，总利息约 760377 元。该方式每月还款额固定，便于家庭预算规划。

  

  

    
场景 4：房贷等额本金方案对比

    
同样 100 万元、4.2%、30 年，选择「等额本金」，首月月供约 6166.67 元，末月约 2788.43 元，总利息约 631750 元。相比等额本息少付约 12.86 万元利息，但前期还款压力更大。

  

  

    
场景 5：教育储蓄长期规划

    
为 10 年后子女留学准备 50 万元，假设年化 3.5% 按年复利，反推现在需一次性存入多少。可用复利公式反算 P = A / (1+r)^t ≈ 35533.87 元（此处为演示思路，工具当前版本仅支持正向计算，反向求解需使用者自行代入）。

  


  
五、常见错误

  
    
    
  • 年利率与月利率混淆：等额本息/等额本金公式中的 i 应为月利率（年利率/12），切勿直接代入年利率。
    • 
    
  • 期限单位错误：单利、复利的 t 以「年」为单位；还款期数 N 以「月」为单位，二者不可混用。
    • 
    
  • 复利频次误用：「按月复利」应填 n=12，而非 r 直接除以 12 再填 n=1。
    • 
    
  • 忽略费用：实际贷款可能含手续费、保险费、担保费，本工具仅计算利息，不涵盖这些成本。
    • 
    
  • 忽略提前还款：本工具假设按期足额还款至到期，不支持部分提前还款、利率调整等动态场景。
    • 
    
  • 忽略税费：利息所得可能涉及个人所得税（如储蓄存款利息所得，政策有阶段性调整，需查最新税务文件），本工具未扣除税费。
    •

七、精度与误差说明（有限精准原则）

  
现实金融变量是无限的（利率可能精确到小数点后更多位、天数可能涉及闰年与节假日、还款日可能遇周末顺延等），本工具只做到「方法准、输入项准、结果给误差范围」，不承诺绝对精确。


  
① 算准了什么：

  
    
    
  • 数学公式本身按标准形式实现，单利、复利、等额本息、等额本金的代数推导正确。
    • 
    
  • 在用户输入的本金、利率、期限完全确定的前提下，输出结果与公式计算一致。
    • 
    
  • JavaScript 使用 IEEE 754 双精度浮点数，有效数字约 15–17 位，对常规金额（≤ 10^12 元）的元位计算通常可靠。
    • 
  


  
② 哪些因素没算进去：

  
    
    
  • 实际天数折算规则（ACT/360、ACT/365、30/360 等）未实现，仅按年化/月化比例。
    • 
    
  • 闰年、节假日顺延、还款日调整未考虑。
    • 
    
  • 利率浮动（如 LPR 重定价周期）未支持。
    • 
    
  • 提前还款、逾期罚息、宽限期未支持。
    • 
    
  • 利息税、手续费、保险费、担保费等未计入。
    • 
    
  • 分段计息（如利率调整日切分）未支持。
    • 
  


  
③ 误差大概多大：

  
    
    
  • 浮点运算本身：单次四则运算相对误差约 10^−15 量级，累计到数百期还款明细，末位（分以下）可能偏差 10^−10 元量级，经四舍五入到分后通常不影响结果。
    • 
    
  • 与实际银行计息对比：因天数规则、利率生效日、还款日等差异，总利息可能偏差数元至数十元，长期限、大金额、高利率场景偏差可能更大。
    • 
    
  • 本工具输出结果仅供估算与方案对比参考，不作为实际结息、对账、诉讼依据。实际金额以开户银行或贷款机构出具的正式对账单为准。
    • 
  


  
八、局限性

  
    
    
  • 仅支持固定利率、固定期限、按期足额还款的理想化模型。
    • 
    
  • 不支持组合贷款（公积金 + 商业）、不支持多笔贷款合并计算。
    • 
    
  • 不支持外币、不支持与通胀联动的实际利率计算。
    • 
    
  • 不支持反向求解（已知本息和求本金/利率/期限）。
    • 
    
  • 前端运行，未做数据持久化，刷新页面后输入丢失。
    • 
    
  • 未做输入合法性强校验（如超大数值、非数字字符），异常输入可能返回 NaN 或 Infinity。
    •
