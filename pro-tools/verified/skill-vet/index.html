② 安检报告

判定依据：🚨 命中「立即拒绝」类特征（外传数据 / 读密钥 / eval 外部输入 / 混淆代码 / 提权）→ 直接阻断；
⚠️ 命中高危（网络请求、装包、写系统文件、读记忆文件）→ 人工复核；
本工具是「静态扫描」，只认特征模式，代码到底想干什么要靠人读。扫描通过 ≠ 一定安全。

③ ⚡ 深度扫描（动态模拟）

⚠️ 这一区比上面的普通筛查更完整，但对设备有要求：
• 需要较新的浏览器（支持 Web Worker + Proxy）
• 大文件或复杂代码可能卡顿，建议单个文件 ≤ 2MB
• 会在隔离环境里实际执行 JS 逻辑（已断网、已限时），耗电略高
• 只跑 JS；Python / Shell 等只能做静态扫描

原理：把 JS 放进 Worker 隔离环境跑起来，但先把 fetch / XMLHttpRequest / WebSocket / eval / localStorage 全部换成“记录器”—— 代码会以为自己联网、读数据了，实际全被拦下并记录。超时 3 秒自动终止。
