🐳 浏览器端 Demucs 音轨分离

上传一首歌，把它拆成人声 / 鼓 / 贝斯 / 其他四条音轨。
模型在 htdemucs 的基础上导出了频域部分，STFT / ISTFT 全部由前端 JavaScript 实现。
说实话：这个页面完全在你的浏览器里跑，音频不上传、不经过任何服务器。 模型首次加载要下载 139 MB，分离速度取决于你的显卡（有 WebGPU 会快很多，没有就走 WASM，会很慢）。 它存在的意义是证明技术跑得通，不是拿来日常干活的 —— 真要批量处理，还是用命令行快。
拖一首歌进来，或者点这里选择文件
支持 mp3 / wav / flac / ogg / m4a（浏览器能解的都行）
